# 第001章细纲

### 第1章：输掉 Major 后，我从民间赛重新开始

- 核心事件：周野在上海 Major 最后一回合因没有及时交出第二脚步而失冠，独自复盘时被 `7:5` 异常带到白桥枪馆，随后只凭普通终端的两次短试获得七日临时客籍与可撤销试报名。
- 字数目标：8500字（本纲为既有正文的逆向映射，正文事实优先）。
- 阶段位置：开篇期第1章；完成职业创伤、世界切换、民间生存压力和第一阶段目标的同步建置。
- 单元ID/位置：TG-01·七日名单，第1拍“穿越与初试”。
- 目标情绪：离冠军只差半拍的绷紧与侥幸 → 事实无法撤回的失重 → 异常现场的戒备与陌生 → 只赢到一次重新证明机会的克制期待。
- 主角目标/关键选择：先弄清自己为何输掉回合、又到了哪里；在履历无法验证时，选择如实承认不知道、接受设备限制与担保条件，用当场动作而非 Major 故事换试训机会。
- 章节定位：高压建置章＋推进章。
- 本章结构公式：Major 守包失误（建立核心缺陷）＋团队事实复盘（锁定职业底色）＋`7:5` 音画异常（穿越触发）＋白桥设备间程序处置（建立世界边界）＋两轮短试对照（展示可塑性而非碾压）＋七日客籍与试报名（给出阶段目标）。
- 章首钩子：反差场景 — 奖杯只有二十来米，却因最后一个守包回合比整座场馆都远。
- 核心爽点：无碾压式爽点；小兑现是周野在第二轮短试里停止同时看两条线，以及时信息和第一时间补枪证明自己确有职业底子，换到一张可撤销的试报名表。
- 本章禁止提前释放：不得确认 `7:5` 来源；不得证明平行宇宙；不得取得正式身份、赛籍、天衡资格或长期信任；不得把苏禾、江宁、唐夏、许安写成现代队友的镜像。
- 契约风险：契约安全；逆向映射必须保留“失误由团队事实共同构成、周野承担自己的那一份”，不能改成单人背锅或救世主降临。

#### 内容概括（五段式）

- 起因：上海 Major 决胜图来到进攻方守包末局，周野作为赵雨的补枪位，听到 A1 后方第二组脚步却没有及时报出。
- 发展：他因试图兼顾第二条线挪开准星，赵雨先倒，补枪链断裂；对手带拆弹器完成五秒拆除，白桥故事的起点由一场可复盘的职业失败建立。
- 转折：团队复盘后周野独自回看，语音、画面和时间轴发生半拍错位，比分短暂跳成 `7:5`，手机却只能录到黑屏；显示器最终变成通往另一处设备间的门。
- 高潮：周野连同自己的身体、现代手机和亚军奖牌落到白桥，被苏禾等人按未知闯入者处置；普通终端短试第一遍重演旧错，第二遍才以分级报点和补枪完成二打二。
- 结尾：苏禾只签七日担保，并保留四人撤销试报名的权利；周野在第五格写下姓名，落到“第一枪，从白桥开始”。

#### 情节安排（多线）

- 主线推进：从“现代职业选手失冠”推进到“无本地身份的白桥试训第五人”，明确第一阶段目标为通过完整试训并赶上午时报名锁定。
- 辅线推进：亚军奖牌、现代手机、监控断帧和 `7:5` 成为待核验物证；只登记事实，不给结论。
- 事件线 / 任务线：Major 末局 → 团队复盘 → 独自复盘 → 异常穿越 → 现场封控 → 临时客籍说明 → 普通终端短试 → 七日担保与试报名。
- 任务卡点（如适用）：周野想用“我打过六年职业”换设备验证 → 本地数据库无法查证、苏禾拒绝碰私人设备 → 只能接受离线公用终端与全程记录 → 删掉该卡点会破坏“经验不能越过程序”的卷契约 → 以十分钟短试收束。
- 感情线 / 关系线：无显性感情线；周野与白桥四人的关系从相互戒备变成“允许继续验证”，不等于欢迎、信任或正式入队。
- 逻辑线：第二信息未及时共享 → Major 补枪链断裂 → 独自复盘触发异常 → 白桥无法核验其身份 → 当场试训成为唯一可行的低风险验证 → 七日担保与可撤销报名成立。

#### 人物关系和出场顺序

- 出场顺序：周野 → 陈默 → 林溪 → 赵雨 → 顾遥 → 赛事工作人员与对手 → 亚军奖牌／回放设备 → 苏禾 → 唐夏 → 江宁 → 许安 → 罗叔 → 韩平 → 七日客籍表／南城公开赛试报名表。
- 人物关系变化：现代队伍与周野由共同守包转为共同承担事实复盘；白桥四人与周野由未知闯入者和处置人，转为担保方与有条件试训者。
- 视角/信息差：严格周野第一人称；读者只知道周野听到、看到和推测的内容。白桥众人知道本地制度与设备异常，周野不知道；周野知道现代 Major 与手机内容，白桥无法验证。双方都不知道穿越原理。
