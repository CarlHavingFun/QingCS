# 第008章细纲

### 第8章：替补先上

- 核心事件：唐夏因维修坊安全验收无法赶上周末杯半决赛开局，苏禾遵守已锁定的六人名单与赛事换人规则，安排夏满首发；白桥据此重排入口、设备和信息职责，让替补顺位真正改变比赛阵容。
- 字数目标：3600字。
- 阶段位置：开篇期第8章；TG-01收尾，以真实班次和合规阵容把名单承诺推向第一次公开比赛。
- 单元ID/位置：TG-01·七日名单，第8拍“替补合法上场与周末杯入口”。
- 目标情绪：临赛缺人的焦灼 → 发现已有合法顺位可承接的稳定 → 主力与替补都不被牺牲的职业尊严 → 对六人体系首次公开验证的紧张期待。
- 主角目标/关键选择：想按完整主力阵容打第一场；关键选择是接受唐夏的本职验收不能为比赛违规跳过，也接受夏满凭注册顺位首发，与她重新建立入口和补枪配合。
- 章节定位：推进章＋关系章。
- 本章结构公式：班次冲突（现实卡点）＋赛事替补规则核对（程序解法）＋夏满首发决定（顺位兑现）＋角色重排训练（六人体系）＋成本收益签字（队务落账）＋对手与首发板（公开赛钩子）。
- 章首钩子：突然揭示 — 唐夏把维修坊盖章通知放到桌上：她必须完成次日安全验收，最早只能在周末杯换边前赶到。
- 核心爽点：夏满不靠唐夏受伤或周野让位获得机会，而是凭第2章合法注册顺位首发；周野不抱怨阵容变化，主动把补枪和信息协议改成适合夏满的版本。
- 本章禁止提前释放：不得让夏满永久取代唐夏或成为主力；不得让唐夏放弃工作安全责任；不得让周野决定谁上场；不得提前赢下周末杯或获得长期资源。
- 契约风险：契约安全；需确保苏禾拥有阵容拍板权、夏满拥有合法实战收益、唐夏拥有履行本职责任的选择，周野只在自己功能位内贡献适配方案。

#### 内容概括（五段式）

- 起因：周末杯前夜，唐夏收到维修坊不可顺延的安全验收通知；缺席会牵连她的工作资格与姐姐旧伤后的家庭边界。
- 发展：苏禾核对杯赛六人注册、开局首发和换边一次合规替换规则，不找人情跳过程序；夏满成为唯一合法且已完成同标准试训的首发选择。
- 转折：夏满不把机会当补偿，要求按她的快速支援和设备判断重排；周野发现不能照搬与唐夏的入口距离，只能重新跑配合。
- 高潮：五人用有限时间完成两套入口，夏满在一次设备异常提示中先于众人发现输入波动，证明她的价值不只在“有人缺席”。
- 结尾：周末杯首发板上，夏满与周野同时在列；唐夏的姓名留在合规换人栏，旁边夹着维修坊验收回执的空位。

#### 情节安排（多线）

- 主线推进：确定周末杯半决赛首发与换人计划，TG-01“主力＋注册替补”承诺变成实际阵容。
- 辅线推进：唐夏的工作与安全旧债进入赛事；夏满获得至少一次合规实战机会；桥南急雨队作为第一支有独立利益与打法的对手进入。
- 事件线 / 任务线：工作通知 → 规则核验 → 阵容决定 → 角色重排 → 设备与入口演练 → 报名成本确认 → 首发板锁定。
- 任务卡点（如适用）：唐夏不能按时到场 → 临时找人会违规、坚持五人则无法开赛 → 使用已注册夏满并按换边规则预留唐夏 → 卡出替补真实价值和六人体系 → 以首发名单公示收束。
- 感情线 / 关系线：无显性感情线；周野与夏满从同场竞争者变为第一次公开比赛的直接入口搭档；唐夏与夏满不是互相抢位，而是对各自工作与比赛选择负责。
- 逻辑线：本职验收不可跳过 → 六人注册本就为现实波动准备 → 苏禾按规则启用夏满 → 新阵容必须重练而非套旧方案 → 第一场公开验证获得明确看点。

#### 人物关系和出场顺序

- 出场顺序：唐夏／维修坊通知 → 苏禾 → 周野 → 夏满 → 韩平／周末杯规则页 → 江宁 → 许安 → 罗叔／设备清单 → 桥南急雨队签位 → 首发板。
- 人物关系变化：夏满由纸面替补转为有明确首发任务的队员；周野与夏满由比较成绩转为必须互相补足的搭档；苏禾对六人名单由风险备份转为实际轮换工具。
- 视角/信息差：周野起初只看见“唐夏缺席”，不了解维修验收失约会影响她的工作资格；夏满比周野更了解普通终端的磨损提示，周野在重练中才看见这项优势。
