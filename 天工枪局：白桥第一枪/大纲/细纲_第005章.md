# 第005章细纲

### 第5章：旧经验要重验

- 核心事件：白桥用可重复训练逐项测试周野的补枪距离、赤漆连珠铳枪感、木廊声音与本地图撤位，确认补枪时序有价值，却把枪械、声音和路线全部列为待证或需重学。
- 字数目标：3800字。
- 阶段位置：开篇期第5章；第一次系统运行“现代经验经本地验证才有用”的题材核心。
- 单元ID/位置：TG-01·七日名单，第5拍“经验有效点与反制点初分”。
- 目标情绪：期待前职业选手展示实力 → 第一项成功带来的确认 → 枪械和地图连续反制产生的清醒 → 找到可训练边界后的踏实好奇。
- 主角目标/关键选择：证明自己不是只能讲现代术语；关键选择是在发现本地参数不同后停止强行解释，允许队友把经验拆成“已验证、待验证、作废候选”。
- 章节定位：修炼试错章。
- 本章结构公式：补枪距离成功（给即时反馈）＋枪感失败（拆万能经验）＋木廊声音误判（本地体系反制）＋撤位距离差异（地图规则落地）＋重复训练修正（保留主角能力）＋三栏记录（开启长线验真）。
- 章首钩子：悬念对话开局 — 唐夏站在乙仓门外只问一句：“我进去以后，你到底离我多远？”
- 核心爽点：周野凭职业补枪习惯在第一次交换训练里给出准确跟进距离；随后能够承认其他经验尚未成立，并在第二轮迅速修正，爽点来自职业学习能力而非本地人无知。
- 本章禁止提前释放：不得宣布周野现代体系更先进；不得形成“两项有效、一项作废”的最终结论（留至第16章）；不得让江宁交出重狙；不得推进 `7:5`。
- 契约风险：契约安全；主角必须保有不可替代的职业判断和学习速度，同时由本地角色掌握枪械、材料、地图与声音解释权。

#### 内容概括（五段式）

- 起因：苏禾根据账本后的三条空栏安排白桥货栈训练，要求每个判断至少重复三次并记录条件。
- 发展：唐夏入口与周野补枪的距离测试顺利，白桥第一次从本地回放中看见周野的职业经验可以减少交换空窗。
- 转折：换到赤漆连珠铳长连发、木廊声音和本地图撤位时，周野连续出现压枪、方向和距离误判；江宁与许安分别指出材料和信息条件不同。
- 高潮：周野停止用 AK、现代声音习惯替答案，按本地枪名和明确条件重跑；第二轮虽未完全掌握，却把错误缩小到可复现范围。
- 结尾：苏禾在三栏上分别写下“已验证一项、待验证两项、作废候选一项”，最后一栏暂时不盖章。

#### 情节安排（多线）

- 主线推进：证明周野至少有一项能直接帮助白桥的职业能力，同时建立后续训练必须经过本地复现的硬规则。
- 辅线推进：江宁的瞄具与枪械专业、许安的声音置信度、唐夏的入口条件和夏满的设备稳定性分别获得功能位置。
- 事件线 / 任务线：训练条件锁定 → 补枪距离对照 → 枪械控制对照 → 声音盲测 → 撤位测试 → 条件修正 → 三栏初判。
- 任务卡点（如适用）：周野想证明经验可用 → 单次成功不足以外推，且本地枪械与材料不同 → 重复同一条件、再改变一个变量 → 卡出“经验可拆分验证”的方法 → 以三栏记录收束。
- 感情线 / 关系线：无显性感情线；江宁对周野从“可能只会讲现代名词”变为承认其补枪基础，但仍拒绝他评价望山重狙；唐夏得到一个更可靠的跟进者，尚未获得信息信任。
- 逻辑线：周末杯需要可复核方案 → 先测试最接近周野原位置的补枪习惯 → 成功不能覆盖枪械和地图差异 → 多变量失败被拆开重跑 → 队伍得到有限可用结论和下一步问题。

#### 人物关系和出场顺序

- 出场顺序：唐夏 → 周野 → 苏禾 → 夏满／设备记录 → 江宁 → 许安 → 白桥货栈训练服 → 三栏复盘板。
- 人物关系变化：唐夏与周野由仅在短试配合过，转为拥有第一套可重复的补枪距离；江宁从纯质疑转为“承认一项、其余继续验证”；苏禾开始用证据而非履历分配训练。
- 视角/信息差：周野起初把声音和枪感当成功能相似即可迁移，读者随训练看见他的误判；江宁和许安分别知道材料与环境条件，但不知道周野会多快修正。
