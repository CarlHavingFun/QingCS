# 第002章细纲

### 第2章：同一张表

- 核心事件：周野与夏满用同批普通设备完成枪控、陌生图入口和五人残局三项公平试训，白桥四名既有成员各自保留否决权，最终锁定周野主力、夏满注册替补及后续实战机会，并在午时封表。
- 字数目标：4000字。
- 阶段位置：开篇期第2章；把第1章的“可撤销试报名”转成有标准、有竞争、有复核条件的正式公开赛名单。
- 单元ID/位置：TG-01·七日名单，第2拍“完整试训与名单锁定”。
- 目标情绪：担心故事和性别挤掉正常顺位 → 对同标准竞争的紧张 → 两人各有不可替代价值的踏实 → 名单锁定但信任仍待挣的克制满足。
- 主角目标/关键选择：周野想在午时前进入主力名单；关键选择是接受与夏满同设备、同任务、同复盘和四票否决，不用现代履历要求优待，也不把夏满当成必须击败或羞辱的阻碍。
- 章节定位：高压推进章。
- 本章结构公式：午时倒计时（紧迫）＋试训规则公开（公平契约）＋枪控双向优劣（拆除碾压）＋陌生图入口与五人残局（功能位验真）＋四票条件式表决（程序兑现）＋主力/替补同时落表（关系结算）。
- 章首钩子：倒计时开局 — 距离南城公开赛报名锁定只剩三个时辰，昨夜写下的名字仍可被任何一票划掉。
- 核心爽点：周野不是以绝对枪法压倒夏满，而是在陌生局面里展现补枪和晚段判断；夏满也以本地设备稳定、地图口令与替补适配赢得真实顺位，公平程序让两个人都获得应得位置。
- 本章禁止提前释放：不得让周野赢得长期信任、固定首发权或不可撤换地位；不得把夏满写成主动献位、崇拜男主或吉祥物；不得出现天衡、正式身份、职业赛籍、媒体性别噱头、暧昧。
- 契约风险：契约安全；需保持收益归属清楚——周野获得主力试用位，夏满获得注册替补、继续训练和周末杯等后续实战机会，苏禾保留按成绩调序的经营权。

#### 内容概括（五段式）

- 起因：清晨铜钟报时，韩平提醒午时系统封表；夏满从夜班值守后赶到，要求自己和周野都只看试训结果。
- 发展：苏禾公布三项试训、同批设备抽签和四票否决规则；两人轮换同一套公用终端，枪控项目呈现“周野修正快、夏满初始稳定”的不同优势。
- 转折：陌生图入口与固定五人残局中，夏满的本地口令和设备判断更稳，周野的补枪距离、晚段判断与对失误的即时修正更符合当前主力缺口，结果无法用单一击杀数决定。
- 高潮：江宁、唐夏、许安、苏禾依次给出条件式表决；四人没有行使否决，但把枪械、报点、数据、担保与重新排位条件写进名单附页。
- 结尾：韩平在午时把红印压到报名表右下角；复写联上同时写着“周野：主力试用”和“夏满：注册替补”，夏满把自己的工具袋挂回训练位，没有退场。

#### 情节安排（多线）

- 主线推进：完成进入南城公开赛所需的五主力加一替补名单，解除“第五格仍可随时撤回”的即时悬念。
- 辅线推进：夏满的基层竞争线正式建立；周野的主力位置被定义为可复核、可调整而非永久所有。
- 事件线 / 任务线：倒计时与规则宣读 → 设备抽签 → 枪控测试 → 陌生图入口 → 固定五人残局 → 输入与回放复核 → 四票表决 → 午时封表。
- 任务卡点（如适用）：两人都想获得正式名单位置 → 只有一个当前主力缺口、又不能抹掉合法替补顺位 → 用功能位、地图池与稳定性而非总击杀做分工 → 删掉会令夏满沦为陪跑 → 以五主力加一注册替补收束。
- 感情线 / 关系线：无显性感情线；周野与夏满从潜在位置冲突转为承认对方各自成绩的同队竞争者，关系仍有后续排位压力。
- 逻辑线：第五席空缺且报名将锁 → 同标准三项试训提供可比较证据 → 两人优势落在不同功能位 → 四名既有队员在各自责任范围内不否决 → 苏禾按当前赛事需要分配主力与替补 → 韩平合法封表。

#### 人物关系和出场顺序

- 出场顺序：铜钟／试报名表 → 周野 → 夏满 → 苏禾 → 江宁 → 唐夏 → 许安 → 罗叔 → 韩平 → 三套抽签设备与联会回放。
- 人物关系变化：周野与夏满由未见面的顺位竞争者变为有明确主力/替补关系的同队成员；白桥四人与周野由“允许试训”变为“同意带条件报名”，但仍未交付长期信任。
- 视角/信息差：周野只知道自己昨夜短试与现代经验，不知道夏满在白桥长期积累的稳定记录；读者随他逐项看见夏满价值。苏禾提前知道当前图池更缺补枪与晚段判断，但在测试结束前不公布倾向，避免影响试训。
