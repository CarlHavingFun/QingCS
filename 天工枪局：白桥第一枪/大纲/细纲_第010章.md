# 第010章细纲

### 第10章：补枪距离有效

- 核心事件：苏禾在换边时按地图与职责启用唐夏，夏满带着已完成的公开贡献退出本图；周野与唐夏用经训练校准的补枪距离和交换时序破解急雨队后半场反扑，白桥晋级周末杯决赛，正式回放确认第一项现代职业习惯在本地有效。
- 字数目标：3800字。
- 阶段位置：开篇期第10章；第一批细纲收束，以一个可见竞技结论完成“经验验真”的首次正向反馈，并把更强的本地声音对手推入下一批。
- 单元ID/位置：TG-02·小杯赛验真，第2拍“补枪习惯正式生效与半决赛晋级”。
- 目标情绪：换人选择可能抹掉夏满贡献的担忧 → 六人职责被清楚结算后的稳定 → 急雨反扑下交换链不断的畅快 → 一项有效证据落盘、下一项声音考验逼近的期待。
- 主角目标/关键选择：在新半场与唐夏恢复已训练的入口补枪；关键选择是不把夏满退出解释成失败，也不以一次成功外推全部现代经验，只争取让补枪距离通过正式回放。
- 章节定位：高压推进章＋小高潮结算章。
- 本章结构公式：苏禾换人拍板（队务结算）＋夏满交接贡献（顺位尊严）＋急雨反调补枪（对手适应）＋距离微调（主角学习）＋关键交换链（竞技高潮）＋回放验证与决赛对手（收益＋新钩子）。
- 章首钩子：悬念对话开局 — 苏禾没有先念唐夏的名字，而是问夏满：“这半场你留下了什么，下一张图还要什么？”
- 核心爽点：周野和唐夏的补枪不靠个人连杀，而是在对手主动拉开交换距离后仍用一次微调完成连续空间接管；公开回放给出时间证据，证明“补枪距离有效”而非“周野比本地人先进”。
- 本章禁止提前释放：不得判定第二项现代习惯有效或宣布声音结论；不得赢下周末杯决赛；不得让夏满失去后续实战或训练顺位；不得形成长期主力信任和职业身份。
- 契约风险：契约安全；苏禾拥有换人因果权，夏满保有上半场收益，唐夏保有入口选择，周野保有补枪时序的不可替代贡献。

#### 内容概括（五段式）

- 起因：换边是杯赛唯一常规换人点，苏禾必须在已有节奏与后半场地图职责之间拍板。
- 发展：她依据唐夏更适合守方锚点和近区第一接触启用唐夏；夏满把设备、对手快攻频率和自己留下的公开记录完整交接，不被写成“被换下就失败”。
- 转折：急雨队察觉周野补枪习惯，故意拉开第一人与交换者距离、用低价枪逼他提前移动；第一次配合差点被拆开。
- 高潮：唐夏要求按实战距离重定入口，周野缩短半步并只守第一接触；急雨再次夹击时，唐夏主动进、周野第一时间补，苏禾和其余两人接管空间，白桥拿到赛点并结束比赛。
- 结尾：正式回放把两次交换的时间与距离并列，苏禾在三栏表第一项盖下“有效”；决赛对手檐声队的公开图上，木廊声音数据占满一页。

#### 情节安排（多线）

- 主线推进：白桥晋级周末杯决赛；周野取得第一项由本地公开回放支持的有效证据。
- 辅线推进：六人轮换收益公平结算；急雨队以正常反侦察适应白桥，不作低智陪衬；檐声队的声音体系进入下一阶段。
- 事件线 / 任务线：换边拍板 → 夏满交接 → 唐夏入场 → 急雨反调 → 补枪距离微调 → 关键交换 → 比赛结算 → 正式回放验证 → 决赛签位。
- 任务卡点（如适用）：急雨拉开交换距离破坏白桥训练参数 → 照搬固定距离会继续迟补，过近又会堵唐夏撤位 → 两人根据当场枪线缩短半步并固定第一优先级 → 卡出经验必须随本地条件修正 → 以两次可复现交换收束。
- 感情线 / 关系线：无显性感情线；夏满与唐夏完成不贬低彼此的合法交接；唐夏与周野的关系从训练规则转为公开比赛里可以依赖一轮动作的队友。
- 逻辑线：换边允许一次替换 → 苏禾按地图职责而非偏爱换人 → 急雨根据上半场信息调整 → 固定训练距离受到反制 → 周野与唐夏按条件微调 → 团队赢下后半场 → 回放只验证这一项。

#### 人物关系和出场顺序

- 出场顺序：苏禾 → 夏满 → 唐夏／维修验收回执 → 周野 → 江宁 → 许安 → 急雨队 → 地方裁判与观察者 → 正式回放 → 檐声队签位。
- 人物关系变化：夏满从首发执行者转为拥有可追溯贡献的注册替补，未被抹去；唐夏重新进入场上职责；周野从训练中“补枪距离初步有效”推进到有本地比赛证据支持。
- 视角/信息差：周野能看见苏禾的阵容决定与夏满交接，不能读取两人的内心；急雨队知道上半场补枪链而不知道白桥会当场改距离；白桥尚不了解檐声队完整声音方案。
