# 第006章细纲

### 第6章：第二声必须说出来

- 核心事件：五人入口演练中，周野再次因试图确认第二路线而晚报信息，唐夏中止训练；队伍把看见、听见、推测整合为“事实—不确定—建议”三段式口令，并在重跑中得到第一次有效结果。
- 字数目标：4000字。
- 阶段位置：开篇期第6章；将第1章职业创伤从回忆转成当前关系冲突和可训练规则。
- 单元ID/位置：TG-01·七日名单，第6拍“旧失误复现与信息规则成形”。
- 目标情绪：上一章初验成功后的期待 → 同一缺陷再次伤害入口的恼火与失望 → 冲突被拆成可执行语言的释压 → 重跑成功但问题尚未根治的谨慎信心。
- 主角目标/关键选择：想证明自己能同时处理更多信息；关键选择是在失败后不以现代决赛创伤自辩，承认自己扣住了第二信息，要求按新口令立刻重跑。
- 章节定位：高压关系章＋修炼试错章。
- 本章结构公式：完整入口条件（建立预期）＋第二信息出现（旧缺陷触发）＋唐夏倒下与训练失败（关系爆点）＋当面对质（情绪结算）＋三段式口令共建（规则产出）＋即时重跑（小兑现）。
- 章首钩子：未完成动作开局 — 唐夏已经把拇指敲上护腕，周野却在她问“第二条线呢”时慢了半拍。
- 核心爽点：冲突没有靠道歉或队长压服解决；许安提供信息分级、唐夏提出入口需要、苏禾固定权限、周野完成重跑，规则由队伍共同生成并当场生效。
- 本章禁止提前释放：不得让周野彻底克服半拍问题；不得完成 Major 同构回收（留至第32章）；不得让唐夏无条件信任周野；不得将新口令写成周野对本地队伍的现代教学。
- 契约风险：契约安全；若三段式规则被写成男主发明并单向传授会损害许安、唐夏与苏禾的代理权，正文必须按共同建构呈现。

#### 内容概括（五段式）

- 起因：唐夏要求把木廊第二声音放进五人入口演练，苏禾给出烟闪、补枪和撤退条件，检验周野能否在行动中使用上一章结论。
- 发展：第二路线只出现一组不完整脚步，周野为了判断真假没有立即开口，准星和注意力也再次离开唐夏的第一接触线。
- 转折：唐夏在入口倒下，周野迟到的补枪又使下一人完成交换；她主动叫停训练，指出问题不在没听准，而在队伍直到她死后才知道他听见过什么。
- 高潮：许安把信息拆成事实、不确定和建议，唐夏补充入口所需时限，苏禾明确最近信息人可以先报后证；周野不长篇道歉，只要求照相同条件重跑。
- 结尾：第二遍里周野及时说出“右廊一声，不确定远近，建议先打近点”，唐夏据此改变进入角度；复盘板上留下三列尚未擦掉的口令。

#### 情节安排（多线）

- 主线推进：建立白桥第一条全队信息规则，为周末杯和南城公开赛的核心回收提供可执行基础。
- 辅线推进：唐夏的入口拒绝权萌芽；许安的信息专业从性格标签变成队内制度；苏禾开始允许近场信息先进入决策。
- 事件线 / 任务线：入口准备 → 第二声音出现 → 晚报与失败 → 唐夏叫停 → 事实复盘 → 三段式口令 → 同条件重跑 → 规则上板。
- 任务卡点（如适用）：队伍需要使用不完整信息 → 周野怕误报、许安过去又因来源问题过度谨慎 → 区分事实、不确定与建议而不是二选一“报或不报” → 卡出全队口令与权限 → 以重跑验证收束。
- 感情线 / 关系线：无显性感情线；唐夏与周野由初步补枪配合转为公开冲突，再转为拥有一条可以追责的共同口令，信任只恢复到“愿意再跑一遍”。
- 逻辑线：实战加入不完整第二信息 → 周野旧缺陷复现 → 唐夏承担入口后果 → 队伍确认问题是信息未共享而非判断错误本身 → 三段式口令降低误报与迟报的二选一压力 → 重跑证明规则可用。

#### 人物关系和出场顺序

- 出场顺序：唐夏 → 周野 → 苏禾 → 江宁 → 许安 → 夏满／记录终端 → 白桥货栈训练服 → 三列复盘板。
- 人物关系变化：唐夏与周野从“补枪距离初步有效”退回到“信息未交付会让入口条件失效”，再建立可复核的最低合作；许安从旁观记录者变成信息规则的主要设计者。
- 视角/信息差：周野知道自己听见第二声却想再确认，唐夏只知道队友没有及时报；冲突后两边事实才对齐。读者不读取唐夏内心，只从她叫停、摘耳罩和复盘用词判断态度。
