# 第003章细纲

### 第3章：七天不是身份

- 核心事件：周野在报名锁定后的半天里逐项办理食宿、指定区域、临时账号镜像、奖金冻结和生活分区，第一次把“七日客籍”理解成一套每天都会执行的现实限制。
- 字数目标：3600字。
- 阶段位置：开篇期第3章；高潮后短暂降压，用生活和程序把身份压力从纸面落到身体与日程。
- 单元ID/位置：TG-01·七日名单，第3拍“生活边界落地”。
- 目标情绪：名单锁定后的短暂轻松 → 每一步都需要担保和记录的局促 → 边界清楚反而带来的有限安全感 → 对真实账目将被打开的期待。
- 主角目标/关键选择：弄清自己今天能去哪、能用什么、住在哪里；关键选择是把边界当作可执行条件而非羞辱，不试图借现代物证绕过本地调查。
- 章节定位：低压生活章＋信息整理章。
- 本章结构公式：客籍卡七格倒计时（身份具象）＋食宿与区域登记（生存落地）＋账号和奖金限制（职业落差）＋生活分区协商（性别边界）＋白桥工作日常（群像落地）＋账本邀请（承接下一章）。
- 章首钩子：未完成动作开局 — 周野刚把报名回执折好，韩平便按住那张七格客籍卡，提醒他第一格从昨夜已经开始计算。
- 核心爽点：无显性爽点；功能性满足来自所有人用具体安排解决尴尬，不拿周野的男性身份制造福利、误闯或集体反应。
- 本章禁止提前释放：不得延长客籍、解冻奖金、建立正式账号或长期住宿；不得出现暧昧、更衣误闯、身体展示；不得让现代手机接入天工网络。
- 契约风险：契约安全；本章允许低压，但每项规则必须通过物件、动作和谁承担责任来表演，不能变成制度说明书。

#### 内容概括（五段式）

- 起因：韩平完成名单封表后，没有把报名回执当身份证，而是要求周野逐项登记七日客籍的活动范围和每日复核。
- 发展：方婶按现有床位、饭票和公共区域安排食宿；罗叔划出可使用的普通终端；周野的现代手机、奖牌与行李分别登记但不被没收。
- 转折：临时账号镜像可以进入普通训练服，却不能领取或使用个人奖金，报名所得也继续冻结；“能参赛”与“有身份”被彻底拆开。
- 高潮：住宿、更衣、洗浴和设备边界被当面说清，周野没有用玩笑缓解，也没有把队友当现代兄弟替代；苏禾只问每个人的时间是否可执行。
- 结尾：周野拿到一把只开男客宿舍和公共区域的铜钥匙；苏禾在柜台合上客籍册，又把另一本带红圈的账本推到五人面前。

#### 情节安排（多线）

- 主线推进：将周野从“已报名”推进到“可以在指定条件下生活和训练”，为后续七日倒计时建立可见基线。
- 辅线推进：方婶、罗叔、韩平作为基层执行者进入人物网络；现代手机与奖牌继续保持未被本地系统验证的物证状态。
- 事件线 / 任务线：客籍卡启用 → 活动区标注 → 食宿登记 → 设备权限 → 临时账号镜像 → 奖金冻结 → 生活分区 → 第一次日常报到 → 账本转场。
- 任务卡点（如适用）：周野要开训练账号 → 没有本地实名身份和结算账户 → 只能由白桥担保临时镜像、权限限于普通终端且收益冻结 → 删掉会让身份压力失真 → 以可训练但不能支取结算收束。
- 感情线 / 关系线：无显性感情线；周野与白桥众人从比赛名单关系扩展为共享场馆、但边界明确的临时生活关系。
- 逻辑线：名单封表不等于身份成立 → 联会必须限定活动、收益和设备权限 → 白桥为每项权限承担责任 → 周野获得有限安全与训练入口 → 资源成本转入下一章账本。

#### 人物关系和出场顺序

- 出场顺序：韩平／七格客籍卡 → 周野 → 方婶 → 罗叔 → 苏禾 → 夏满 → 江宁 → 唐夏 → 许安 → 铜钥匙／临时账号界面／账本。
- 人物关系变化：方婶和罗叔由第一夜见证人转为食宿与设备执行者；夏满与周野开始共享训练资源；苏禾与周野的关系由报名负责人进一步变成具体担保责任人。
- 视角/信息差：周野不知道白桥为担保具体增加多少成本，只能从饭票、钥匙权限和苏禾签字次数推测；读者同样不进入苏禾内心，完整数字留到第4章。
