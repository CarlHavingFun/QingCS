# 第004章细纲

### 第4章：把账摊开

- 核心事件：苏禾把服务器债、员工工资、重狙租赁、队员本职班次和南城公开赛首轮出局后果全部摊给白桥队，五名主力在知道真实机会成本后决定参加枪馆周末杯，以小赛换公开记录和有限训练资源。
- 字数目标：3800字。
- 阶段位置：开篇期第4章；把“必须赢”的抽象压力转为每个人看得见、可以提出异议的三本账。
- 单元ID/位置：TG-01·七日名单，第4拍“账本公开与共同选择”。
- 目标情绪：对欠账规模的压迫和不适 → 各自工作代价被看见后的沉重 → 从被通知必须赢到共同决定如何花最后训练时间的有限掌控感。
- 主角目标/关键选择：弄清白桥为何愿意担保自己、输掉比赛会发生什么；关键选择是先听完本地账目，不用被冻结的奖金或现代履历许诺自己无法支付的东西。
- 章节定位：推进章＋关系回收章。
- 本章结构公式：账本开页（压力具象）＋五类成本逐人归属（群像因果）＋首轮出局条款（卷级赌注）＋周末杯成本收益比较（可执行选择）＋逐人确认（共同责任）＋红圈赛程（下章训练目标）。
- 章首钩子：悬念对话开局 — 苏禾先问“看见这些数以后，谁还要报名”，再把账本推到五个人都够得到的位置。
- 核心爽点：无碾压式爽点；关系兑现是苏禾第一次停止独自背账，允许队友在知道代价后参与决定，队伍从听命名单向共同承担迈一步。
- 本章禁止提前释放：不得清偿贷款、获得长期赞助、延长服务器或客籍；不得把周末杯写成决定枪馆存亡的大赛；不得让周野用现代资产解决本地债务。
- 契约风险：契约安全；必须让选择来自具体账目与各人自愿确认，不能用热血口号替代数字和执行后果。

#### 内容概括（五段式）

- 起因：名单锁定后，苏禾兑现“先把话说清楚”，关闭前厅一角，把白桥的经营账和公开赛条款同时摊开。
- 发展：服务器欠款、员工工资、训练房租、江宁重狙租赁、唐夏和许安损失的工作时数，以及周野食宿和担保成本逐项落到具体人。
- 转折：众人发现南城公开赛进入前四才触发资源，而首轮出局会让五项条件同时恶化；此前“先打再说”的轻松空间消失。
- 高潮：周末杯被提出为一次有机会成本的小型验证——会占用唯一完整合练时段，却能换公开回放、服务器时数、维修券和餐券；五人逐个确认愿意承担。
- 结尾：苏禾用红笔圈住周末杯报名截止和第二天的训练时段，周野看见她没有把自己的名字写在“救枪馆”后面，只写在“需验证”一栏。

#### 情节安排（多线）

- 主线推进：明确周末杯是南城公开赛前的验证场，并建立参加它的资源理由。
- 辅线推进：苏禾独自背账的缺点开始松动；江宁、唐夏、许安的个人工作和资源债第一次同时进入队内公开层。
- 事件线 / 任务线：开账 → 逐项核对 → 首轮出局条款 → 周末杯方案 → 成本收益比较 → 逐人确认 → 训练时间锁定。
- 任务卡点（如适用）：白桥需要公开比赛记录却只有一个完整合练时段 → 参加周末杯会压缩训练并损失半日工作收益 → 小赛奖励无法救枪馆，但能提供下一轮所需回放和资源 → 删掉会让周末杯成为无功能插曲 → 以全员确认参加收束。
- 感情线 / 关系线：无显性感情线；苏禾与队员由“经营者通知结果”转为“经营者公开条件、队员有权反对”，周野不因临时客籍被排除在成本讨论之外。
- 逻辑线：枪馆担保和参赛都消耗资源 → 不公开数字就无法合理分配枪械、班次和训练 → 账本公开让不同风险进入同一决策 → 周末杯成为可承担的验证投资 → 第5章必须先验证哪些经验能用。

#### 人物关系和出场顺序

- 出场顺序：苏禾／经营账本 → 周野 → 江宁 → 唐夏 → 许安 → 夏满 → 方婶／罗叔的工资与维护条目 → 南城公开赛条款 → 周末杯报名页。
- 人物关系变化：苏禾与四名长期成员由她替所有人背风险，转为队员首次看到完整代价；周野由只接受担保的人，转为需要对新增食宿、设备和训练成本负责的参赛者。
- 视角/信息差：周野只能从账面和众人反应理解旧债，不知道苏禾此前独自承受时的内心；江宁等人也第一次看到部分此前只由苏禾掌握的总额。
