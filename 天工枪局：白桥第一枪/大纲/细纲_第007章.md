# 第007章细纲

### 第7章：只确认能复查

- 核心事件：纪秋受南城枪馆联会委托检查第一夜的设备异常，将白桥本机、柜台备份和联会接收件逐项封存，只确认现有记录可以继续复查，并安排异地只读副本核验，不增加任何关于 `7:5` 来源的结论。
- 字数目标：3600字。
- 阶段位置：开篇期第7章；在周末杯前完成异常证据保全，让悬疑线支付程序进展而不抢走竞技主线。
- 单元ID/位置：TG-01·七日名单，第7拍“异常封存，不增结论”。
- 目标情绪：训练规则初成后的短暂稳定 → 专业检查带来的答案期待 → 所有结论都被证据边界压回的克制焦躁 → 至少没有让记录被随意改写的有限安心。
- 主角目标/关键选择：想从纪秋处确认自己是否真的跨越世界；关键选择是把手机时间、记忆和所见按事实提交，并接受她只能封存记录、不能替他证明穿越。
- 章节定位：信息整理章＋悬念保全章。
- 本章结构公式：联会委托到场（新专业角色）＋三份材料盘点（证据链）＋见证人逐项陈述（事实/推测分开）＋校验对照（建立可复查性）＋拒绝超额结论（悬念克制）＋异地封包（长线钩子）。
- 章首钩子：悬念对话开局 — 纪秋进门后的第一句话不是问周野来自哪里，而是问“哪一份记录从落盘以后没人再打开过”。
- 核心爽点：无显性爽点；满足点在纪秋不把异常神秘化，也不因合同压力草率否定，而是让每份证据有编号、保管人和下一次可复核的去向。
- 本章禁止提前释放：`7:5` 不得出现新的异地一致性、来源、目的或穿越因果；不得让纪秋证明平行宇宙、读取设备之外的信息或解决周野身份；不得触发天衡或高权限服务器。
- 契约风险：契约安全；正文必须明确“封存和可复查”不是“异常已被独立证实”，避免提前消费第34章唯一证据进展。

#### 内容概括（五段式）

- 起因：联会根据第一夜报告派纪秋到白桥检查，周末杯前若证据链混乱，枪馆既可能失去报名信用，也可能无法再说明周野落地经过。
- 发展：纪秋先核对本机、柜台和联会接收件的创建时间、保管人和打开记录，再分别听罗叔、许安与周野陈述。
- 转折：三份材料都保存了第一夜已有的断帧和比分画面，但它们来自同一原始链，不能被当作三次独立异常；周野期待的“外部证明”没有出现。
- 高潮：纪秋完成校验与封签，明确只确认材料可供以后复查，不确认断帧成因、比分意义或周野来历；她拒绝让任何人把副本发到公共群组换关注。
- 结尾：一份只读封包由联会专线送往异地镜像库，火漆封口上只有编号和接收时限，没有答案。

#### 情节安排（多线）

- 主线推进：保护白桥报名信用和异常证据链，使竞技线不被“来源不明文件”反噬；不改变当前赛事资格。
- 辅线推进：纪秋以地图工程师和证据流程顾问身份登场；许安的信息合法性议题获得未来合作入口。
- 事件线 / 任务线：委托文件核对 → 原件与副本盘点 → 见证人陈述 → 时间与校验值对照 → 结论边界 → 三份封存 → 异地核验发出。
- 任务卡点（如适用）：周野想取得外部证明 → 三份材料同源、手机录像又无画面 → 纪秋只能保全而不能把同源副本当独立证据 → 卡出第34章异地只读副本的长期等待 → 以封包发出收束。
- 感情线 / 关系线：无显性感情线；周野与纪秋建立“她只对能复现的事实负责”的专业关系；苏禾对纪秋由外部检查者转为可能的训练流程顾问，尚未形成合同。
- 逻辑线：异常已影响设备和报名信用 → 必须在继续使用设备前建立保管链 → 同源三份材料只能证明记录保存，不能证明三次独立发生 → 异地只读核验成为唯一合规下一步 → 竞技主线继续。

#### 人物关系和出场顺序

- 出场顺序：纪秋／联会委托单 → 苏禾 → 罗叔 → 许安 → 周野 → 韩平的第一夜登记件 → 本机、柜台、联会三份记录 → 封签与异地接收回执。
- 人物关系变化：纪秋与白桥由检查方和被检查方转为边界明确的临时协作；周野对纪秋由“可能给答案的人”转为“只肯保存问题的人”。
- 视角/信息差：周野知道现代回放也出现过异常，但手机无法记录；纪秋只掌握被提交的设备材料，不知道周野记忆是否准确。读者与周野都不会提前看到异地镜像结果。
