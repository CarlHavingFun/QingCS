# 第009章细纲

### 第9章：六个人的第一局

- 核心事件：周末杯半决赛上半场，夏满与周野同场面对桥南急雨队，分别以本地设备判断和及时交出的低置信第二线守住关键入口，让六人名单第一次在公开记录里证明替补与主力可以同时产生因果。
- 字数目标：4000字。
- 阶段位置：开篇期第9章，卷尺度1/4关键点；由内部验真进入第一场有裁判、有对手、有公开回放的比赛。
- 单元ID/位置：TG-02·小杯赛验真，第1拍“替补合法上场与六人体系公开验证”。
- 目标情绪：第一次公开比赛的紧张和被审视 → 急雨快攻压迫下的忙乱 → 新搭档各用专长救回选择的振奋 → 上半场只建立微弱优势、仍需换人的持续期待。
- 主角目标/关键选择：帮助当前五人阵容活过急雨队前期快攻；关键选择是不把夏满当唐夏的临时替代品，按她的速度、设备判断和本地口令行动，并在第二线尚不确定时及时报出。
- 章节定位：高压推进章。
- 本章结构公式：民间赛台与公开核验（舞台升级）＋急雨低价快攻（对手独立打法）＋设备/信息双卡点（六人功能）＋及时低置信报点（规则首验）＋关键入口交换（小高潮）＋换边与唐夏回执（下一章轮换）。
- 章首钩子：反差场景 — 没有 Major 的两万观众，只有贴着桌边的几十个人和一名地方观察者，但周野的本地名字第一次会被写进公开击杀与输入记录。
- 核心爽点：夏满先发现普通终端输入波动、避免被判个人失误；周野随后以“事实—不确定—建议”让她保有入口选择，两人的贡献在同一关键回合里分别可见。
- 本章禁止提前释放：不得完成半决赛晋级（留至第10章）；不得让唐夏被永久替换；不得把急雨队写成嘲笑男主的无脑陪衬；不得让周野凭个人击杀掩盖夏满、苏禾、江宁和许安的空间与信息。
- 契约风险：契约安全；1/4兑现的所有权属于六人体系，周野保有及时信息和补枪的因果权，夏满保有设备与入口贡献。

#### 内容概括（五段式）

- 起因：白桥在普通周末杯赛台接受首发、账号、设备和替补名单核验，急雨队为争取共同服务器时段主动选择小票号快攻图。
- 发展：急雨队用低价短铳和连续夹击抢前期兵筹，夏满第一次公开上场出现操作波动，却判断是输入线而非紧张失误并及时申请检查。
- 转折：设备确认无违规后比赛继续；急雨队制造一前一后的声音，周野不等自己确认第二人，按三段式把低置信信息交给夏满和苏禾。
- 高潮：夏满改变进入角度，周野完成近点交换，许安拖住后路、江宁封长线，白桥拿下关键局并在上半场建立一局优势。
- 结尾：地方观察者的记录同时写下夏满的设备申请与周野的信息时间；换边提示响起，唐夏带着刚盖好的维修验收回执出现在裁判席外。

#### 情节安排（多线）

- 主线推进：周末杯正式开打；“主力＋替补”“事实—不确定—建议”两项内部规则第一次接受公开记录验证。
- 辅线推进：急雨队获得独立利益——队员夜班不一，必须靠杯赛服务器券保住共同训练；她们的快攻来自时间条件而非愚蠢。
- 事件线 / 任务线：赛台核验 → 对手选图与前期经济 → 输入波动申请 → 快攻加压 → 低置信报点 → 关键交换 → 上半场结算 → 合规换人变量出现。
- 任务卡点（如适用）：夏满操作出现波动 → 若继续可能被当个人失误或设备争议，停太久又会丢节奏 → 她依据登记主动申请检查并由裁判确认 → 卡出替补的设备专业与合法程序 → 以继续比赛并留下记录收束。
- 感情线 / 关系线：无显性感情线；周野与夏满由训练搭档转为能在公开压力下互相交付信息与空间的队友；信任限定在这一套动作，不扩展成长期保证。
- 逻辑线：临时阵容必须通过公开设备核验 → 急雨快攻压缩沟通时间 → 夏满设备判断保住合法状态 → 周野及时交出不确定信息 → 五人共同拿局 → 唐夏合规到场触发下一阶段阵容选择。

#### 人物关系和出场顺序

- 出场顺序：周末杯赛台／地方裁判与观察者 → 周野 → 夏满 → 苏禾 → 江宁 → 许安 → 桥南急雨队 → 罗叔／设备检查 → 唐夏／维修验收回执。
- 人物关系变化：夏满由内部认可的注册替补变成有公开比赛贡献的队员；周野由她的位置竞争者变成第一次正式配合的补枪位；苏禾开始拥有六人轮换的真实选择。
- 视角/信息差：周野不知道急雨队的完整战术，只能从公开记录和当场经济推测；急雨队看过白桥有限短试数据，却不知道三段式口令已经形成。读者只随周野看到地方观察者公开的信息。

#### 结尾设定和钩子

- 结尾设定：换边铜钟响起，唐夏的验收回执被裁判夹到第六人名单旁；夏满仍坐在设备前等苏禾拍板。未解决问题是是否换人、换人后补枪距离能否继续有效。
- 章尾钩子：两难抉择 — 保留已经进入节奏的夏满，或在唯一合规换人点启用更熟悉入口的唐夏，期待度：强；第10章由苏禾拍板并验证补枪距离。
