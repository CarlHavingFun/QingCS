# 第一卷·白桥七日

## 卷级信息

- 章节范围：第1—34章。
- 故事时间：第一天深夜至第七日深夜。
- 核心事件：周野以七日临时客籍加入白桥的公平试训，随队完成周末杯验真和南城公开赛前两轮，最终进入前四。
- 卷契约：周野的职业经验必须经过本地事实验证；白桥的胜利必须由六人体系与每名成员的职业选择共同促成。
- 主推线：白桥服务器与周野临时身份是否能继续。
- 战果线：队伍协作、地图适应、信息分级、人物选择与`7:5`证据保全。
- 终局底牌边界：第一卷不得解释穿越，不得让周野通过天衡或取得正式身份，不得进入乙级以上赛场。
- 总体风险：契约安全；最大风险是用男性话题、旧职业履历或机构认可替代队伍因果权。

## 关键坐标

| 坐标 | 章节 | 功能 |
|---|---:|---|
| 1/4 | 第9章 | 夏满不因周野出现而消失；六人体系第一次通过公开比赛 |
| 中点 | 第17章 | 白桥拒绝用男性包装和全量数据换设备，确立职业伦理 |
| 3/4 | 第26章 | 前八无保底，四分之一决赛与客籍截止重合 |
| 高潮 | 第31—32章 | 江宁、唐夏、许安、苏禾与周野以具体回合动作共同结算 |
| 结尾 | 第33—34章 | 条款收益到账；周野只获续审受理；`7:5`只增一层证据 |

## TG-01·七日名单（第1—8章）

- 单元位置：卷首建置。
- 单元承诺：周野在夏满同场、同设备、同地图、同投票标准下取得有条件主力位置。
- 核心阻碍：履历不可验证；夏满有合法顺位；周野仍习惯把第二信息留在脑中。
- 节拍：穿越与初试 → 完整试训 → 生活边界 → 账本公开 → 经验反制 → 信息冲突 → 异常封存 → 替补先上。
- 关键选择：周野接受公平标准；苏禾公开账本与否决权；夏满不退让也不阻拦试训。
- 兑现：周野主力、夏满注册替补；形成“事实—不确定—建议”口令。
- 未兑现：长期信任、正式身份、职业能力认证。
- 单元钩子：周末杯将第一次留下可查的公开比赛记录。
- 风险等级：契约安全。

### 章节卡

1. 第1章：完成穿越、普通终端初试、七日客籍和可撤销试报名；只给一次试训机会。
2. 第2章：同一批普通设备完成枪控、陌生图入口、五人残局三项试训；周野主力、夏满替补，午时封表。
3. 第3章：食宿、指定区域、账号镜像、奖金冻结与男女生活边界落地。
4. 第4章：苏禾公开服务器债、重狙租金、队员班次与首轮出局后果。
5. 第5章：补枪距离有效，但枪感、声音与撤位规则不能直接平移。
6. 第6章：周野晚报第二路线，队伍建立三段式信息口令。
7. 第7章：纪秋依法封存回放，只确认异常可复查，安排异地核验。
8. 第8章：唐夏先完成本职安全验收，夏满按注册顺位首发周末杯。

## TG-02·小杯赛验真（第9—16章）

- 单元位置：卷前段第一次公开验证。
- 单元承诺：现代职业经验有用，但只在本地训练与正式回放中被证明后有用。
- 核心阻碍：木廊回声、枪械后坐、梁架投掷、兼职班次和六人轮换。
- 节拍：替补合法上场 → 补枪习惯生效 → 声音反制 → 投掷作废 → 临场修正 → 小杯赛获胜 → 奖励落账 → 阶段判定。
- 兑现：第一份本地正式比赛记录；六小时高质量服务器；基础维修券；两项习惯有效、一项作废。
- 未兑现：奖励不延长客籍，也不足以解决枪馆经营。
- 单元钩子：票盟愿意给设备，却只购买“神秘男枪手”的噱头与数据。
- 风险等级：契约安全。

### 章节卡

9. 第9章：夏满与周野同场，各自贡献不可替代的信息。
10. 第10章：补枪距离和交换时序经正式回放验证，白桥晋级。
11. 第11章：檐声队用木廊回声与延迟第二人打穿白桥。
12. 第12章：现代投掷落点撞上梁架，周野主动废案。
13. 第13章：苏禾采用最近信息人的判断，白桥一局险胜。
14. 第14章：奖励只够六小时服务器与一次维修，江宁公开租赁条款。
15. 第15章：许安与纪秋建立公开样本、匿名测试和隐私隔离链。
16. 第16章：纪秋判定两项有效、一项作废，公开赛签位公布。

## TG-03·名单之外的价格（第17—25章）

- 单元位置：卷中点与公开赛首轮。
- 单元承诺：白桥不出售队友贡献和数据边界换活路，且必须用公开赛成绩证明拒绝不是空话。
- 核心阻碍：设备与道具预算不足；折柳队针对公开录像反侦察；周野仍可能因第二信息迟疑。
- 关键选择：苏禾拒绝只署周野姓名的合同；唐夏在条件不足时叫停入口；周野不以续审为由逼队友接受授权。
- 兑现：拒绝不平等赞助；两图累计16:15进入前八。
- 未兑现：前八没有服务器、续审或职业邀请；现实赌注全部保留。
- 单元钩子：四分之一决赛与七日客籍截止落在同一天。
- 风险等级：契约安全。

### 章节卡

17. 第17章：全队拒绝男性噱头、单人署名和全量数据授权。
18. 第18章：折柳队依据公开录像做正常反侦察。
19. 第19章：唐夏拒绝烟闪不足的入口，苏禾承认近场停止权。
20. 第20章：折柳队避开正面交换，连续吃掉白桥经济。
21. 第21章：江宁保重狙错过重夺，白桥7:9输第一图。
22. 第22章：江宁改用轻狙，节省兵筹补足入口道具。
23. 第23章：许安报低置信侧线，周野补建议，苏禾及时转点。
24. 第24章：白桥9:6、累计16:15进前八。
25. 第25章：前八不触发保底，客籍只余一天，异地核验未完成。

## TG-04·前四线（第26—34章）

- 单元位置：卷末高潮与结算。
- 单元承诺：每条前段人物债都必须在关键回合变成可见选择。
- 核心阻碍：长缆队长线狙击与纪律保枪；白桥无新枪可买；客籍与五项资源同时到期。
- 关键选择：江宁放弃保枪；唐夏在条件完整后主动入口；苏禾授权最近信息人；周野及时交出第二信息。
- 兑现：白桥第二图9:5、累计15:14进入前四；服务器、维修、租赁、城区职业预选邀请和一个续审名额按条款执行。
- 边界：周野只获续审受理资格；奖金继续冻结；白桥仍有贷款，尚非职业俱乐部。
- 新开环：异地只读副本保留相同`7:5`异常，证据离开白桥机柜，结论仍未知。
- 风险等级：契约安全。

### 章节卡

26. 第26章：四分之一决赛与客籍截止同日，输掉将使五项资源失效。
27. 第27章：江宁公开重狙租金、保险与保枪条件。

31. 第31章：江宁放下望山重狙，用步枪和道具完成重夺。
32. 第32章：唐夏主动入口，周野及时报告第二人并补枪，白桥进入前四。
33. 第33章：联会执行收益，苏禾拒绝出售邀请，决定注册城区预选队。
34. 第34章：周野递交续审，纪秋签短约，夏满获青训试位；异地副本确认同一异常。

## 终局反向校验

- 因果权：第32章的胜利由五名在场队员的选择与夏满此前保住的合法设备共同促成，不能由裁判、机构或巧合赠送。
- 结算权：第33—34章逐条执行早已公开的条款，不额外赠送正式身份或职业资格。
- 期待债：Major第二脚步在第32章完成行为层回收；`7:5`只支付证据层利息，不支付真相。
- 角色尊严：夏满的顺位、唐夏的停止权、许安的信息置信度、江宁的资源选择、苏禾的经营权都必须独立成立。
- 换书债：第一部始终停留在白桥民间职业生态；任何宫廷、国家队或天衡线索只能留在远期设定，不得进入正文推进。
