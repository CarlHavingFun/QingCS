## 场景统一边界

白桥必须是：

- 南城窄长民间枪馆；
- 旧普通终端和修补线材；
- 青砖、深漆木、黄铜走线槽、黑化钢；
- 雨夜木桥、货栈与小额经营压力；
- 现代电子设备真实可工作。

白桥不得是：

- 国家队训练院；
- 豪华宫廷电竞殿；
- 仙侠洞府；
- 赛博霓虹基地；
- 无使用痕迹的样板间。
