# 《天工枪局：白桥第一枪》漫剧验收基准

## 结构

- [ ] 第一章样片总时长为 70 秒；
- [ ] 穿越前不超过 8 秒；
- [ ] 穿越后不少于 62 秒；
- [ ] 现代段没有独立团队复盘和长颁奖；
- [ ] 白桥枪馆完整显现是第一场主要视觉高潮；
- [ ] 结尾是七日担保和可撤销第五格，不是正式首发或国家队身份。

## 人物

- [ ] 周野始终为同一二十四岁男性、同一张脸和同一身体；
- [ ] 右腕黑色护带、现代队服和亚军奖牌跨界连续；
- [ ] 苏禾、江宁、唐夏、许安与正式三视图一致；
- [ ] 四人功能清楚，且不围绕男主做后宫构图；
- [ ] 不出现现代队友在大曜的同名、换脸、性转或位置镜像。

## 白桥场景

- [ ] 设备间和主厅狭窄、旧、有修补和经营痕迹；
- [ ] 电子设备和现代枪械结构真实可工作；
- [ ] 青砖、深漆木、黄铜走线槽和黑化钢稳定；
- [ ] 不生成豪华宫廷、国家队基地、仙侠或蒸汽朋克空间；
- [ ] 雨夜木桥与货船建立南城生活感。

## 战术因果

- [ ] 第一遍先看到震声雷撞梁，再看到唐夏被迫进入；
- [ ] 第一遍先看到周野准星离开近点，再看到唐夏倒下；
- [ ] 第二遍先报告右廊不确定信息，准星仍留近点；
- [ ] 第二遍完成近点补枪后，必须等脚步确认再转右廊；
- [ ] 成功来自信息和动作修正，不使用外挂、觉醒或属性提升。
