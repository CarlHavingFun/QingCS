## 2. MiniMax 生产规则

- 人物图使用 `mmx image generate`，同一角色始终传入对应 `--subject-ref`；
- H3 视频始终显式使用 `--model MiniMax-H3`；
- 多人物场景优先先生成一张通过的合成关键帧，再以该图作为 `--image` 首帧；
- 一个 H3 片段控制在 4—15 秒；70 秒成片拆为 8 段生成后剪辑；
- 不在生成请求中写入真实 API key；
- 图片和视频中的精确文字留空，统一后期合成；
- H3 参考模式和首帧模式不可混用；
- 已产生任务 ID 后禁止因等待中断而重复提交付费任务。
