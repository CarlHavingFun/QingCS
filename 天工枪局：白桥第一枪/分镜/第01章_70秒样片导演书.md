# 第一章《输掉 Major 后，我从民间赛重新开始》70 秒样片导演书

## 1. 制作目标

用 70 秒让观众完成一次明确的世界转移：

```text
现代职业失误
→ 异常坠落
→ 白桥陌生规则
→ 第一次失败
→ 第二次修正
→ 获得七日机会
```

现代段只提供因果证据，不承担主要观赏篇幅。白桥段负责人物关系、空间质感、游戏差异和第一章落点。

## 2. 输出规格

- 画幅：16:9
- 成片：1920×1080 / 24 fps
- 总时长：70 秒
- 场景：8 段
- 镜头：16 个
- 穿越前：8 秒
- 穿越后：62 秒

## 3. 总体导演约束

### 三层表现

- `REALITY`：身体、键鼠、耳机、机柜、账本、客籍、食宿和现实后果。
- `GAME`：白桥货栈数字战场、赤漆连珠铳、震声雷、准星、脚步与补枪。
- `OBSERVER`：只显示合法记录、人数、比分、输入曲线和简化回放。

白桥私训没有正式解说、豪华转播台或完整观议司包装。

### 色彩

- 现代：冷蓝、黑灰、屏幕白光，快速、压缩、近乎证据片段。
- 白桥：青砖、深漆木、黑化钢、黄铜、暖灰灯、冷蓝机柜灯与雨夜青色。

### 连续物

周野穿越前后始终保持：

- 同一张脸；
- 同一具二十四岁男性身体；
- 同一套现代深色队服；
- 右腕黑色护带；
- 亚军奖牌。

### 文字

比分、姓名、客籍表、报名表、终端 UI 和枪名均预留后期安全区。生成图不承担精确可读文字。

## 5. 场景导演书

### S01_MAJOR_EVIDENCE

```text
SCENE_ID: S01_MAJOR_EVIDENCE
DURATION: 4.0s
LAYER: REALITY → GAME → OBSERVER
LOCATION: 上海 Major 选手席与 A 点残局
CHARACTERS: 周野、赵雨；其余队友只作快速位置证据
TACTICAL_FACT: 赵雨准备接烟边，周野听见第二脚步后把准星从近点补枪线移开；赵雨先倒，拆包完成，比分落到 16:19
CAMERA: 鼠标手极近景 → 第一人称准星离位 → 亚军奖牌落进掌心
MOVEMENT: 不完整复原回合，只保留“该补近点—却看深处—错过半拍”三段因果
SOUND_PRIORITY: 赵雨“你跟着补” > 第二脚步 > 拆包结束音 > 欢呼
PROP_CONTINUITY: 右腕护带、现代队服、亚军奖牌
UI_SAFE_AREA: 比分和结果置于画面上缘，后期合成
REALITY_RETURN: 最后一帧落在周野没有按响的鼠标和奖牌冷光
NEXT_CUT: 拆包音延长，转成异常钟声
```

NEXT_CUT: 同一金属声落在白桥青砖地面

## 6. 验收结论

成片必须让未读正文的观众准确复述：

1. 周野因多看第二条线错过补枪；
2. 他带着自己的身体和奖牌穿入白桥；
3. 白桥是有现代设备和成熟规则的基层枪馆；
4. 四名队友各自拥有权限和现实压力；
5. 周野第一遍失败，第二遍靠及时信息和正确补枪修正；
6. 他最终只获得七日担保和可撤销的第五格。
