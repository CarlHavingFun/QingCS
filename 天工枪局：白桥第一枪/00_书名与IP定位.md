# 书名与 IP 定位

## 正式书名

**《天工枪局：白桥第一枪》**

- **主品牌：天工枪局**——平行大曜的原创职业枪战游戏，也是小说、漫剧、动画、视觉设定与未来游戏概念的长期 IP 名；
- **第一部副标题：白桥第一枪**——强调周野失去现代职业身份后，从民间枪馆重新拿起第一把枪；
- **平台短名：天工枪局**；
- **英文内部索引：Tiangong Gun Game**，不作为正文公开专名。

## 核心宣传句

> 输掉 Major 后，他没有进入国家队，而是在异世界最小的枪馆里重新报名。

## 一句话简介

现代 CS 职业选手周野肉身穿入架空大曜，从曜京南城白桥枪馆获得七日临时客籍，与四名毫无关联的本地女性选手组成白桥队。她们先要赢下食宿、租金和服务器时段，才有资格谈城区联赛、职业赛、宫城选拔、国家队与回到现代。

## 第一部核心承诺

1. **从零开始是真的从零开始**：无身份、无赛籍、无本地账号、无住处、无国家队关系；
2. **民间比赛是真的比赛**：有经济、道具、站位、补枪、残局、训练、报名与赛后复盘；
3. **小比赛也有现实后果**：食宿、枪馆租金、服务器时段、担保和职业预选名额随胜负改变；
4. **穿越不是外挂**：现代经验只提供比较与职业习惯，本地枪械、地图和职业体系已经发展数百年；
5. **女性队友不是镜像或陪衬**：苏禾、江宁、唐夏、许安拥有独立家族、职业选择和成长弧线；
6. **唯一男性身份必须靠晋升获得**：周野先成为队友，再成为职业选手，再通过天衡检测，最后才有资格竞争国家队；
7. **漫剧不是屏幕录像**：现实赛台、游戏战场和观察者层共同把操作改编成动作戏。

## 系列结构

1. **《白桥第一枪》**：穿越、生存、临时客籍、白桥队、南城民间赛；
2. **《城赛无退路》**：城区联赛、身份落定、赞助合同、天衡预检；
3. **《宫门没有回头枪》**：职业甲级、宫城地图、朝廷与票盟、国家集训竞争；
4. **《万国赛点》**：国家队、外邦战队、国运权益与归途真相。

每一部必须独立完成一条队伍与赛事弧线，同时向更高职业层级和归途谜题推进。
