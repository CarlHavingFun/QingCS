# 第一章电影级样片分镜重构设计

## 1. 决策

第一章先生产一支约 70 秒、16:9、电影级半写实国漫风格的完整声音样片。样片覆盖正式正文的十个核心节拍，以“现代 Major 的半拍失误—`7:5` 异常—白桥试训用正确补枪选择赢得第五格”为闭环。

现有两份分镜仅作为历史过渡稿，不再作为生产入口：

- `分镜/第一章_输掉Major后我从民间赛重新开始_完整分镜.md`
- `分镜/第一章_逐镜头生产分镜.md`

实现阶段先写完并验证新稿，再从工作树删除上述两份文件。删除后仍可从 Git 历史恢复。

## 2. 正史与 Skill 优先级

分镜内容按以下顺序解析冲突：

1. 作者在当前任务中的明确要求；
2. `设定/IP圣经/00_专名词典与原创边界.md`；
3. `正文/第01章_输掉Major后，我从民间赛重新开始.md`；
4. 人物档案与时代、游戏、设备设定；
5. `skills/tiangong-cinematic-director/SKILL.md`；
6. `skills/tiangong-cinematic-storyboard/SKILL.md`；
7. 人物视觉与比赛视觉 Skills；
8. 历史源只可用于外观和材质参考，不回流旧身份、旧关系或旧剧情。

正式正文中的现代队友陈默、林溪、赵雨、顾遥只属于上海 Major 段；穿越后角色固定为苏禾、江宁、唐夏、许安。周野始终是同一名男性、同一身体，现代队服与亚军奖牌跨世界连续。

## 4. 叙事与时长结构

最终剪辑目标为 65—75 秒；声音总线和片尾不得把成片推到 80 秒以上。

| 段落 | 目标时长 | 可执行镜头数 | 叙事任务 |
|---|---:|---:|---|
| 上海 Major 残局 | 0—18 秒 | 4 | 建立四打三、准星离位、补枪失败、五秒拆除与亚军 |
| 休息室复盘 | 18—25 秒 | 2 | 团队只复盘事实，周野承认漏报第二脚步 |
| `7:5` 异常 | 25—34 秒 | 3 | 音画错位、手机无法留证、暗红木框和钟声完成转场 |
| 白桥设备间 | 34—46 秒 | 3 | 同一男性身体、陌生人安全距离、天工系统与七日客籍 |
| 第一轮试训失败 | 46—55 秒 | 2 | 赤漆连珠铳、震声雷碰梁、周野再次多看一条线 |
| 第二轮试训成功 | 55—65 秒 | 2 | 先报“可能”、保近点补枪，再转右廊 |
| 报名第五格 | 65—72 秒 | 2 | 苏禾拍板、四人现实账回场、周野签名 |

镜头源片可按 MiniMax H3 的自然时长生成，剪辑时只使用有效动作区间。不得通过无意义慢动作、重复空镜或旁白复述把样片凑长。

## 5. 视觉设计

### 统一风格

- 电影级半写实国漫；真实材质和电影光影，人物面部适度动漫化收敛；
- 现代段使用冷蓝、黑灰和屏幕白光；
- 白桥段使用青砖、漆木、黄铜、黑化钢和暖灰；
- `7:5` 以暗红木框、低沉钟声和奖牌反光缝合两个世界；
- 画幅固定 16:9，最终输出 1920×1080、24 fps。

### 三层画面

- `REALITY`：身体、键鼠、耳机、设备、队内语音、账本和现实代价；
- `GAME`：地图空间、现代机械枪械、烟闪雷火、准星和补枪；
- `OBSERVER`：人数、比分、倒计时、回放与公开信息。

每次从 `GAME` 或 `OBSERVER` 切回 `REALITY` 都必须有身体动作、设备声音或现实后果作为落点。白桥私训没有太监解说和完整转播团队。

### 关键视觉连续性

- 周野穿越前后脸、身体、现代队服、右腕护带和亚军奖牌一致；
- 白桥四人首次出现时保持安全距离，不围住周野，也不形成后宫式构图；
- 苏禾位于账本、出口与队伍之间；江宁与瞄具和侧屏绑定；唐夏靠训练入口；许安能同时看见门、屏幕和记录；
- 第一轮失败与第二轮成功复用轴线和近似构图，差异只来自信息表达和准星选择；
- 赤漆连珠铳保留现代机匣、导气、弹匣、枪托、瞄具和抛壳结构，不变成古代火器或法器；
- 白桥空间狭窄、旧、维修痕迹明显，不能画成宫廷豪华电竞殿。

## 6. 角色声音与 Voice ID

样片使用原创合成声线，不模仿任何真人。MiniMax Voice Design 为以下五人各建立可复用 Voice ID，并把 ID、声线描述、试听文本、模型和合成参数写入版本化声音清单：

- `ZHOU_YE`：二十四岁中国男性，职业选手式克制、疲惫但不虚弱；同一 Voice ID 同时承担现实对白和内心声，内心声更近、更低、更少房间反射；
- `SU_HE`：二十多岁女性，理性、清楚、短句拍板，不冷艳腔；
- `JIANG_NING`：二十多岁女性，低音量、重细节、语速略慢；
- `TANG_XIA`：二十多岁女性，直接、短促、行动感强，不做暴躁喊叫；
- `XU_AN`：二十多岁女性，观察型、语速稳定、信息层次清楚。

周野的内心声是唯一旁白，不另建旁白 Voice ID。对白必须来自正文事实或在不改变事实的前提下压缩，不能用旁白解释刚刚已经演出的画面。

## 7. 关键帧、视频与声音数据流

```text
正式正文与设定
→ 导演书
→ 18 镜头完整分镜
→ 人物/场景/道具连续性清单
→ GPT Image 关键帧
→ kk9850 ComfyUI 修手、修枪、统一脸与材质、放大
→ MiniMax H3 单镜头图生视频
→ MiniMax 固定 Voice ID 配音
→ 枪声、脚步、设备、环境与配乐分轨
→ 剪辑、字幕、UI 后期合成
→ 1080p 完整声音样片
```

每个镜头都保留 `SHOT_ID`，关键帧、视频、对白、音效和最终剪辑素材均以该 ID 命名。任何返工只替换对应镜头资产，不改变其他镜头文件。

## 8. 失败处理

- 人脸、服装或性别漂移：退回关键帧，不把错误带入视频；
- 手部、枪械结构或握持错误：先在 ComfyUI 修复，再进入 H3；
- 比赛信息看不懂：补建立镜头、人数、位置和目标，不依赖击杀栏解释；
- H3 出现身体融化、枪械漂移、镜头违背轴线或多余人物：该镜头失败，保留失败记录并重新生成；
- Voice ID 试听不符合角色：在正式对白生成前淘汰并重新设计，不用后期变调强行修补；
- 精确文字错误：生图阶段不修文字，统一在后期覆盖；
- 角色像救世主或女性围绕男主：退回分镜，恢复苏禾拍板、江宁资源、唐夏入口和许安信息的独立动作。

## 9. 验收标准

### 文件验收

- 两份旧粗稿从当前工作树删除；
- 三份新生产文件存在，且 `SHOT_ID` 集合完全一致；
- 目录说明只指向新生产入口；
- 每个镜头具备所有导演和分镜必需字段，不留占位标记或空字段；
- 不修改历史源目录。

### 内容验收

- 65—75 秒内讲清十个核心节拍；
- 三秒内能读出每个比赛镜头的操作者、位置、目标或信息变化；
- 第一轮失败和第二轮成功形成明确视听对照；
- 周野没有开局进入国家队、没有天衡正式检测、没有系统外挂；
- 四名女性有独立职业动作，不形成后宫构图；
- 现代队友与白桥队员没有同脸、同名或性转对应；
- UI、比分、报名表姓名和字幕均预留安全区并由后期合成。

### 资产与成片验收

- 五个原创 Voice ID 均有试听、角色说明与固定参数；
- 18 个镜头均有通过审核的关键帧；
- 视频不出现明显人脸漂移、错误性别、额外手指、枪械融化、错误文字或无动机镜头运动；
- 最终视频为 1920×1080、24 fps、完整声音版，时长 65—75 秒；
- 对白、枪声、报点和环境声层级清楚，关键报点不被配乐覆盖。
