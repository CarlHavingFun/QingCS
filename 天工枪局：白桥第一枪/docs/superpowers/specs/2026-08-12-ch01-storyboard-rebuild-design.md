# 第一章样片分镜与关键帧重建设计

日期：2026-08-12  
状态：待用户复核  
选择方案：A——保留完整叙事闭环，按真实表演节奏重做分镜、对白和关键帧提示词

## 1. 目标

把第一章压缩成一支可以独立观看的横屏漫剧样片：周野在上海 Major 决胜局因漏报和准星偏移输掉冠军；复盘时异常回放把他带到白桥枪馆；他在同类失误中学会及时报点并完成补枪；最终在报名表第五格写下自己的名字。成片不预设目标秒数，由对白试读、动作完成时间、反应停顿和声音落点共同反推时长。

本轮只建立可审核的生产事实源。分镜审核通过前，不继续生成关键帧或视频。

## 2. 方法与边界

使用 `libtv-shortdrama-storyboard` 的方法论，不调用 liblib.tv API、CLI、画布或付费模型，也不需要 Access Key。

采用的方法：

- 先分析题材、冲突、情绪弧线和钩子。
- 为人物、场景、道具建立稳定锚点。
- 每镜使用“景别、运镜、主体动作、构图、光影、情绪”六元素公式。
- 每镜单独列出内容片段、时长、台词、声音和引用锚点。
- 关键帧只描述一个可见瞬间；人物外貌通过锚点引用保持一致。

不采用的方法：

- 不使用该技能建议的自动音画生成。
- 不把台词交给视频模型自由发挥。
- 不在关键帧图片中生成字幕、比分、姓名或报名表文字；精确文字后期合成。
- 不把长镜头当成一张“剧情海报”，每个关键帧必须能对应一个明确镜头起点。

## 3. 正文与生产事实源

事实源优先级固定为：

1. `正文/第01章_输掉Major后，我从民间赛重新开始.md`
2. 本设计批准后生成的新版逐镜头分镜
3. 新版关键帧提示词与声音锁
4. 已生成素材

正文与新版分镜冲突时，以正文为准。旧分镜、旧关键帧和旧声音锁均不得反向修改正文事实。

## 4. 台词铁律

所有可听见的人声必须满足以下一项：

- 正文中的完整原句，逐字复制；
- 正文中的连续原文片段，删节不能改变原意；
- 明确标注为“无台词／刻意沉默”。

禁止改写、解释性补句、口号式润色和模型自由补白。尤其废止旧稿中的下列非正文句子：

- “我听见第二个脚步了，没及时报。准星也离开了补枪位。明早重走这一波。”
- “留不住？”
- “曜京南城，白桥枪馆；你站那儿，说明来处。”
- “先试训，七日客籍再谈。”
- “服务器欠款没清，明日午时报名已锁。”
- “资格可撤销，条件不合适就划掉。”
- “这次，从补枪位重新开始。”

结尾的周野内心声锁定为正文原句：

> 也好。第一枪，从白桥开始。

每个镜头的分镜卡必须同时显示：`说话人`、`表演方式`、`逐字台词`、`起止时间`。无台词镜头也必须写明沉默承担的叙事功能。

## 5. 题材与情绪弧线

题材：电竞逆袭 × 异世界悬疑

核心冲突：周野不是输在枪法，而是输在听见信息后没有及时说清；穿越后，他必须在陌生规则和陌生武器下重新证明自己能守住补枪位。

情绪弧线：

- 0–13 秒：强钩子。第二脚步、准星偏移、五秒拆除，冠军丢失。
- 13–23 秒：责任落地。团队复盘，周野亲口承认漏报。
- 23–36.5 秒：悬疑升级。旧报点脱离设备、比分错乱、木框和坠落。
- 36.5–51 秒：异世界落地。白桥醒来、身份核验、提出试机。
- 51–58 秒：重复失败。震声雷失误，再次看两条线。
- 58–64 秒：选择修正。先报低置信度信息，再守近点完成补枪。
- 收尾段：代价与承诺。第五格落笔，内心声收束主题。

以下时长是按普通对白约每秒 3.5–4.2 个汉字、战术短报点略快、情绪对白略慢，并为动作与反应预留时间后得到的第一版建议值。对白可以跨动作连续发生，不能为了命中总时长而加速朗读。完成角色声音样本后，以实际音轨波形二次校准；镜头可拆分，样片总时长不是验收指标。

台词的实际口播速度将在声音测试时复核；若某镜超出建议值，只能延长、拆镜或删去完整句段，不能加速到不自然，也不能改写原句。

## 7. 新版分镜卡格式

每个镜头必须包含以下字段，缺一项即不进入关键帧生产：

- `SHOT_ID`、场景、层级、时长和时间码；
- 正文内容片段与该镜叙事任务；
- 人物、位置、动作起点和动作终点；
- 六元素镜头描述；
- 说话人、表演方式、逐字台词、台词时间码；
- 环境声、拟音、音乐进入和退出；
- 人物／场景／道具锚点引用；
- 连续性输入、连续性输出；
- 后期文字安全区；
- 单一关键帧时刻；
- 禁止项。

分镜表中的台词属于审核信息，不要求生图模型把台词画在画面里。最终故事板预览图的台词排在画格下方，由排版程序写入，不由图片模型生成。

## 8. 锚点策略

人物锚点：

- 现代：周野、陈默、赵雨、林溪、顾遥。
- 白桥：苏禾、江宁、唐夏、许安、罗叔、韩平。
- 周野穿越前后始终为同一个二十四岁男性身体、同一现代队服和右腕黑色护带。

场景锚点：

- 上海国际电竞中心比赛席；
- Major 赛后隔音休息室；
- 白桥设备间；
- 白桥离线训练区；
- 白桥柜台与报名桌。

道具锚点：

- 亚军奖牌；
- 现代耳机与声卡；
- 赤漆连珠铳；
- 震声雷；
- 七日临时客籍表与南城公开赛试报名表。

现有人物外观母版可以作为身份参考，但关键帧只引用当前镜头实际出场的人物，避免一次塞入过多角色导致脸型串扰。

## 9. 关键帧生成规范

每镜先生成一张 16:9、1920×1080 首帧或动作临界帧。提示词结构固定为：

`锚点引用 + 单一可见时刻 + 景别 + 机位 + 构图 + 光影 + 材质 + 情绪 + 连续性物件 + 安全区 + 统一风格后缀`

统一风格：高完成度电影级 3D 国漫，真实人体比例，克制自然表演，可信电竞设备与机械结构，可触摸的漆木、青砖、金属、玻璃和织物材质；不是廉价游戏截图，不是塑料皮肤，不是二维平涂，也不是直接真人照片。

统一负面项：乱码、字幕、水印、随机 UI、真实赛事 Logo、塑料皮肤、同脸角色、错误手指、漂浮设备、武器结构错误、多人视线混乱、海报式站桩、夸张仙侠粒子。

关键帧验收必须同时通过：

- 人物身份与外观母版一致；
- 动作时刻与分镜的因果顺序一致；
- 场景时代、材质和空间轴线正确；
- 台词对应的人物在镜头中具备合理发声状态，画外音除外；
- 精确文字区域留空，后期可覆盖；
- 下一镜能从当前构图或声音自然承接。

## 10. 旧稿处理

旧三份分镜文档、旧 `dialogue-lock.json` 和已生成关键帧不删除，统一移动到带日期的 `历史版本/2026-08-12_重做前/` 或 `rejected/storyboard-v1/`。归档文件只作为问题追踪证据，不再被生产脚本读取。

新版文件使用明确的 `v2` 或 `重制版` 名称。在全部新版文件和声音锁完成前，不覆盖或删除任何用户资产。

## 11. 验证

进入关键帧生成前执行四项机械检查：

1. 每镜建议时长不短于实际台词音轨，并完整容纳必要动作与反应；
2. 每句台词都能在正文中逐字检索到；
3. 每镜都有台词或“无台词／刻意沉默”说明；
4. 每个关键帧提示词只描述一个时刻，并引用所需锚点；若长对白需要拆分反应镜，新增镜头沿用同一场景连续性和台词时间轴。

抽检重点：S01_SH02 与 S01_SH03 的“准星先离开、赵雨后倒下”；S03_SH04 的“先木框、再钟声、后下坠、最后奖牌滑落”；S05_SH01 与 S06_SH01 的相似轴线；S07_SH01 的正文原句内心声。
