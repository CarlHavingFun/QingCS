# S01_SH01 完整参考资产与 MiniMax H3 工作流设计

日期：2026-08-23
状态：已批准
选择方案：五人完整比赛席、赵雨与陈默可见口型、连续向右横移、Ref2VA 只引用场景/人物/声音而不引用首帧

## 1. 目标

先把第一章第一个镜头 `S01_SH01` 做成可复用的完整生产样板：补齐该镜头所需的五人现代身份参考、无人物五席 Major 场景板和无对白环境动作声，随后在本机 ComfyUI 中搭建一份 MiniMax H3 Ref2VA 完整工作流。工作流导入画布后先保持队列为零，供用户审核全部参考输入、标签、时长和连线；只有再次获得用户确认才运行生成。

本设计只覆盖 `S01_SH01` 及其直接依赖资产，不在同一次实施中生成其余 17 镜。该镜验收后，其资产命名、清单、校验和工作流结构作为第一章后续镜头的母版。

## 2. 已锁定的全章决策

以下决策在本轮讨论中已经确认，后续第一章资产不得与其冲突：

- 第一章 10 个具名人物最终都要拥有独立 Voice ID：周野、赵雨、陈默、林溪、顾遥、苏禾、江宁、唐夏、许安、罗叔。
- 第一章没有台词的林溪、顾遥、江宁、许安、罗叔使用 6–10 秒的非剧情音色校准句；校准句只用于 Voice ID，不进入正片，也不修改分镜时长。
- 周野、赵雨、陈默、林溪、顾遥属于现代 Major 段，穿现代职业电竞队服。
- 周野穿越后在第一章继续保留现代队服、右腕护带和亚军奖牌，不在第一章更换白桥衣服。
- 苏禾、江宁、唐夏、许安、罗叔穿白桥世界的架空古代工业工作服：传统交领、窄袖、布革层次，适合维修、操作终端和使用现代机械枪械；不采用宽袖仙侠汉服。
- 第一章采用“参考资产库 + 标准单镜头母版 + 18 个独立镜头工作流”，不建立一个一次执行 18 镜的巨型画布。

## 3. S01_SH01 叙事与对白边界

镜头仍承担 Major 末局压力建立、五人队伍关系、赵雨先报点、陈默要求周野补枪以及周野准备执行补枪职责的功能。

为满足已经确认的“赵雨与陈默入镜并显示口型”要求，本设计仅针对 `S01_SH01` 覆盖旧分镜中“现代队友只以屏幕倒影和语音存在”的人物位置约束；对白文本、战术事实和后续镜头因果不变。后续正式分镜同步时必须记录这一处有意变更，不能让旧位置描述反向覆盖本设计。

逐字对白保持：

- 赵雨（可见口型、队内通讯质感）：`A1 两个。`
- 陈默（可见口型、与赵雨不同声线）：`你跟着补。`
- 周野：无台词，不得替赵雨或陈默对口型。

周野虽然不说话，但必须出现可读的浅呼吸、吞咽、下颌收紧、眼神锁屏和鼠标手微调。不得再把“周野嘴不动”与“周野完全没有表演”混为一件事。

## 4. 五人席位与摄影调度

比赛席必须体现完整五人制队伍，不得把场景板缩减为三个席位。

五席从画面左到右固定为：

1. 林溪
2. 顾遥
3. 赵雨
4. 陈默
5. 周野

镜头为一条不切镜的连续向右横移：

- `0.0–1.2s`：五人席中景，建立完整队伍、五套设备和隔音比赛空间；林溪、顾遥可识别但不抢对白焦点。
- `1.2–2.7s`：镜头向右靠近赵雨；赵雨说出“A1 两个”，脸部尺寸必须足以判断口型。
- `2.7–4.1s`：镜头继续向右经过陈默；陈默说出“你跟着补”，不得复用赵雨的脸、声线或口型。
- `4.1–8.0s`：镜头停在周野的脸、右腕护带和鼠标手；周野以身体微动作回应，深处脚步逐渐清楚，结尾进入第一声游戏内枪响，为 `S01_SH02` 提供剪辑点。

镜头不得反向、环绕、跳切或生成通讯小窗。精确比分、人数、赛事标识和 HUD 仍由后期完成。

## 5. 完整参考资产包

### 5.1 场景参考

创建：

`视觉资产/现代Major/场景/SCN-MAJOR-FIVE-SEAT-BOOTH-v01.png`

要求：

- 16:9 无人物场景板，完整呈现五个连续比赛席位。
- 五套显示器、键盘、鼠标、耳机、座椅和统一走线必须符合可操作的现代电竞设备逻辑。
- 隔音玻璃、远处观众、冷蓝场馆灯、屏幕白光和黑灰设备材质延续现有 `S01_SH01` 的视觉语言。
- 明确支持从第三席赵雨连续向右经过第四席陈默、最终到第五席周野的摄影轴线。
- 不生成现实赛事、战队或赞助 Logo；不生成可读文字、比分或随机 HUD。
- 不包含人物、人体剪影、反射中的假人或海报人物。

现有 `AI生产/样片01/视觉/keyframes/h3-input/S01_SH01.png` 只作为生成场景板时的材质、灯光和设备氛围参考；它不得进入最终 Ref2VA 工作流。

### 5.2 人物参考

复用：

`视觉资产/人物外观母版/00_周野_外观母版.png`

创建：

- `视觉资产/现代Major/人物/CHAR-LIN-XI-MODERN-v01.png`
- `视觉资产/现代Major/人物/CHAR-GU-YAO-MODERN-v01.png`
- `视觉资产/现代Major/人物/CHAR-ZHAO-YU-MODERN-v01.png`
- `视觉资产/现代Major/人物/CHAR-CHEN-MO-MODERN-v01.png`

人物母版统一采用 16:9 身份板：左侧大面部特写，右侧正面、侧面、背面全身视图。四人必须拥有可区分的脸型、发型、年龄感和体态，不得与周野同脸；五人共享同一套无品牌石墨黑现代职业队服体系，但允许通过内搭、袖口和个人小配件建立区分。所有母版不得含姓名、胸牌、真实队标、赞助标识或随机文字。

林溪与顾遥即使在本镜只处于远侧席位，也必须引用正式人物母版，不得由模型生成随机路人。

### 5.3 对白音色参考

复用：

- `AI生产/样片01/声音/voice-seeds/ZHAO_YU_V001.flac`
- `AI生产/样片01/声音/voice-seeds/CHEN_MO_V001.flac`

本镜不为周野、林溪或顾遥连接 Voice ID，因为三人没有台词。全章十人 Voice ID 的其余补全属于后续子项目，不阻塞 `S01_SH01`。

### 5.4 环境与动作声参考

创建：

`AI生产/样片01/声音/ambience/AMB-MAJOR-BOOTH-S01_SH01-v01.wav`

该文件为准确 8.0 秒、无对白的时间化参考声轨：

- 前段为隔音玻璃外的观众低频、耳机底噪和轻微键盘触碰。
- 赵雨、陈默对白时间段只保留低层环境，不加入任何人声或可误识别音节。
- `4.1s` 后加入周野浅呼吸、鼠标微响和逐渐清楚的深处脚步。
- 结尾加入第一声游戏内步枪声，作为切入下一镜的声音节点。
- C4 提示保持低于对白和脚步，不得持续尖锐覆盖口型段。

环境声可通过本地 H3 音频生成流程建立，再抽取 WAV；不得调用付费云端 MiniMax API。

### 5.5 参考清单

创建：

`AI生产/样片01/manifests/S01_SH01_refs_v01.json`

清单至少记录：`shot_id`、资产 ID、相对路径、用途、版本、SHA-256、图片尺寸或音频时长/采样率、批准状态、生成来源和禁止用途。工作流中的每个媒体节点必须能反查到该清单中的一条记录。

## 7. ComfyUI 工作流结构

编辑器工作流至少包含：

- 6 个 `LoadImage` 节点；
- 3 个 `LoadAudio` 节点；
- 本地 `minimax_h3_ref2va_pruned_int8_convrot.safetensors`；
- 本地 Qwen3-VL MiniMax H3 文本编码器；
- MiniMax H3 视频 VAE 与音频 VAE；
- `MiniMaxH3ReferenceToVideo`；
- `RandomNoise`、`BasicGuider`、`KSamplerSelect`、`BasicScheduler`、`SamplerCustomAdvanced`；
- 视频与音频解码、`CreateVideo` 和 `SaveVideo`；
- 标明镜头、参考编号、时长与验收规则的说明节点或分组。

参数锁定为：

- 模式：Ref2VA；
- 宽高：`864×480`；
- 帧率：`24 fps`；
- 长度：`192` 帧，即 `8.0s`；
- 采样器：`res_multistep`；
- 调度器：`simple`；
- 步数：`20`；
- `denoise=1.0`；
- `ref_image_size=match`；
- v01 固定 Seed：`2026082302`。

不连接 `first_frame`、`last_frame` 或参考视频。工作流保存到项目目录，并同步到 ComfyUI 用户工作流目录；同步后的两个 JSON 必须哈希一致。

## 8. 预览门槛

在任何生成开始前：

1. 把全部最终参考资产复制到 ComfyUI input 根目录或节点能合法解析的位置。
2. 在 ComfyUI 中导入完整编辑器 JSON。
3. 适配画布，确保 6 张图片、3 路音频、模型、采样、解码和输出连线全部可见。
4. 确保前端没有缺失媒体或缺失节点错误。
5. 确保任务队列显示为零。
6. 由用户审核画布并明确要求开始后，才允许点击运行。

## 9. 输出与验收

技术验收：

- ComfyUI 历史状态为 `success`，队列运行和等待项均为零。
- 输出为准确 `8.000s`、`192` 帧、`864×480`、`24 fps`。
- 同时具有 H.264 视频流和双声道 AAC 音轨。
- 保存 Prompt ID、工作流 JSON、Seed、源资产 SHA-256、输出 SHA-256 和总耗时。

视觉验收：

- 场景可读为完整五人比赛席，五套设备数量与空间关系正确。
- 五名人物均能对应各自母版；赵雨、陈默、周野在全镜头不得换脸。
- 赵雨和陈默在各自台词时间段具有可判断的可见口型。
- 周野不替任何队友对口型，但呼吸、吞咽、下颌、眼神和鼠标手动作清楚。
- 镜头从赵雨连续向右经过陈默到周野，无切镜、反向、环绕或无动机变焦。
- 林溪、顾遥保持远侧队员身份，不变成随机路人，也不抢对白焦点。
- 不出现可读伪文字、真实品牌、真实赛事、真实战队或赞助标识。

声音验收：

- 赵雨逐字说出“A1 两个”，陈默逐字说出“你跟着补”。
- 两人声线可区分并分别匹配自己的 Voice ID，不交换、不合并。
- 不新增对白、旁白或无法归属的人声。
- 环境、脚步、C4 和结尾枪声不覆盖对白；结尾枪声形成清楚剪辑点。
- 对白需经过本地 ASR 或人工逐字试听确认；未核验时不得标记正式通过。

任何一项身份、口型、逐字对白或连续运镜失败，输出都只标记为试验版本，不覆盖既有素材，也不进入正式合片。

## 10. 非目标

本子项目不执行以下工作：

- 不生成其余 17 镜的关键帧或视频。
- 不补齐全章其余 7 个 Voice ID。
- 不生成白桥人物工作服、白桥场景、赤漆连珠铳或货栈地图。
- 不做 1080p 升格、HUD、字幕、比分或赛事标识后期。
- 不把本镜工作流改成包含 18 镜的自动批处理画布。

上述内容在 `S01_SH01` 完整样板验收后，按相同资产合同拆分为后续子项目。
