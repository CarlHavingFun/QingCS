> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** 将《天工枪局》从国家队第五席穿越重构为周野独自肉身穿越、从白桥枪馆民间赛逐级晋升的长期竞技 IP。

**Architecture:** 以主品牌不变、第一部改名为《白桥第一枪》的方式重排系列。世界制度和明清火器工业风保留，人物、穿越落点、赛事成长梯、第一章后半段和生产 Skill 统一切换到白桥民间赛正史。

**Tech Stack:** Markdown 小说与设定文档、GitHub Git Data API、PNG 外观母版的 Git blob 无损重命名。

## Global Constraints

- 周野是唯一穿越者，以自己的男性身体穿越。
- 不得出现谢晚失踪、身体置换、同名女性队友或国家队保送。
- 穿越后核心队友固定为苏禾、江宁、唐夏、许安，均为大曜本地女性且与现代队友无关。
- 第一章只使用普通终端，不进行天衡正式检测。
- 第一部从民间赛起步，国家队与万国枪赛必须通过长期晋升获得。
- 旧历史源目录保持不动。
