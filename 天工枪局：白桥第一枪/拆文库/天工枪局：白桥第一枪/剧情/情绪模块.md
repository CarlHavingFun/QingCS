# 情绪模块：天工枪局·白桥第一枪

> 权威范围：从第1章抽象出的读者需求、情绪引擎和本书内部续写模块。当前为自分析、黄金三章1/3，不得作为本书外部对标，也不得把正文专名与事件顺序复制成“通用模板”。

## 读者需求 / 情绪引擎

| 读者需求 | 本书当前满足方式 | 证据章节/情节点 | 持续追读机制 | 可迁移边界 |
|---|---|---|---|---|
| 失败后的第二次机会 | 先写最高舞台失败，再把主角降到普通终端重新证明 | 第1章P1-P4,P18 | 次日完整试训与可撤名资格 | 本书内部可保留“高位跌落→低位重建”，不得把Major残局机械重写 |
| 专业可信感 | 责任落在脚步、准星、补枪、枪械材料和声学差异 | 第1章P1-P4,P13,P16-P17 | 现代经验需逐项本地验证 | 只能迁移“动作可复核”原则，不照抄地图、枪名、数值 |
| 团队边界带来的安全感 | 不找替罪羊，不凭履历收编，权限与否决权清楚 | 第1章P4,P10,P14-P18 | 关系必须通过训练与账本逐步改变 | 不写无条件信任、集体崇拜或后宫化 |
| 认知好奇 | 双端七比五互证却不解释机制 | 第1章P5-P12 | 后续每次给一条可核验答案和一层新问题 | 异常不能发任务、赐能力或吞没竞技主线 |
| 小人物共同承担现实成本 | 服务器、租赁、维修、工时和担保同时结算 | 第1章P15,P18 | 南城公开赛会改变三本账 | 现实后果必须匹配赛事层级，不夸大为国运 |

## 故事框架与套路运行图

| 框架/套路 | 在本书中的位置 | 运行方式 | 为什么有效 | 失效风险 |
|---|---|---|---|---|
| 高位跌落后重建 | Major失败→白桥普通终端 | 顶级失败立伤口 → 身份清零 → 小动作重新证明 | 同时提供专业落差与成长空间 | 若第二章立刻碾压，本章代价全部失效 |
| 无外挂穿越适配 | 赤漆连珠铳、木廊、震声雷 | 先识别功能 → 本地差异反制 → 训练验证 → 保留短板 | 兼顾现代参照和异世界原创职业体系 | 把现代知识写成未卜先知会串味 |
| 有限准入 | 七日客籍、断网试训、试报名 | 给机会 → 列边界 → 明确撤销条件 → 立下一关 | 接纳感与现实可信度同时成立 | 一次胜利直接转正式队员会削弱团队主体性 |
| 证据阶梯谜团 | 旧语音→七比五→黑屏→双端断帧 | 每次增一条证据，但证据只能排除一种解释 | 维持好奇而不靠空泛玄学 | 连续只加怪象不回答任何小问题会拖延 |

## 可复现模块卡

### EM-001 高位失败降到最低起点

| 字段 | 内容 |
|---|---|
| 读者想看什么 | 一个真正有水平的人如何面对可定位的失败，并从失去信用的起点重建 |
| 情绪链 | 逼近最高目标 → 半拍失误 → 事实复盘 → 身份与履历清零 → 获得最低级再试机会 |
| 戏剧单元 | 有能力者在最高舞台暴露长期缺陷，随后只能在低门槛场景重新证明 |
| 关键触发物 | 失误证据、见证团队、降级场景、可撤销机会 |
| 复现步骤 | 1. 先写具体失误 2. 拒绝替罪羊 3. 让过去不可兑换 4. 给只够下一步的机会 |
| 可替换项 | 赛事、位置、失误动作、验证场景、准入程序 |
| 不可照搬 | 上海Major、A1脚步、七比五、白桥、原句与事件顺序 |
| 关联节奏 | RH-001 / TR-001 / TR-005 |

### EM-002 双端证据只推进一层

| 字段 | 内容 |
|---|---|
| 读者想看什么 | 异常不是幻觉，但真相仍需调查 |
| 情绪链 | 不合时序的声音 → 设备异常 → 个人记录失败 → 异地同数值互证 → 保留伪造可能 |
| 戏剧单元 | 两个相互隔离的观察端出现同一异常，证明问题存在但不解释机制 |
| 关键触发物 | 重复标记、失败记录介质、第三方设备、谨慎见证人 |
| 复现步骤 | 1. 私人感知 2. 物理反常 3. 记录失败 4. 第三方互证 5. 只缩小解释范围 |
| 可替换项 | 标记、介质、见证人、时间换算、审查程序 |
| 不可照搬 | 七比五、黑屏、钟声、监控断帧组合 |
| 关联节奏 | TR-002 / 第1章P5-P12 |

### EM-003 现代经验先识别再被反制

| 字段 | 内容 |
|---|---|
| 读者想看什么 | 主角确实专业，但新世界也有自己的成熟知识 |
| 情绪链 | 快速识别 → 产生熟悉感 → 参数差异 → 实操失败 → 本地人克制校正 |
| 戏剧单元 | 外来专家认出功能相似物，却因材料、环境和制度差异失去直接优势 |
| 关键触发物 | 功能类比、本地参数、可重复训练、专业队友 |
| 复现步骤 | 1. 让主角说出可验证类比 2. 立刻给差异 3. 用实操失败证实 4. 允许保留一部分有效经验 |
| 可替换项 | 枪械、地图、声学、道具、程序 |
| 不可照搬 | AK/赤漆连珠铳对应、木廊共振和震声雷落点 |
| 关联节奏 | RH-001 / TR-003 |

### EM-004 同场重跑只修一个动作

| 字段 | 内容 |
|---|---|
| 读者想看什么 | 角色成长能当场验证，同时不被一次训练治愈 |
| 情绪链 | 同错复现 → 同伴点破 → 主角不辩解 → 重跑条件固定 → 单点修正 → 克制反馈 |
| 戏剧单元 | 相同训练在关键变量不变时重跑，角色只改变一个可观察行为 |
| 关键触发物 | 同场景、明确反馈、固定职责、新证据、保留短板 |
| 复现步骤 | 1. 复现缺陷 2. 用一句动作反馈点破 3. 重跑 4. 先执行约定 5. 评价只覆盖已证明部分 |
| 可替换项 | 缺陷、训练、反馈者、验证指标、残留问题 |
| 不可照搬 | “右廊到门，半秒”、乙仓机器人与补枪顺序 |
| 关联节奏 | RH-001 / TR-004 |

### EM-005 有限准入与三本账

| 字段 | 内容 |
|---|---|
| 读者想看什么 | 被接纳，但接纳不会抹掉队友的风险和现实生活 |
| 情绪链 | 资源缺口 → 陌生人可能有用 → 担保风险公开 → 每个人算账 → 只签短期 → 新门槛 |
| 戏剧单元 | 团队在现实压力下给候选人可撤销机会，资格与资源各自结算 |
| 关键触发物 | 账本、合同、担保人、否决权、下一次验证 |
| 复现步骤 | 1. 写明缺什么 2. 写明谁承担 3. 拆开权限 4. 让全员表态 5. 只给下一步 |
| 可替换项 | 食宿、设备、报名、工时、保险、租赁 |
| 不可照搬 | 白桥七日客籍、南城公开赛具体条款与人物名单 |
| 关联节奏 | TR-003 / TR-005 |

## 重组与复现指南

1. 这些模块只用于本书内部维持情绪逻辑，不是外部市场样本。
2. 第2章优先选择EM-004与EM-005，兑现完整试训和可撤销关系；EM-002只推进一小步。
3. 保留“证据—责任—代价”功能位，替换具体训练、地图、冲突对象与余波方向。
4. 若模块与人物档案冲突，以人物档案和IP圣经为准。
5. 禁止用异常替周野报点、预知对手、获得属性或越过赛籍程序。

## 置信度

- EM-001至EM-005对第1章的概括：中高。
- 模块在第2章以后的稳定复现性：低，待至少黄金三章完成后复核。
