# 势力：白桥枪馆

> 兼容分析层。权威来源为 `设定/游戏背景/06_白桥枪馆与民间职业生态.md`、人物档案与第1章正文。

| 项目 | 内容 |
|---|---|
| 名称 | 白桥枪馆 |
| 类型 | 民间枪馆、基层职业训练与临时担保节点 |
| 地点 | 曜京南城跨支河木桥旁 |
| 核心人物 | 苏禾、江宁、唐夏、许安；周野为七日客籍与试训第五人；夏满为注册替补 |
| 立场倾向 | 保住基层训练入口，以可复核程序和现实账维持队伍，不接受不可验证履历换特权 |
| 当前对外关系 | 受南城枪馆联会规则约束；与设备租赁、维修铺、货栈和票号资源存在经济联系 |

## 空间与设备

项目权威设定包含十二台普通竞赛终端、一间五人训练房、复盘墙屏、后门设备间/服务器柜、维修台、两间临时宿舍、柜台与租赁登记。第1章实际写到漆木桌、黄铜走线、修补鼠标垫、白桥木桥、设备间、训练房、普通终端和服务器/训练服费用，验证了它是设备真实可用但资源紧张的小场馆，不是豪门俱乐部。

## 经营状态

苏禾接手前任留下的设备贷款和服务器合同，客流受大型票号赛馆挤压。第1章账本明确：南城公开赛明日午时锁定；进入前四可续高质量训练服并取得城区预选邀请，首轮出局则训练服停用一个月，周野担保也无法在白桥续期。权威设定另补充设备维修额度、重狙租赁优惠、队员本职工时等后果。

## 队伍与岗位

- 苏禾：经营者、队长、IGL、经济与最终拍板。
- 江宁：主狙、瞄具维修与远点信息。
- 唐夏：首接触、守方锚点、火器维修。
- 许安：游走、晚段信息、货栈记账。
- 周野：试训二号位/补枪/晚段判断，尚非正式主力。
- 夏满：注册替补，竞争权不得因周野故事或性别取消。

## 内部规则

1. 事实、推测和建议分开报告。
2. 入口必须说明烟闪、补枪和撤退条件。
3. 私人枪械、账号与高权限设备不能因试训开放。
4. 来源不明信息先封存，不直接用于正式赛。
5. 现代经验必须在本地训练中验证。
6. 性别不改变技术标准，也不取消住宿、更衣、医疗和数据边界。
7. 输回合先复盘动作，再讨论责任。
8. 任何人都有合同、健康与职业选择的离队权。

## 第1章关键事件

1. 周野随七比五断帧出现在设备间。
2. 苏禾封门、备份、报联会；许安记录，罗叔锁门。
3. 白桥训练服同步跳到七比五。
4. 白桥在断网、公用设备、全程录像条件下给两遍试训。
5. 四名队员各自评估并算现实账。
6. 苏禾只签七日客籍与可撤销试报名。

## 势力边界

白桥可以提供设备、训练、临时担保和地方赛入口，不能证明穿越、伪造身份、跳过天衡/赛籍、扣押人身或把周野直接送入职业体系。南城赛的胜负只影响匹配层级的服务器、担保、维修、租赁和预选资格，不直接决定国家权益。
