# 世界观背景设定

> 来源：第1章正文＋项目权威 `设定/IP圣经/`、`设定/游戏背景/`。正文已证事实与后续世界规则分开记录；本文件是拆文兼容投影，不覆盖项目原设定。

## 世界类型

架空清制现代平行社会＋成熟职业枪战竞技。大曜不是历史清朝：使用承曜年号并与国际公历并行，拥有现代电脑、网络、智能设备、职业赛事、合同、保险和行政程序；视觉材料使用漆木、黄铜、青砖与火器工业语言，但功能不是古代法器或魔法。

## 第1章已证实规则

1. 周野从现代上海中国Major赛场进入大曜曜京南城白桥枪馆，现代手机、队服、护腕、身体与亚军奖牌保持连续。
2. 现代回放与白桥训练服都出现七比五、音画错位或断帧；这证明异常可跨端观察，不证明完整机制。
3. 大曜公共库查不到周野照片中的国名；他的手机无法接入本地网络。
4. 《天工枪局》有枪械、投掷物、地图声学、普通终端、天衡层级和赛事程序；赤漆连珠铳与现代AK功能可类比，但重量、回正、材料和环境参数不同。
5. 临时客籍只能提供七日指定食宿、监督与低级别试训，不等于身份证、赛籍、长期合同或职业资格。

## 项目权威核心规则（未必已在正文展开）

- 《天工枪局》是五人制成熟职业运动，赛事金字塔为：民间枪馆赛 → 曜京城区联赛 → 职业乙级 → 职业甲级 → 宫城选拔与国家集训 → 万国天工枪赛。
- 普通终端男女皆可使用；天衡属于后续职业流程，第一部禁止提前正式通过。
- 每次升级必须有报名、成绩、合同、检测和名单程序，性别、皇帝关注与穿越不能保送。
- 竞技同时结算三本账：局内经济与回合选择、队伍资源与关系、现实食宿/工作/合同后果。
- 现代经验只提供功能参照；本地数百年职业体系会以材料、地图、设备、赛务和合同反制盲区。

## 关键地点

- 现代上海国际电竞中心：第1章Major失败与异常起点。
- 曜京南城白桥枪馆：基层训练、担保、设备与白桥队日常中心。
- 白桥货栈离线靶场：第1章两遍二打二验证场景。
- 后续权威范围：南城、运河货栈、地方会馆；正文尚未展开的地点不计入拆文事件。

## 穿越与七比五边界

- 穿越只发生一次，周野是唯一穿越者，没有本地人物被替换、失踪或性转。
- 七比五是长期谜题与证据标记，不是系统面板、任务提示、预知工具或战术报点来源。
- 每一阶段可推进一条可核验证据，但谜题不得吞没白桥竞技与职业成长主线。

## 无力量体系说明

本书没有玄幻境界、法术等级或超能力晋升体系。可量化的“成长”来自枪械/地图熟练度、团队职责、比赛成绩、身份程序、合同资源与职业层级。

## 置信度

- 第1章直接出现的设备、日期、客籍、枪械与异常：高。
- 长期赛事层级与规则：权威设定高，但尚未全部正文验证。
- 穿越源头、可逆性与最终归途：原文未明确，禁止推断填空。
