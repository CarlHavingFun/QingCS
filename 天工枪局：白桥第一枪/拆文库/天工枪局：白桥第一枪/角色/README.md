# 角色目录说明

本目录是 story-import/story-long-analyze 的兼容分析层，不是项目角色权威源。

## 权威规则

1. 正式人物权威仍在项目根 `人物档案/`。
2. 专名、世界与原创边界以 `设定/IP圣经/00_专名词典与原创边界.md` 为更高优先级。
3. 本目录把“第1章已发生证据”与“人物档案预设”分开记录，便于工具读取；不得用本目录反向覆盖人物档案。
4. 当前黄金三章只有1/3，除周野与白桥四人首章行为外，角色成长弧均为低置信或未进入正文。
