# 天工枪局人物视觉 Skill

## 1. 正式人物

```text
ZHOU_YE      周野，二十四岁男性，唯一穿越者
SU_HE        苏禾，二十七岁女性，枪馆经营者与 IGL
JIANG_NING   江宁，二十三岁女性，主狙与瞄具维修
TANG_XIA     唐夏，二十五岁女性，首接触与火器维修
XU_AN        许安，二十四岁女性，游走信息位与货栈记账员
```

正式三视图位于 `视觉资产/人物三视图/`。其他图片不得覆盖这些身份事实。

## 2. 三视图标准

- 16:9；
- 左侧面部与胸像；
- 右侧正面、左侧、背面全身；
- 空手、中性站姿；
- 三视角同脸、同发型、同体型、同服装；
- 手、鞋和衣服功能结构清楚；
- 浅灰无缝背景；
- 无文字、色卡、枪械、奖杯和战斗姿势。

## 3. 周野硬锁

- 二十四岁中国男性；
- 短黑发，偏窄男性骨相；
- 瘦而有力量感，肩颈略前倾；
- 右腕黑色护带；
- 现代深色职业队服；
- 不用女性母版变形；
- 不直接复刻现实职业选手脸；
- 不添加古风长发、银簪、仙侠铠甲或国家队标识。

## 4. 白桥四人差异

```text
SU_HE: 方下颌、短直发、稳定肩线、玄黑与暗绛红、经营者
JIANG_NING: 高瘦窄脸、耳下碎发、灰蓝细节、精密技术人员
TANG_XIA: 宽肩方脸、贴颈短发、红黑护腕、低重心
XU_AN: 高瘦长脸、高束深发、墨青袖扣、安静信息位
```

不得全员同脸、同身高、同发型、同妆容或同一种冷脸。

## 5. 服装层级

### 身份三视图

空手、工作层、无武器，用于锁定人物。

### 白桥日常工作服

- 苏禾：账本、钥匙与设备权限；
- 江宁：瞄具维修层；
- 唐夏：火器维修层；
- 许安：记账与仓门工作层；
- 周野：现代队服跨界，后续另做白桥借用工作服。

### 民间比赛服

玄灰收袖短袍、灰白桥纹小型编号片、少量绛红识别、真实修补和混用装备。不能画成国家队礼服。

## 6. 关键帧规则

- 关键帧必须引用对应正式三视图；
- 同一镜头只改变姿势、表情和光线，不改变脸、发型、性别与服装层级；
- 多人镜头先声明人物左右、前后、距离与视线；
- 周野开局在空间边缘，不自动成为群像中心；
- 四名女性保持职业边界，不统一围观或爱慕周野。

## 7. 禁项

- 谢晚和旧同名女队；
- 现代队友性转或换脸；
- 皇冠、凤袍、国家队胸牌；
- 身份三视图持枪；
- 宽袖遮住手；
- 高跟鞋和不适合工作的长裙；
- 性感化突出周野唯一男性身份；
- 在正式文件名中添加连续版本后缀。
