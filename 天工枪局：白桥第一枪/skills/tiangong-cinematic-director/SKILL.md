# 天工枪局电影导演 Skill

## 1. 第一章最终比例

```text
穿越前 8 秒
穿越后 62 秒
总时长 70 秒
```

现代段只提供因果证据。白桥设备间、枪馆主厅、两轮试训、登记和雨夜结尾承担主视觉。

## 2. 三层镜头

### REALITY

身体、键鼠、耳机、设备、账本、客籍、食宿、贷款和比赛后果。

### GAME

白桥货栈等明清火器工业风数字战场，现代枪械结构、烟闪雷火、脚步和补枪。

### OBSERVER

合法记录、人数、比分、输入曲线和简化回放。白桥私训没有完整转播团队和太监解说。

## 3. 第一章八段

1. Major 失败证据蒙太奇；
2. 7:5 异常与坠落；
3. 白桥设备间醒来；
4. 白桥枪馆与四人建立；
5. 欠款、客籍与试训条件；
6. 第一遍试训失败；
7. 第二遍试训成功；
8. 七日担保、第五格与雨夜白桥。

禁止恢复独立赛后团队复盘场景。

## 4. 场面调度

- 苏禾在账本、出口、设备权限与队伍之间移动；
- 江宁靠瞄具、异常屏和远距离构图；
- 唐夏靠入口、设备检查区和第一接触轴线；
- 许安位于能同时看到门、屏幕与记录的位置；
- 周野开局处于空间边缘；
- 四人保持安全距离，不围住周野。

## 5. 失败与成功对照

第一遍：

```text
错误投掷条件
→ 震声雷撞梁
→ 周野听见右廊却不报
→ 准星离开近点
→ 唐夏先倒
→ 周野与右廊交换失败
```

第二遍：

```text
先报告右廊不确定信息
→ 使用本地图投掷线
→ 准星留近点
→ 完成近点补枪
→ 听见确认脚步
→ 再转右廊
```

两段复用相似机位。成功必须来自选择变化，不来自突然变强。

## 6. 声音优先级

```text
队内关键报点
> 脚步、投掷物和枪声
> 设备异常
> 机柜、键帽、雨与货船
> 配乐
```

现代段拆包声延长为钟声；白桥段桥板雨声作为结尾延迟声。

## 8. 禁止捷径

- 周野醒在女性身体；
- 本地队员与现代队友匹配剪辑；
- 国家队、宫城或正式天衡检测；
- 皇帝来接人；
- 白桥画成豪华电竞宫殿；
- 游戏枪械变成火绳枪或法器；
- 用字幕替代可见行动；
- 生成多个带后缀的导演书版本。
