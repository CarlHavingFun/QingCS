# 天工枪局电影导演 Skill

## 1. 当前视觉阶段

第一部视觉中心是白桥枪馆和南城民间赛，不是宫廷国家队大片。

成长对比必须清楚：

```text
白桥旧终端与贴近观众
→ 城区标准赛馆
→ 职业甲级观议司直播
→ 宫城比赛殿
→ 万国赛场
```

## 2. 三层镜头

### REALITY

现实身体、键鼠、耳机、设备、队内语音、账本和比赛后果。

### GAME

明清火器工业风地图中的战斗化身、枪械、烟闪雷火和交火。

### OBSERVER

小地图、经济、击杀栏、回放和解说。第一部私训只使用固定记录；南城公开赛只有简化观察者。完整太监解说在城区后进入。

## 3. 第一章导演重点

- Major 赛场规模和失败；
- 休息室静音式复盘；
- `7:5` 音画错位；
- 现代显示器木框化转场；
- 白桥设备间狭窄、旧但真实；
- 周野确认自己的男性身体；
- 白桥四人保持安全距离；
- 赤漆连珠铳第一次出现；
- 第一轮试训失败与第二轮补枪成功；
- 报名表最后一格写下“周野”。

## 4. 场面调度

- 苏禾多在账本、出口和队伍之间移动，体现经营与指挥；
- 江宁与瞄具、侧屏和远距离构图绑定；
- 唐夏靠近训练入口和设备检查区；
- 许安常位于能同时看到门、屏幕和记录的位置；
- 周野开局处于空间边缘，不能自动站到海报中心。

## 5. 动作连续性

- 开枪、拉栓、换弹拆成不同动作帧；
- 投掷物必须有拿出、拉保险、投掷、落点和作用；
- 现实鼠标动作与游戏准星运动对应；
- 补枪失败时先看到准星离位，再看到队友倒下；
- 第二次成功补枪要复用相同构图形成对照。

## 6. 声音设计

优先级：

```text
队内关键报点
> 枪声与脚步
> 设备异常
> 地方解说/观察者
> 环境
> 配乐
```

白桥环境声包括桥板雨声、货船、机柜风扇、旧键帽和铜走线槽轻振。

## 7. 禁止视觉捷径

- 周野醒在女性身体；
- 本地队员与现代队友匹配剪辑；
- 国家队训练院；
- 第一章正式天衡检测；
- 皇帝或宫廷军队来接人；
- 四名女性围住男主制造暧昧；
- 白桥枪馆画成豪华电竞宫殿；
- 游戏枪械变成火绳枪或法器。
