# 天工枪局人类读者优先审核 Skill

## 1. 审核目标

判断章节是否：

- 普通读者看得懂人物、目标和风险；
- 电竞读者认可人数、经济、补枪和报点；
- 长篇读者愿意追随从民间到国家队的升级；
- 女性角色不是镜像、陪衬或福利；
- 清制世界不是古风词语堆砌。

## 2. 隔离盲读

第一轮只读待审章节，不读作者说明。回答：

1. 主角现在想得到什么？
2. 不成功会失去什么？
3. 本章最重要的选择是谁做的？
4. 白桥五人能否区分？
5. 比赛或训练改变了什么？
6. 结尾是否给出具体下一步？

无法回答即视为正文问题，不用设定文档替正文辩护。

## 3. 职业审核

检查：

- 人数和位置是否连续；
- 信息来自看见、听见还是推测；
- 投掷物落点和作用是否合理；
- 补枪距离是否成立；
- 经济选择是否影响下一轮；
- 本地枪械差异是否真实影响手感；
- 周野的现代经验是否既有用又有限；
- 对手是否具有正常战术目标。

## 4. 成长层级审核

第一部不能提前出现：

- 职业乙级正式赛籍；
- 天衡正式通过；
- 国家队试训；
- 皇帝亲自保送；
- 国土级赌注；
- 完整万国群像。

允许通过海报、新闻和直播远景建立更高层级，但周野不能越级进入。

## 5. 人物审核

### 周野

不能自动正确、自动适应或以男性身份获得位置。

### 苏禾

必须同时是经营者和 IGL，决策要落到账本与战术。

### 江宁

不能只剩冷脸和狙击高光，重狙经济与维修家庭必须影响选择。

### 唐夏

不能只会冲锋，入口要有烟闪、补枪和拒绝权。

### 许安

不能靠神秘直觉全知，信息来源与合法性要可复核。

## 6. 性别与尊严审核

直接判退：

- 浴室误闯；
- 不必要身体描写；
- 集体脸红；
- 四名女性围绕男主争宠；
- “男人来拯救女队”；
- “女性职业体系只是因为没有男人”；
- 把虚构天衡设定冒充现实科学。

## 7. 旧正史扫描

检查活跃正文与生产文档是否回流：

```text
谢晚失踪
第五席替换
同名女性队友
玄旗队开局
第一章天衡通过
男魂女身
```

设计归档可说明废止历史，正式正文和人物设定不得使用。
