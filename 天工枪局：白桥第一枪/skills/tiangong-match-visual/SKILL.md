# 天工枪局比赛视觉 Skill

## 1. 当前生产阶段

第一部优先生产：

1. 白桥枪馆现实场景；
2. 白桥队民间比赛服；
3. 白桥货栈、南城会馆、东平码头、小票号；
4. 赤漆连珠铳、望山重狙和基础烟闪雷火；
5. 普通终端 UI；
6. 南城公开赛简化观察者层。

宫城比赛殿、国家队玄旗、正式天衡 UI 和万国赛场只作为远景概念，不抢先生产主资产。

## 2. 地图设计

地图必须先有：

- 攻守出生区；
- 甲阵、乙阵；
- 主信息线；
- 长短视线；
- 主轮转和快速回防；
- 烟雾切线、震声雷进入、火油封路和瓷雷清点空间；
- 普通观众能复述的地标。

### 白桥货栈

木桥中线、河岸侧路、货棚近点、账房二层、仓门回防。木板回声是战术机制，不是装饰。

### 南城会馆

演武院中庭、客房短道、侧巷、屋脊通道。重点是多入口和晚段信息。

## 3. 枪械规则

现代机械结构硬锁：枪管、机匣、导气、弹匣、枪托、瞄具、抛壳、换弹和握持必须正确。

材料：乌木、黑化钢、黄铜、牛皮、漆器、少量景泰蓝。

禁止：火绳枪、燧发枪、弓弩、法器、蒸汽朋克管线、龙头枪口、满枪黄金。

## 4. 白桥装备层级

白桥队使用：

- 租用、维修和旧型号器材；
- 枪身真实磨损；
- 不统一的耳机和鼠标；
- 灰白桥纹小型编号片；
- 玄灰短袍与少量绛红识别；
- 不使用国家队豪华鎏金版本。

装备升级应随职业层级可见，而不是第一章全部顶配。

## 5. 比赛化身

- 复用人物身份母版脸型、发型和体态；
- 收袖短袍，腰侧整合弹匣和道具；
- 周野为男性战斗化身；
- 苏禾、江宁、唐夏、许安为独立女性化身；
- 不把任何人设计成现代队友性转版本；
- 枪械与人物可分层贴图，手部握持准确。

## 6. UI

民间普通终端：

- 竹筹经济；
- 简化军令牌状态；
- 沙盘小地图；
- 铜钟倒计时；
- 磨损但清晰的界面；
- 精确姓名、比分和经济后期合成。

后续职业层逐步增加火漆封存、观议司击杀栏、完整回放和太监解说版式。

## 7. 观察者

- 白桥私训：无解说，只显示记录；
- 南城公开赛：地方观察者和基础 UI；
- 城区：观议司地方制作和太监解说进入；
- 甲级/宫城：完整四岗位；
- 万国：跨国版本。

## 9. 验收

- 三秒内能读出地图主线；
- 枪械能真实握持和换弹；
- 白桥看起来是基层枪馆而非宫廷豪门；
- 角色位置和性别正确；
- 现代类比只属于周野内心；
- 没有旧第五席、同名女队和国家队开局视觉。
