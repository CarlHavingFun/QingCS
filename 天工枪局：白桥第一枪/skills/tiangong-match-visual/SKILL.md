# 天工枪局比赛视觉 Skill

## 1. 第一部优先级

1. 白桥枪馆现实场景；
2. 白桥货栈两轮试训；
3. 白桥队民间比赛服；
4. 赤漆连珠铳、望山重狙与基础烟闪雷火；
5. 普通终端 UI；
6. 南城公开赛简化观察者层。

宫城比赛殿、国家队玄旗、正式天衡 UI 与万国赛场不抢先生产。

## 2. 白桥货栈

地图必须可读：

- 攻守出生区；
- 甲阵、乙阵；
- 木桥中线；
- 河岸侧路；
- 货棚近点；
- 账房二层；
- 仓门回防；
- 主轮转与快速回防；
- 烟雾切线、震声雷进入、火油封路和瓷雷清点空间。

木板回声是战术机制，不是装饰。

## 3. 枪械规则

现代机械结构硬锁：枪管、机匣、导气、弹匣、枪托、瞄具、抛壳、换弹与握持必须正确。

材料：乌木、黑化钢、黄铜、牛皮、漆器、少量景泰蓝。

禁止：火绳枪、燧发枪、弓弩、法器、蒸汽朋克管线、龙头枪口和满枪黄金。

## 4. 第一章试训对照

### 失败

- 周野按现代落点投掷；
- 震声雷撞木梁提前爆；
- 唐夏近点首接触；
- 周野听见右廊却不先报；
- 准星提前离开近点；
- 两人倒下。

### 成功

- 周野先分级报告右廊；
- 使用白桥本地图投掷线；
- 准星留近点；
- 完成补枪；
- 脚步确认到门；
- 再转右廊。

两张正式效果图位于 `视觉资产/场景效果图/03_第一次试训失败.jpg` 与 `04_第二次试训成功.jpg`。

## 5. 比赛化身

- 复用正式三视图的脸型、发型和体态；
- 收袖短袍，腰侧整合弹匣和道具；
- 周野明确为男性；
- 四名队友为独立女性化身；
- 枪械与人物可分层生产；
- 手部握持准确；
- 不把本地人物设计成现代队友性转版本。

## 6. UI

民间普通终端：

- 竹筹经济；
- 简化军令牌状态；
- 沙盘小地图；
- 铜钟倒计时；
- 磨损但清晰；
- 精确姓名、比分和经济后期合成。

## 7. 验收

- 三秒内读出地图主线；
- 枪械可真实握持和换弹；
- 白桥是基层枪馆，不是宫廷豪门；
- 第一遍与第二遍的条件差异可见；
- 角色位置、性别与镜头轴线正确；
- 正式资产不增加版本化文件名。
