# 《天工枪局：白桥第一枪》

这是 QingCS 仓库唯一的新正史小说与漫剧工程。主品牌为 **《天工枪局》**，本目录对应第一部 **《白桥第一枪》**。

## 一句话故事

现代 CS 职业选手周野输掉 Major 后，以自己的男性身体独自穿入架空大曜。他没有身份、赛籍、账号、住处或国家队保送，只能在曜京南城白桥枪馆取得七日临时客籍，与苏禾、江宁、唐夏、许安组成临时民间队，从一场关系到食宿和枪馆存亡的公开赛重新开始。

## 正史硬锁

- 大曜采用清制审美与现代工业并行发展的架空社会，不是历史清朝；
- 穿越前游戏称 CS，穿越后原创游戏称《天工枪局》；
- 周野是唯一穿越者，始终使用自己的二十四岁男性身体；
- 现代队友只存在于穿越前，不在大曜生成同名、同脸、性转或位置镜像角色；
- 第一支队伍是白桥队，核心队员为周野、苏禾、江宁、唐夏、许安；
- 第一部从普通终端、民间枪馆和南城公开赛起步；
- 天衡检测、职业赛籍、国家队与万国枪赛必须靠后续成绩和程序获得；
- 比赛始终结算局内账、队务账与现实账。
