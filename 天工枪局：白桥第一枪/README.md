# 《天工枪局：白桥第一枪》

这是 QingCS 仓库当前唯一的新正史小说工程。主品牌为 **《天工枪局》**，本目录对应第一部 **《白桥第一枪》**。

## 一句话故事

现代 CS 职业选手周野输掉 Major 决赛后，连同自己的男性身体与亚军奖牌独自穿入架空大曜。他没有身份、赛籍、账号、住处或国家队保送，只能在曜京南城的白桥枪馆取得七日临时客籍，与苏禾、江宁、唐夏、许安组成临时民间队，从一场关系到食宿和枪馆存亡的公开赛重新开始。

## 核心辨识

- 大曜是清制审美与现代工业共同发展的架空国家，不是历史清朝；
- 穿越前游戏称 CS，穿越后原创游戏称《天工枪局》；
- 周野是唯一穿越者，始终使用自己的男性身体；
- 没有人因穿越失踪、被替换或被夺取身体；
- 现代队友只存在于现代 Major 段，穿越后队友全部重新认识；
- 第一支队伍是白桥队，四名本地女性队友为苏禾、江宁、唐夏、许安；
- 成长路线为民间枪馆赛、城区联赛、职业乙级、职业甲级、宫城选拔、国家集训、万国枪赛；
- 周野成为“唯一通过正式检测的男性职业选手”是后续成就，不是第一章赠送身份；
- 比赛始终结算局内账、队务账和现实账；
- 漫剧采用现实赛台、游戏战场、观察者直播三层表现。
