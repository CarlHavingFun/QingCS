# 漫剧三层表现与观察者系统

## 1. 三层画面

### 现实赛台层

表现选手真实身体、键鼠、耳机、队内语音、暂停、设备问题和比赛后的现实反应。

第一部重点是白桥枪馆：旧终端、修补桌面、拥挤走线、观众贴近、临时裁判和有限设备。它与后期宫廷比赛殿形成成长对比。

### 游戏战场层

镜头直接进入《天工枪局》地图，角色以比赛化身进行跑动、架枪、投掷、补枪和残局。地图、武器和道具统一使用明清火器工业风，但战术空间必须清楚。

### 观察者信息层

表现小地图、人数、兵筹、击杀顺序、回放、俯视图、解说和公众版本。观察者只能使用合法公开信息，不能向选手传递敌方位置和隐藏语音。

## 2. 第一部的观察者规模

白桥私下训练没有完整转播团队，不应为了视觉华丽强行安排太监解说。

赛事层级对应：

- 枪馆训练：固定机位、简单回放、队内语音；
- 南城周末杯：地方观察者、一名普通唱局员、基础击杀栏；
- 城区联赛：观议司地方制作、专业观察者和太监解说班逐步进入；
- 职业甲级与宫城赛：完整唱局监、评策监、掌镜监、录局监；
- 万国赛：多语种观察者和跨国公共版本。

## 3. 太监解说岗位

太监解说是观议司的专业职业制度，不是笑料。

| 岗位 | 职责 |
|---|---|
| 唱局监 | 实时交火、人数、时间、掉匣、残局事实 |
| 评策监 | 经济、道具、站位、轮转、补枪链和下一轮代价 |
| 掌镜监 | 第一人称、自由镜头、俯视图和慢放切换 |
| 录局监 | 时间戳、经济曲线、投掷轨迹、击杀顺序和证据索引 |

尊严边界：禁止尖嗓、娘化、猥琐、身体羞辱、跪地解说和谄媚刻板印象。专业差异来自信息、节奏和判断方式。

## 4. 漫剧比赛镜头语法

1. 现实赛台建立场地、选手位置和压力；
2. 键鼠或回合开始音作为转场切点；
3. 进入游戏地图建立甲阵、乙阵和主信息线；
4. 用肩后、第一人称和侧面动作表现交火；
5. 关键失误、高光或设备异常切回现实反应；
6. 观察者层用俯视图或回放解释烟、闪、补枪和残局；
7. 比赛结束必须回到现实执行和人物关系。

## 5. 第一章表现

第一章现代段使用成熟 Major 转播。穿越后的白桥段只需：

- 设备间固定监控；
- 公共回放中的 `7:5`；
- 普通终端试训；
- 苏禾等人的现实观察；
- 赤漆连珠铳训练画面。

不出现完整宫廷赛台、国家队观察者或正式太监解说，以免跳过成长层级。

## 6. 声音优先级

```text
当下队内关键报点
> 枪声、脚步、拆械与回合提示
> 观察者事实解说
> 评策解释
> 环境与观众
> 配乐
```

同一秒不能让所有声音争夺注意力。太监解说必须为关键队内语音和枪声让位。

## 7. UI 与后期

- 生成图只提供军令牌、火漆、竹筹、沙盘和铜钟式版式；
- 精确比分、经济、姓名和地图文字后期合成；
- 民间赛 UI 应简洁、旧但可读；
- 正式赛事 UI 随职业层级升级；
- 禁止伪汉字、随机队标和过度金色装饰。

## 8. 叙事边界

三层表现是漫剧的电影化语法，不代表角色真的进入异空间。正文可以直接写游戏战场动作，但必须让读者知道其对应现实操作、合法信息和赛后后果。
