## 5. 生产顺序

每轮只处理一个 `CURRENT_ASSET`：

1. 读取对应人物三视图或场景效果图；
2. 生一张合成关键帧；
3. 检查身份、空间、手部、枪械和镜头方向；
4. 通过后才进入 H3 视频；
5. 失败结果不进入正式目录，也不在正史目录保留连续版本文件。

## 6. MiniMax 图片命令模板

```bash
mmx image generate \
  --prompt "$(cat prompt.txt)" \
  --aspect-ratio 16:9 \
  --n 1 \
  --out-dir ./output \
  --out-prefix CURRENT_ASSET \
  --non-interactive \
  --quiet
```

需要人物一致性时追加：

```bash
--subject-ref type=character,image=视觉资产/人物三视图/00_周野.jpg
```

所有密钥仅通过 MMX 已保存凭证或安全环境变量使用，不写入命令文档和 Git。
