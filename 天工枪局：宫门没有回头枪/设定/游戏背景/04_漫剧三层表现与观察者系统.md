# 漫剧三层表现与观察者系统

## 1. 三层画面

### 现实赛台层

表现真实身体、键鼠、耳机、队内语音、暂停、裁判、教练和比赛后的现实后果。周野必须保持男性外观和身体比例；陈默、林溪、赵雨、顾遥、纪秋与唐果均为女性，不得因统一古装轮廓产生性别混淆。

### 游戏战场层

镜头进入明清火器工业风地图，以比赛化身表现跑动、架枪、投掷、补枪、残局和地图机关。化身身份与现实选手一一对应，不变性别，不互换身体。

### 观察者信息层

表现比分、兵筹、击杀、地图、回放、太监解说和公众版本。观察者信息不得传回选手。

## 2. 同名人物的视听消歧

现代回忆与大曜比赛出现同名人物时，至少使用两项区别：

- 世界环境：北港现代场馆 / 大曜宫廷赛台；
- 性别与声线；
- 队服与旗色；
- 镜头字幕：“现代·陈默”或“大曜·陈默”；
- 周野的称呼变化；
- 不同的动作习惯和关系距离。

禁止仅靠发色或胸牌区分。

## 3. 太监解说岗位

- 唱局监：实时事实、人数、时间、掉包与残局；
- 评策监：经济、道具、轮转、补枪链和下一轮代价；
- 掌镜监：第一人称、自由镜头、俯视图与慢放；
- 录局监：时间戳、经济曲线、投掷物轨迹、击杀顺序和证据索引。

太监是专业从业者，禁止尖嗓、娘化、身体羞辱、猥琐和谄媚刻板印象。

## 4. 唯一男性的镜头边界

- 第一次检测重点是设备数据、在场反应和程序，不拍成身体展示；
- 更衣、医疗、理疗和住宿冲突通过门禁、表格、空间与对话表达；
- 不用误闯浴室、误触身体和集体害羞制造笑点；
- 周野与女队友的接近必须有战术、照护或明确同意；
- 观议司不得未经同意直播周野的完整生理数据；
- “历史首位男性通过者”可以成为新闻，但不能覆盖谢晚失踪与队伍成绩。

## 5. 比赛镜头语法

```text
现实赛台建立
→ 地图战术全景
→ 角色与枪械识别
→ 第一人称/肩后交火
→ 观察者解释信息与代价
→ 关键选择
→ 回到现实手部、表情和队友反应
→ 赛后回放与现实交接
```

精确比分、经济、地图名和击杀文字统一后期合成，生成图只留安全区域。

## 6. 声音优先级

1. 当前角色必须听见的队内语音；
2. 枪声、脚步、投掷物与目标装置；
3. 太监解说；
4. 观众与环境；
5. 内心独白。

关键报点时解说让位；内心独白不能盖住决定胜负的信息。

## 7. 失败诊断

- 只见古装人物坐电脑前：缺游戏战场层；
- 只有枪战没有键鼠与赛后：缺现实赛台层；
- 解说像全知旁白：缺观察者权限边界；
- 四名同名女性像现代队友性转复制：缺独立人格与生活；
- 周野镜头总在女性包围中心：出现后宫化；
- 检测绿字直接变首发名单：违反资格与阵容分离。
