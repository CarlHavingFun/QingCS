# 比赛制度与现实后果

## 1. 核心原则

比赛必须有前因后果。任何正式赛都不能只留下比分、高光和一句“我们赢了”。每张地图开始前要写明押上的现实权益，结束后要执行交接、申诉、资源调整和人物关系变化。

## 2. 赛约

赛约至少包含双方队伍、名单、替补、教练、地图池、禁选、服务器、现实权益、兵筹规则、暂停、设备故障、数据授权、违约、申诉、交接和民生最低保护线。

皇帝、票盟和百兵会可以谈判赛约，签署后都必须受约束。

## 3. 权益不是永久割地

现实权益采用有限合同：

- 管理权：某道城门、仓区或会馆一季内的训练与调度；
- 优先权：火药、设备、运河时段、保险和情报顺位；
- 席位权：下一阶段赛事、规则议会或地图测试名额；
- 开放权：地图模型、旧档案和跨境数据访问范围；
- 收益权：门票、直播、物流或贸易的一定比例。

主权、居民基本权利和不可替代公共安全不能被一场比赛随意转让。

## 4. 三本账

- **局内账**：兵筹、枪械、护甲、烟闪雷火、保枪、掉枪、连败补偿；
- **队务账**：火药配额、设备信用、训练时段、工资保险、健康、合同和数据权限；
- **现实账**：城门、运河、粮仓、票号、会馆权益，联盟、家庭担保、舆论和归途线索。

## 5. 回合后果传导

```text
输掉关键回合
→ 经济崩坏或核心枪械丢失
→ 输掉地图
→ 赛约权益触发
→ 机构执行交接
→ 家庭、民生、政治与下一场受影响
```

## 6. 唯一男性与席位程序

周野的天衡检测属于资格问题，不属于阵容自动变更。完整路径是：

```text
短时稳态通过
→ 医务观察
→ 完整天衡复核
→ 临时身份与赛籍申请
→ 公开试训
→ 教练提案
→ 队伍与赛务程序
→ 才可能进入某张图名单
```

谢晚失踪期间，她的合同、设备、数据、家庭权益和申诉权继续封存保护。唐果作为注册替补拥有正常竞争权。任何机构不得用“唯一男性宣传价值”越过流程。

## 7. 人物决定外溢

- 陈默的强起、暂停、保枪和公开担责影响承天门旧案与队长权；
- 林溪的数据授权和重狙资源影响票号与个人权利；
- 赵雨是否接受无条件先死影响火器营英雄叙事和兄长旧事故；
- 顾遥是否公开来源影响会馆网络和合法情报机制；
- 周野是否把同名女性当替身、是否尊重谢晚资料、是否接受宣传包装，影响队伍信任与制度改革；
- 谢晚失踪前的选择持续改变调查权限和现实责任。

## 8. 胜败处理

获胜后至少处理：谁获得权益、谁负责交接、谁得到功劳或背负代价、下一场增加什么限制。失败也必须推动地图池、人员分工、家庭利益、申诉或地下赛路径，不能只虐主。
