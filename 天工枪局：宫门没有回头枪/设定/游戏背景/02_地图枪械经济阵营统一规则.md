# 地图、枪械、经济与阵营统一规则

## 1. 统一设计原则

《天工枪局》的地图、枪械、UI、经济和阵营不是五套互不相关的古风皮肤。它们都来自同一个世界的工业、制度和利益分配：

- 地图对应现实资产与空间；
- 枪械对应工造体系和职业功能；
- 兵筹对应局内风险；
- 火银、火药配额和设备信用对应队务资源；
- 阵营纹样对应背后的朝廷、商会、会馆或外邦组织；
- 比赛结果通过国运簿进入现实交接。

## 2. 地图系统

### 2.1 地图不是现实战场直播

正式地图是经测绘、授权和竞技平衡重构后的数字镜像。它可以取材现实宫门、瓮城、会馆、票号、粮仓、运河、火器营和机造局，但不能复制安保细节或让比赛直接控制真实武器。

### 2.2 地图必须同时具备

- 攻方与守方出生区；
- 甲阵与乙阵两个目标区；
- 主信息线、中路或等价控制区；
- 长视线与近距离争夺；
- 主轮转、快速回防和高风险侧线；
- 烟雾切线、闪光进入、火油封路和破片清点的空间；
- 可被太监解说和普通读者复述的地标。

### 2.3 第一批地图池

| 地图 | 空间语言 | 核心战术 | 现实权益示例 |
|---|---|---|---|
| 承天瓮城 | 宫门、双重门洞、城墙马道 | 中门长线、甲门长道、乙门地道 | 承天门外城的赛季训练与通行调度权 |
| 南漕粮台 | 运河、粮仓、栈桥、吊机 | 水陆双线、仓内近战、桥面回防 | 粮仓装卸时段与南漕护运合同 |
| 四海票号 | 票厅、金库、后巷、账房 | 中庭控制、上下层夹击、狭窄金库 | 跨境结算额度与数据托管权 |
| 神机火营 | 机造厂、试射台、地下维护道 | 长线狙击、厂房轮转、机关门时序 | 火药配额与设备维修优先级 |
| 百兵会馆 | 演武院、客房、兵器库、屋脊通道 | 多入口默认、晚段侧线、声音欺骗 | 地方青训席位与枪坊牌照 |
| 北关票路 | 关隘、驿站、货车、雪沟 | 远点信息、狭长回防、补给车掩体 | 北境商路保险与护运协定 |

每张地图的现实权益必须是有限、季节性、可交接的制度权利，而不是输一局就永久割让领土。

## 3. 枪械系统

### 3.1 机械硬锁

枪械必须保持现代可工作的功能结构：枪管、机匣、弹匣、枪托、瞄具、抛壳、散热、换弹和握持路径清楚。明清工艺只能改变材料、表面、护木、纹样和附件外观。

禁止把枪械改成：火绳枪、燧发枪、鸟铳、弓弩、法器、蒸汽朋克装置、满身珠宝的礼器或无法握持的龙形雕塑。

### 3.2 材料语言

- 乌木：枪托、握把与耐磨护木；
- 黑化钢/乌铁：枪管、机匣与受力结构；
- 黄铜：小型包角、编号片、接口和保护件；
- 少量鎏金：冠军版、皇室礼仪版的非受力细节，不能满枪覆盖；
- 牛皮：枪带、贴腮垫和工具套；
- 漆器：护木与识别色；
- 景泰蓝：极小面积的队伍识别片，不进入枪管、扳机和散热区。

### 3.3 通用枪名

| 周烬的现代类比 | 大曜通用名 | 定位 |
|---|---|---|
| AK | 赤漆连珠铳 | 进攻方主力步枪，威力高、后坐明显 |
| M4A4 | 玄甲镇门铳 | 守方稳定连发步枪 |
| M4A1-S | 玄甲静锋铳 | 低声、低弹量守方步枪 |
| AWP | 望山重狙 | 高价值栓动重狙 |
| SSG 08 | 游隼轻狙 | 轻量经济狙击枪 |
| Desert Eagle | 金翎重铳 | 高威力重型手枪 |
| USP-S | 夜巡静铳 | 守方消音手枪 |
| Glock | 轻骑连铳 | 进攻方基础手枪 |

人物对话初次可说全名，交火中应缩短为“赤漆”“重狙”“静铳”等可懂短词；主角内心可继续用 AK、AWP 等现代参照。

## 4. 战术道具

| 大曜名称 | 现代功能 | 视觉语言 |
|---|---|---|
| 烟雾罐 | 烟雾弹 | 黑铁罐体、玉白识别环、稳定灰白烟墙 |
| 震声雷 | 闪光弹 | 银白识别环、瞬时强光与震响 |
| 火油瓶 | 燃烧弹 | 厚壁瓶体、阻燃套、可读地面火区 |
| 破片瓷雷 | 高爆手雷 | 内部金属破片、外层耐冲瓷甲；不是古代陶罐 |
| 火药匣 | C4 类目标装置 | 现代电子计时、线束、漆木保护框与铜扣 |
| 拆械匣 | 拆弹器 | 剪线钳、探针、绝缘工具与计时器 |

道具必须有清楚尺寸、拉环、保险、投掷和落点，不出现仙雾、凤凰火、雷法符咒或神秘发光核心。

## 5. UI 与信息语言

### 5.1 视觉外壳

- 军令牌：选手状态、枪械和护甲；
- 火漆：暂停、申诉、回放封存状态；
- 竹筹：兵筹和购买；
- 兵部文书：赛前名单、地图权益和赛务回执；
- 沙盘：小地图、投掷轨迹和轮转；
- 铜钟/更刻：回合与火药匣倒计时。

### 5.2 可读性

UI 仍要让现代观众快速读出人数、时间、经济、道具、甲乙阵和击杀顺序。生成图只做版式与短标签，精确文字和数据后期合成。禁止伪汉字和为了古风牺牲信息密度。

## 6. 经济系统

### 6.1 局内兵筹

兵筹只在地图内结算，用于购买枪械、护甲和道具。它遵循清晰的胜负奖励、连败补偿、击杀收益和保枪规则。

### 6.2 队务资源

- 火药配额：训练与正式赛的道具、弹药模拟和枪械认证额度；
- 设备信用：维修、升级、训练服务器和备用设备优先级；
- 火银：工资、赞助、差旅、保险和违约结算；
- 训练时段：高质量服务器、地图和教练资源；
- 数据权限：回放、地图模型和对手研究范围。

输掉一个普通回合不会凭空扣现实火药，但连续表现、赛约条款和地图结果会改变下一阶段配额。小说必须写清中间流程。

### 6.3 三本账接口

```text
回合选择
  → 兵筹与枪械变化
  → 地图胜负概率
  → 队伍赛季信用与资源
  → 现实权益交接
  → 家族、机构和下一场限制
```

## 7. 阵营识别

阵营不穿现代印花队服，以以下元素区分：

- 主旗色与副色；
- 补服位置和纹样；
- 腰牌形状与材料；
- 轻甲、护腕、肩片和枪带；
- 枪械上的小型编号片；
- 战斗化身的轮廓、发型和职业动作。

玄旗队主色为玄黑、深绛与克制铜金。外邦和商会队必须有自己的制度来源，不能只换颜色。

## 8. 生产 QC

每个新地图或武器资产交付前检查：

- 是否先有战术功能再有装饰；
- 是否能在三秒内读出甲阵、乙阵和主信息线；
- 枪械是否仍能真实握持、瞄准、换弹和抛壳；
- 经济是否同时解释局内与现实接口；
- 阵营识别是否不用现实品牌、队标和赞助商；
- 主角的现代类比是否只属于内心/研究层，没有取代本世界公开专名。
