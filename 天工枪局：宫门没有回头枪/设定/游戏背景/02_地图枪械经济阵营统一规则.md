# 地图、枪械、经济与阵营统一规则

## 1. 权契图

正式地图称 `权契图`。每张图有独立战术骨架，也映射一类受限现实权益。

| 地图 | 空间语言 | 战术重点 | 现实权益示例 |
|---|---|---|---|
| 朔漠关 | 边关、瓮城、烽燧、运兵洞 | 双门长线、A 长、地下 B 路 | 边关查验时段 |
| 丹阙城 | 王城外廓、商市、马厩、内院 | 中路控制、窗口与快速轮转 | 城门商货通行额 |
| 烟雨府 | 江南府城、窄巷、祠堂、粮道 | 近距争夺、回防岔路 | 地方粮仓调度 |
| 天工局 | 机造总局、上下厂房、管线、机库 | 垂直声学、上下层夹击 | 军械维修订单 |
| 玄陵 | 皇陵外城、祭台、甬道、石兽道 | 远近混合、地下绕后 | 文物护运与勘测权 |
| 漕铁驿 | 铁轨、货栈、龙门吊、军需仓 | 多线穿插、长货道 | 漕运装卸时段 |
| 御河桥 | 水道、桥面、闸房、岸仓 | 水声掩护、桥下回防 | 运河闸口优先权 |
| 凌霄台 | 营造工地、脚手架、吊装台 | 高低差、声音与风险侧线 | 城建供应合同 |

现实权益必须有期限、地域和用途，不转移人民、司法或完整领土主权。

## 2. 地图设计硬锁

每张地图必须明确：

```text
攻方出生区
守方出生区
甲点
乙点
中路
长视线
近距离争夺区
主轮转
高风险侧线
烟雾切割面
闪光进入点
火油封锁面
高低差与声音关系
```

没有这些字段，不能只凭“古风好看”进入生产。

## 3. 枪械体系

枪械保留现代功能结构，采用大曜工艺与原创式样名。

| 功能 | 公开称呼 | 视觉材料 | 周烬内心类比 |
|---|---|---|---|
| 进攻方主步枪 | 云雷铳 | 黑钢、赤漆乌木、黄铜小包角 | AK |
| 守方主步枪 | 玄甲铳 | 深黛复合材料、乌木、低反光铜箍 | M4 |
| 重型狙击 | 望山狙 | 长枪管、灰白硬木、铜镜筒 | AWP |
| 重型手枪 | 金翎重铳 | 黑钢、牛皮握把、克制黄铜 | 沙鹰 |
| 消音手枪 | 夜巡铳 | 黑钢、乌木、细长消音组件 | USP-S |
| 轻型冲锋枪 | 宫门疾铳 | 紧凑机匣、黑铁、短木护板 | MP9 类 |
| 震城装置 | 震城匣 | 现代电子结构、漆木护框、铜扣 | C4 |
| 拆除工具 | 拆械匣 | 剪线钳、探针、绝缘工具 | 拆弹器 |

异世界人物只说公开称呼或短称：“云雷”“望山”“火匣”。首次视觉亮相可以写完整式样名，交火时保持短促。

## 4. 战术道具

- `烟雾罐`：形成稳定遮挡，受风口、湿度和空间影响；
- `震声雷`：短时强光与震声，功能对应闪光控制；
- `火油瓶`：形成持续地面火区；
- `破片瓷雷`：以破片与冲击造成范围伤害；
- `诱声筹`：在部分赛事允许制造短暂假声；
- `拆械匣`：缩短拆除时间。

道具不能变成仙法、龙形烟雾、雷电召唤或追踪法术。

## 5. 兵筹经济

每名选手每回合拥有兵筹账户。兵筹来源：

- 回合基础配给；
- 击杀、安放、拆除和胜负奖励；
- 连败补偿；
- 赛事限定的队伍共享调整。

兵筹只在一张地图/一场比赛中使用。队务火药配额是赛外资源，不能直接兑换成无限局内兵筹。

经济选择包括：

- 全起：护甲、主枪和完整道具；
- 半起：保留下一轮购买能力；
- 强起：以未来经济换当前回合；
- 经济局：低投入争取掉枪、安放或伤害；
- 保枪：放弃低概率回防，保存下一轮资源。

## 6. 阵营识别

队伍不用现代运动队服，而使用：

- 旗色；
- 补服纹样；
- 腰牌形制；
- 轻甲边线；
- 枪带与弹匣识别片；
- 战斗化身肩标。

同队五人仍需通过发型、体态、职责装备和动作区别，不能只靠换颜色。

## 7. UI 语言

- 回合比分：军令牌式左右栏；
- 经济：竹筹与火银刻度；
- 装备：兵部器械文书式图标；
- 小地图：沙盘/城图式轮廓；
- 回放：卷宗时间轴与火漆标记；
- 暂停：令牌插入与钟声提示。

精确数字、姓名、地图名和击杀栏在漫剧中以后期合成为主，生图只保留安全区。

## 8. 材料边界

允许：乌木、黄铜、少量鎏金、牛皮、漆器、景泰蓝、黑钢、深黛复合材料。  
禁止：满枪珠宝、巨大龙头、蒸汽管线、霓虹赛博、火绳结构、弓弩替代和不可能操作的装饰。
