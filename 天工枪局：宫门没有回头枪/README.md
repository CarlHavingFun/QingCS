# 《天工枪局：宫门没有回头枪》

这是 QingCS 仓库的全量重启主线，也是后续小说、漫剧、视觉资产与衍生项目的唯一新正史入口。

## 一句话故事

现代 CS 职业选手周烬输掉 Major 决赛后，意识落入架空大曜朝玄旗队首发谢照夜的身体。他以为现代战术足够横扫异世界，却发现这里的《天工枪局》已经发展数百年：枪手、机关、地图契约与经济体系都比他预想得成熟，而每一场胜负都会改变城门、运河、仓储、商路、家族命运，以及他是否能找到回到现代的路。

## 核心辨识

- 架空清制王朝，不是历史清朝；
- 原创皇帝、国家、机构、势力、游戏、战队和职业选手；
- 穿越前游戏称 CS，穿越后称《天工枪局》；
- 朝廷、四海票盟与百兵会共同操盘万国天工枪赛；
- 地图、枪械、经济、阵营、社会和人物成长属于同一套规则；
- 比赛输赢会改变现实权益，赛后必须留下政治、家族或资源后果；
- 漫剧表现采用现实赛台、游戏战场、观察者直播三层画面；
- 第一人称职业现实主义：先写事实、动作和代价，再写判断与情绪。
