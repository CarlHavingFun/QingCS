# 《天工枪局：宫门没有回头枪》

这是 QingCS 仓库的全量重启主线，也是后续小说、漫剧、视觉资产与衍生项目的唯一新正史入口。

## 一句话故事

现代男性 CS 职业选手周野输掉 Major 决赛后，以自己的身体独自穿越到架空大曜朝。他出现在玄旗队第五席谢晚失踪的位置，面对四名与现代男队友同名、同位置的女性职业选手，并成为这个世界开局唯一通过顶级天衡检测的男性玩家。他想回家，就必须先查清谢晚、`7:5` 和两支镜像队伍之间的关系，再靠真实比赛争取一张并不属于他的席位。

## 核心辨识

- 架空清制王朝，不是历史清朝；
- 原创皇帝、国家、机构、势力、游戏、战队和职业选手；
- 穿越前游戏称 CS，穿越后称《天工枪局》；
- 主角是男性肉身、唯一穿越者，不是男魂女身；
- 现代四名男队友留在现代，大曜四名同名女选手是独立本地人；
- 谢晚是失踪的原第五人，周野通过检测也不能自动继承她的席位；
- 朝廷、四海票盟与百兵会共同影响万国天工枪赛；
- 地图、枪械、经济、阵营、社会和人物成长属于同一套规则；
- 比赛输赢会改变现实权益，赛后必须留下政治、家族或资源后果；
- 漫剧采用现实赛台、游戏战场、观察者直播三层画面；
- 第一人称职业现实主义：先写事实、动作和代价，再写判断与情绪。
