# 男性肉身穿越与同名女队重构设计

## 1. 目标

将《天工枪局：宫门没有回头枪》的主角设定从“现代男性意识进入大曜女性身体”改为：

- 周野以自己的男性肉身独自穿越；
- 现代四名男队友陈默、林溪、赵雨、顾遥留在现代；
- 大曜玄旗队存在四名同名、同位置但不同人生的女性本地选手；
- 大曜原第五人谢晚在 `7:5` 异常发生时失踪；
- 周野出现在谢晚最后连接终端的位置；
- 周野是故事开局唯一通过最高级天衡检测的男性玩家；
- 通过检测只获得试训与申请赛照的资格，不自动继承谢晚席位。

## 2. 核心人物命名

核心人物采用“常用姓＋常用名”的折中命名，古风感由服装、制度、地图、武器和机构承担。

| 旧名 | 新名 | 新身份 |
|---|---|---|
| 周烬 | 周野 | 现代男性职业选手、唯一穿越者 |
| 谢照夜 | 谢晚 | 大曜女性二号位、失踪者 |
| 裴镇霜 | 陈默 | 大曜女性队长；现代另有同名男队长 |
| 闻青砚 | 林溪 | 大曜女性主狙；现代另有同名男主狙 |
| 霍长缨 | 赵雨 | 大曜女性首接触；现代另有同名男突破手 |
| 陆停云 | 顾遥 | 大曜女性游走；现代另有同名男断后位 |

| 唐照野 | 唐果 | 玄旗队女性替补 |

四组同名人物只共享姓名、战术位置和一个可见习惯，不共享记忆、家庭、性格、履历、关系或命运。

## 3. 两支队伍的对应结构

```text
现代男队                         大曜女队
陈默，队长 / IGL          ↔      陈默，队长 / IGL
林溪，主狙                ↔      林溪，主狙
赵雨，突破                ↔      赵雨，首接触
顾遥，断后 / 游走         ↔      顾遥，游走 / 晚段信息

周野，二号位              ×      谢晚，二号位
```

前四组是“镜像对应位”，第五席是“错位位”。`7:5` 异常、谢晚失踪和周野穿越都围绕第五席发生。

## 4. 穿越规则

- 只有周野穿越，现代四名男队友仍在北港体育馆；
- 周野携带自己的身体、现代队服、手机和亚军奖牌；
- 周野不会获得本地人的记忆、赛籍、门禁或合同；
- 谢晚并未被证明死亡，其去向是第一部主谜题；
- 周野和谢晚不能被写成灵魂互换的既定结论；
- 周野出现前，谢晚已经记录过 `7:5`、半拍音画错位和现代男队的四个同名名字。

## 5. 唯一男性检测规则

顶级职业赛使用天衡竞赛终端。规则表面不按性别禁赛，而是要求取得神经稳态赛照。历史终端长期按女性样本校准，本地男性高概率出现“天衡眩振”，因此顶级职业选手事实上全部为女性。

周野的跨时空神经相位与终端异常同步，使他成为开局唯一通过检测的男性玩家。第一章只完成短时检测：

```text
生理性别：男
本地赛籍：无
短时神经稳态：通过
正式赛照：未取得
```

三日后才能进行完整资格复核。检测通过不等于：

- 自动进入玄旗队；
- 自动继承谢晚席位；
- 枪法或体能强于女性；
- 成为男性群体的天然代表；
- 获得系统、预知或特殊能力。

## 6. 性别冲突的长期写法

性别差异必须进入流程和关系，而不是只用于暧昧：

- 女队封闭训练区突然出现陌生男性，先执行安全、医务、门禁和证据封存；
- 更衣、洗浴、住宿、医疗、理疗和宣传拍摄设置明确边界；
- 周野不能以“我认识另一个你”为由越过身体接触与私人资料边界；
- 四名女性对周野保持不同态度，不统一害羞或排斥；
- 外界会把周野包装成改革符号、男性救世主或抢席者，队伍必须共同反对；
- 周野获得认可的唯一途径是训练纪律、报点、补枪、尊重谢晚和实际比赛表现。

## 7. 第一章重构

第一章前半保留 Major 决赛、半拍失误、队内复盘、`7:5` 异常和亚军奖牌物证，只替换现代队员姓名。

穿越后改为：

1. 周野以男性肉身出现在玄旗训练室；
2. 谢晚的座位空着，终端仍连接，人员无法定位；
3. 四名女性依次自报陈默、林溪、赵雨、顾遥；
4. 周野因同名、同位置和相似习惯产生错认；
5. 她们明确自己从未见过周野，并怀疑他与谢晚失踪有关；
6. 设备完成短时天衡检测，周野成为首位通过的男性；
7. 女陈默明确：通过检测只代表能坐上赛台，不代表谢晚席位归他；
8. 三日后的完整复核与东掖旧服访问权绑定，形成下一章倒计时。

## 8. 角色关系基调

- 陈默：承认检测事实，不承认周野已是队友；
- 林溪：最保护谢晚的设备、回放与私人资料；
- 赵雨：不纠结周野性别，直接用补枪训练判断价值；
- 顾遥：最早察觉机构和舆论准备利用“唯一男选手”；
- 纪秋：坚持医务、赛籍、住宿、接触和试训流程；
- 谢晚：缺席但持续通过记录、家族和回放推动剧情。

第一部核心关系不是后宫，而是“相似名字造成错认，独立人生迫使重新认识”。

## 9. 公开层禁写

- 男魂进入女身；
- 四名女性其实是现代男队友性转穿越；
- 周野因男性身份天然更强；
- 女队等待男性拯救；
- 通过检测立即获得首发；
- 用洗浴、更衣或误触制造低俗福利；
- 谢晚只是给男主腾位置的工具人；
- 以现实医学解释虚构天衡眩振；
- 用同名直接复制现实选手履历、性格和经典桥段。

## 10. 验收标准

新正史公开文本必须满足：

- 主角公开名统一为周野；
- 现代四队友与大曜四女队友统一为陈默、林溪、赵雨、顾遥；
- 大曜原第五人统一为谢晚；
- 周野明确为男性肉身、唯一穿越者和开局唯一通过检测的男性玩家；
- 第一章无女性身体、女声、长发、银簪或“登记身份是谢晚”等旧桥段；
- 新正文目录只有重构后的第一章；
- 旧姓名只允许出现在内部迁移索引或历史源目录；
- 六项 Skill 全部读取新规则；
- 视觉资产文件名与公开角色名一致。
