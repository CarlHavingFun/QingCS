## 2. IP 与专名

### 2.1 正式书名

**《天工枪局：宫门没有回头枪》**

- `天工枪局`：可独立识别的世界与游戏 IP 名；
- `宫门没有回头枪`：第一部副标题，强调职业选择、宫廷门槛与枪局后果；

## 3. 世界背景

### 3.1 时代

故事发生在与现代同期的架空世界。主政国家为 **大曜朝**，其礼制、宫城、官署、服章和建筑吸收明清制度视觉，但不是历史清朝，也不存在任何真实皇帝、年号、宗室或历史事件。

- 当代年号：`承曜二十七年`；
- 皇帝：`宣昭帝·祁元熙`，成年原创女性统治者；正文通常称“皇帝”或“陛下”，不以性别标签代替政治角色；
- 宫廷、商会和江湖共同参与枪赛治理，权力必须通过合同、牌照、配额、地图控制权、军械供应和公众舆论落地；
- 所有能力和技术都来自制度、训练、工程与信息，不使用自动改命的系统外挂。

### 3.2 三权格局

- **朝廷**：天工院、军机火器署、赛籍司、观议司；控制国赛牌照、火药配额、城防地图、跨境赛约与公开责任；
- **商会**：四海票盟及其票号、运河、仓储、军械供应链；控制赞助、火银、设备、保险和跨境结算；
- **江湖**：百兵会及地方会馆、枪坊、护运队；掌握民间枪手、地图暗线、机关工艺与地方声望；
- **军方**：火器营负责实物军械、城门与军需，但无权越过联赛规则直接改比分。

三方都需要枪赛，却没有任何一方能单独控制整个游戏生态。

### 3.3 穿越与国运

- 主角周烬是现代男性 CS 职业步枪手，意识进入大曜玄旗队成年女性选手谢照夜的身体；
- 穿越只发生一次，不发放面板、技能或预知；
- 跨时空异常通过回放时间轴、声音错位、比赛日志和不可解释的实物残留推进；
- `国运簿`是赛果与现实权益的公开总账，不是神明数值；
- `天工枢网`是承担比赛、地图镜像、身份认证和回放归档的工程网络；
- 每场关键比赛可能释放一段“归途残片”，但胜利只换来证据，不保证回家。

## 4. 游戏统一规则

### 4.1 游戏本质

《天工枪局》是发展了数百年的五人制职业枪战项目。其战术骨架能让现代 CS 玩家快速理解，但地图、枪械、UI、阵营、经济和现实后果全部原创。现代战术经验是优势，不是碾压外挂；本地职业枪手对机关、声音、材料、地图契约和配额经济的理解远胜初来者。

### 4.2 一局的三本账

每场比赛同时结算：

1. **局内账**：兵筹、枪械、护甲、烟闪雷火、输局奖励、连败补偿；
2. **队务账**：火药配额、设备维护、训练时段、赞助信用和选手合同；
3. **现实账**：城门、运河、仓储、会馆、票路、情报和赛季联盟权益。

任何高光都必须说明这三本账至少改变一项。

### 4.3 比赛后果

- 输掉地图：对应的季节性城门、航道、仓储或会馆控制权转移；
- 输掉关键回合：下一轮兵筹受压，并可能触发队伍火药配额、维修额度或赞助信用下降；
- 获胜：获得地图情报、盟友、合同筹码、现实通行权或归途残片；
- 角色选择：会改变家族、朝廷、商会、江湖和队内关系，不能被比分清零；
- 赛务争议：必须经过回放、印证、申诉和公开责任流程，不由皇帝或电脑一句话裁定。

### 4.4 视觉与交互语言

- 枪械材料：乌木、黄铜、少量鎏金、牛皮、漆器、景泰蓝；机械结构仍为现代可工作的枪械；
- UI：军令牌、火漆、竹筹、兵部文书、沙盘；精确比分和文字以后期合成为主；
- 地图：宫门、瓮城、会馆、票号、粮仓、运河、火器营、机造局；
- 道具：烟雾罐、震声雷、火油瓶、破片瓷雷、拆械匣；
- 阵营：旗色、补服、腰牌、盔甲纹样和枪带，不使用现代队服与现实队标。

### 4.5 比赛画面

采用三层而不是把 UI 画进角色世界：

1. 现实赛台：身体、键鼠、队内语音、暂停和赛后后果；
2. 游戏战场：战斗化身、地图、枪械、道具与交火；
3. 观察者层：OB、太监解说、回放、经济、公众版本。

太监解说是观议司专业岗位，禁止尖嗓、娘化、身体羞辱和谄媚刻板印象；现代枪战口语优先，宫廷报幕只作调味。
