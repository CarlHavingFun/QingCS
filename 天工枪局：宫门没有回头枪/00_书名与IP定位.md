# 书名与 IP 定位

## 正式书名

**《天工枪局：宫门没有回头枪》**

- **主品牌：天工枪局**——既是异世界原创枪战游戏名，也是可跨小说、漫剧、动画、游戏概念与角色资产持续使用的 IP 名；
- **第一部副标题：宫门没有回头枪**——强调一旦进入职业赛、宫门和国运契约，任何一枪都将留下现实后果；
- **平台短名：天工枪局**；
- **英文内部索引：Tiangong Gun Game**，不作为正文可见专名。

## 核心宣传句

> 他以为自己带来的是领先一个时代的战术，后来才发现，这个世界已经把枪赛打了三百年。

## 一句话简介

输掉 Major 决赛后，现代 CS 职业选手周烬醒在大曜玄旗队首发谢照夜的身体里。朝廷、票盟与江湖把城门、运河和火药配额押上《天工枪局》的赛台；他想回家，就必须先学会在一个比他更懂枪局的世界里赢。

## 第一部核心承诺

1. **职业比赛是真的比赛**：有经济、道具、站位、补枪、残局、暂停和赛后复盘；
2. **清制社会是真的社会**：家族、牌照、军需、票号、会馆和皇权都通过具体流程运转；
3. **比赛后果是真的后果**：地图控制权、物资、舆论、合同与关系随胜负改变；
4. **穿越不是外挂**：现代经验提供比较视角，不提供预知、系统或无条件碾压；
5. **人物不是原型换名**：外观母版只提供视觉起点，新姓名、家族、动机、关系和结局全部原创；
6. **漫剧不是屏幕录像**：现实赛台、游戏战场和观察者直播三层交替，让操作直接成为动作戏。

## 长期衍生格式

主品牌固定为《天工枪局》，不同篇章更换副标题：

- 第一部：《宫门没有回头枪》——穿越落地、玄旗队重组、第一张城门地图；
- 第二部：《运河无退路》——票盟、漕运地图与跨城联赛；
- 第三部：《万国赛点》——外邦战队、国赛权益与归途真相；
- 外传可聚焦枪坊、太监解说班、地方会馆、旧赛季和外邦职业联赛。

每一部必须既能独立完成一条比赛与人物弧线，又推进天工枢网、身体原主和归途残片的总谜题。
