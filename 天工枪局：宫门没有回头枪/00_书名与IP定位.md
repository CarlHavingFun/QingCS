# 书名与 IP 定位

## 正式书名

**《天工枪局：宫门没有回头枪》**

`天工枪局` 同时承担游戏名、世界品牌名和系列母标题；`宫门没有回头枪` 是第一部副标题。

## 核心卖点

1. **唯一男性适格者不是外挂，而是一场制度事故。**  
   周烬能被赛台识别，却没有赛籍、队籍、合同和户籍。他首先面对的不是庆功，而是安保隔离、反作弊复核、媒体争夺和队内资格竞争。

2. **本地职业选手不是古人学现代战术。**  
   《天工枪局》发展数百年，大曜与外邦职业选手已经建立自己的默认、道具、补枪、经济和地图学。周烬只在观察框架和现代经验上占优，必须重新学习材料声学、机关结构、权契图和火药配额。

3. **比赛结果会改变世界。**  
   地图不是背景皮肤，而是现实城门、运河、票号、粮仓、会馆和火器营的数字权契。输赢影响经营时段、军需配额、合同信用、家族地位和归途线索。

4. **比赛可以直接变成漫剧。**  
   现实赛台、游戏战场、观察者信息层并行：选手坐在宫廷工业风赛台操作，画面切进清制火器世界中的战斗化身，太监解说和回放为观众解释人数、时间与代价。

5. **穿越悬疑与失踪案绑定。**  
   周烬出现的同一秒，玄旗队女性二号位谢照夜在封闭区域内消失。两人的位置、工位、回放和身份检测互相咬合，但不是灵魂互换。

## 目标体验

读者应同时获得：

- 职业枪战回合的紧张与可复盘性；
- 架空王朝制度和现代工业并存的新鲜感；
- “唯一男性”引发的身份、赛籍与舆论逆袭；
- 队友、对手和家族各自独立的成长；
- 每一场比赛都推动世界格局和回归谜题。

## 不是这些作品

- 不是“现代高手到古代无脑降维打击”；
- 不是系统发任务、抽技能或自动奖励；
- 不是以男性身份自动收获后宫；
- 不是把真实清朝、真实皇帝或真实职业选手换名搬运；
- 不是把现代枪械改成仙侠法器；
- 不是只有枪战高光、比赛结束后世界毫无变化。

## 长期系列接口

- 第一部：宫门与赛籍——取得合法身份，查谢照夜失踪；
- 第二部：运河与票盟——争夺跨境图契和供应链；
- 第三部：万国赛点——进入世界级赛季与归途主线；
- 外传：火器营、票号、百兵会、观议司、太监解说班、地图工程师；
- 漫剧/动画：三层比赛语法与角色外观母版复用；
- 游戏概念：原创地图、武器与经济体系可以独立开发。
