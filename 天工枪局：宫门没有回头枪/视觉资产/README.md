# 视觉资产迁移说明

## 1. 目录用途

本目录保存从历史源复制来的已批准外观母版与场景参考。复制使用原始 Git blob，不重新压缩图片；文件名和正史身份已全部重命名。

## 2. 人物外观母版

`人物外观母版/` 中七张图片只负责：

- 脸型；
- 发型轮廓；
- 肩线、体态和年龄感；
- 三视图版式与材质参考。

图片内旧文字、胸牌、称号、队标、服章含义和职业道具全部失效。新人物身份必须读取 `../人物档案/` 和 `../设定/人物家族背景/`。

标准身份母版继续遵循：

- 成年原创人物；
- 双手完整可见且严格空手；
- 无枪、枪匣、弹匣、手雷、枪带和疑似武器轮廓；
- 正面、侧面、背面保持同一脸、发型和服装；
- 不复制真人肖像、现实队服、队标和赞助商。

## 3. 场景历史参考

`场景历史参考/` 中图片只用于：

- 宫廷木构与现代电竞设备共存的材质语言；
- 漆木、铜件、朱墙、黛青、机柜冷光和线缆组织；
- 比赛殿、训练通道和基地总览的空间尺度；
- 后续重做大曜天工院、玄旗训练院和比赛殿的构图参考。

旧图中的国名、牌匾、人物、文字和机构不属于新正史。正式画面必须按大曜、天工院、玄旗队和新专名重做。

## 4. 身份图与比赛化身分流

| 资产类型 | 允许武器 | 权威来源 |
|---|---|---|
| 身份母版 | 严格禁止 | `skills/tiangong-ancient-character-visual/` |
| 比赛化身 | 只允许指定枪械/道具 | `skills/tiangong-match-visual/` |
| 正文关键帧 | 按镜头任务决定 | `skills/tiangong-cinematic-storyboard/` |

不得为了省图，把空手三视图和持枪动作塞进同一张资产。
