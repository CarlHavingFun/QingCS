# 视觉资产说明

## 1. 资产分层

### 人物外观母版

用于锁定脸型、发型、体态、年龄和服制。标准母版必须：

- 纯净背景；
- 正面、严格侧面、背面全身；
- 双手完整可见且空置；
- 无枪、枪匣、弹匣、手雷、枪带和武器影子；
- 不使用现实队服、队标、赞助商和真人肖像复刻。

### 比赛化身

用于跑动、架枪、补枪、换弹和投掷。可持指定武器，但必须引用人物母版，不得反向污染空手母版。

### 场景历史参考

只保留构图、材质、光线和“宫廷木构＋现代硬件”的方法。旧图片中的旧国名、旧人物、旧牌匾和随机文字不构成新作正史。
