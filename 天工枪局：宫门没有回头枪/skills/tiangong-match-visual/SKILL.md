# 天工枪局比赛视觉 Skill

## 1. 读取

先读地图枪械统一规则、漫剧三层表现、唯一男性检测、人物档案和视觉母版。

## 2. 角色化身

- 周野：男性比赛化身；
- 陈默、林溪、赵雨、顾遥、谢晚、纪秋、唐果：女性；
- 化身继承身份母版脸型、发型、体态和主色；
- 穿收袖短袍战术服，腰带整合弹匣、烟闪雷火和通讯设备；
- 不能把同名现代男性化身混入大曜比赛。

## 3. 地图与枪械

地图保留甲乙阵、中路、长短道、回防和投掷空间；枪械保留现代机械结构，使用乌木、黑化钢、黄铜、牛皮、漆器和少量景泰蓝。

## 4. 天衡检测视觉

检测不是比赛高光：

- 使用移动检测架或正式终端校准界面；
- 表现眼动点、方向声音、手部传感器和记录人员；
- UI 留后期文字区域；
- 不展示裸露身体、脑内魔法光或天选加冕；
- 结果只表达短时通过，不出现首发名单自动更新。

## 5. 三层关键帧

```text
REAL_STAGE
GAME_BATTLEFIELD
OBSERVER_LAYER
```

每张关键帧只选一个主层，其他层通过屏幕、声音或转场提示存在。

## 6. 太监解说

唱局监、评策监、掌镜监、录局监是专业岗位。服装与设备克制，不使用尖嗓、娘化、身体梗或跪地解说。

## 7. QC

- 性别和身份版本正确；
- 同名角色世界可辨；
- 周野不是女性；
- 谢晚缺席不等于资产删除；
- 武器可真实握持和换弹；
- 地图可读；
- UI 不泄露观察者信息给选手；
- 无后宫构图和男性救世主宣传。
