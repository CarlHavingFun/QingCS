# 《天工枪局》比赛战场与武器视觉生产

## 1. 核心目标

稳定生产同一套世界内的三层比赛资产：

1. **现实赛台层**：选手、键鼠、耳机、宫廷电竞硬件和真实后果；
2. **游戏战场层**：原创战术地图、现代枪械、比赛化身和战术动作；
3. **观察者层**：OB、军令牌/竹筹 UI、回放、太监解说和公众版本。

采用“战术骨架可懂、视觉与制度原创”。现代 CS 只作为周烬内心和制作研究的比较参照，不能进入大曜公开资产。

## 2. 权威输入

1. 作者当前要求；
2. `设定/IP圣经/00_专名词典与原创边界.md`；
3. `设定/游戏背景/`；
4. `设定/时代背景/`；
5. `人物档案/` 与家族背景；
6. `提示词/天工枪局视觉提示词总表.md`；
7. `视觉资产/人物外观母版/`；
8. 本 Skill。

历史场景图只提供材质和空间参考，图内旧文字与机构失效。

## 3. 资产路由

开始前选择唯一主类型：

- `MAP`：地图总览、点位和战术地理；
- `WPN`：基础枪械或角色版本；
- `UTL`：烟雾罐、震声雷、火油瓶、破片瓷雷、火药匣、拆械匣；
- `AVT`：指定角色比赛化身和单一动作；
- `OBS`：观察者 UI、沙盘、回放、经济板；
- `CAST`：唱局监、评策监、掌镜监、录局监；
- `KF`：现实赛台—游戏战场—观察者切换关键帧。

一次只生产一个主资产。不能在一张图里同时塞完整地图、十名角色、全部枪械、解说席和 UI。

## 4. 身份母版分流

- `tiangong-ancient-character-visual` 负责严格空手身份母版；
- 本 Skill 负责比赛持械资产；
- 比赛化身必须复用脸、发型、体态、年龄和主色；
- 战斗服收袖、短下摆、可跑动、蹲伏、戴耳机、换弹和投掷；
- 武器只允许指定型号；
- 比赛海报不能反向污染身份母版；
- 空手三视图与持枪动作必须拆成两个任务。


缺少甲阵、乙阵、主信息线或回防关系时停止生成。

### 5.2 空间来源

可用：宫门、瓮城、票号、会馆、粮仓、运河、火器营、机造局、驿站、枪坊和码头。

不要默认所有地图都是皇宫。空间必须先满足枪战尺度，再使用大曜材料。

### 5.3 掩体

优先使用：军械箱、粮包、木车、石栏、货架、轨道车、维护架、工装平台、残墙、门体、沙袋和设备柜。

禁止用宝座、花瓶、香炉和纯装饰屏风充当主要掩体。

### 5.4 生产顺序

1. 斜俯视战术总览；
2. 甲阵关键视角；
3. 乙阵关键视角；
4. 主信息线；
5. 俯视沙盘；
6. 道具作用面；
7. 正式光线基准；
8. 角色交火关键帧。

总览看不懂，不进入人物战斗图。

### 5.5 地图 QC

- 三秒内能否找到两阵和主信息线；
- 长线与近战是否同时存在；
- 轮转与回防是否真实可走；
- 烟、闪、火和破片是否有明确作用面；
- 门洞、台阶、平台和掩体是否符合人物尺度；
- 现实权益是否与地图有制度关系；
- 是否不是现实游戏地图截图或像素级复制。

## 6. 枪械生产

### 6.1 机械优先

每把枪先锁：

```text
WPN_ID:
PUBLIC_NAME:
PROTAGONIST_COMPARISON:
BARREL:
RECEIVER:
MAGAZINE:
STOCK:
SIGHT:
ACTION:
EJECTION:
RELOAD_PATH:
GRIP_POINTS:
ROLE:
```

再加乌木、漆器、黄铜、牛皮、少量鎏金和小面积景泰蓝。

### 6.2 禁止结构

- 火绳枪、燧发枪、鸟铳和弓弩替代；
- 龙头枪口、满身珠宝和礼器化；
- 景泰蓝覆盖扳机、散热、抛壳和握持区；
- 错误弹匣、悬浮零件、无机械逻辑；
- 现实品牌、现实皮肤和队标；
- 蒸汽朋克管线、法术核心和霓虹。

### 6.3 基础型号

- `WPN-01 赤漆连珠铳`：现代类比 AK；
- `WPN-02 玄甲镇门铳`：现代类比 M4A4；
- `WPN-03 玄甲静锋铳`：现代类比 M4A1-S；
- `WPN-04 望山重狙`：现代类比 AWP；
- `WPN-05 游隼轻狙`；
- `WPN-06 金翎重铳`；
- `WPN-07 夜巡静铳`；
- `WPN-08 轻骑连铳`；
- `WPN-09 宫门疾铳`；
- `WPN-10 飞檐短铳`。

主角类比只用于内部字段和正文内心，不作为武器板公开标题。

### 6.4 角色版本

角色版只允许改变：

- 枪带颜色与系法；
- 护木磨损；
- 小型编号片；
- 贴腮垫和握持痕迹；
- 队伍旗色与合法纹样。

枪管、机匣、弹匣、枪托和机械比例不得随角色漂移。

## 7. 道具生产

- 烟雾罐：真实拉环、保险和灰白烟墙；
- 震声雷：瞬时白光和震响，无雷法；
- 火油瓶：厚壁瓶体、阻燃套和可读火区；
- 破片瓷雷：现代破片核心与耐冲瓷甲，不是古代陶罐；
- 火药匣：电子计时、线束、炸药模块和漆木保护框；
- 拆械匣：可真实展开并接入火药匣。

每个道具输出多角度、手掌尺度、握持/拉环/出手/落点状态。文字后期合成。

### 8.2 动作硬锁

一张图只表现一个动作阶段：

- 安全架枪；
- 急停完成；
- 开火终点；
- 拉栓；
- 换弹中点；
- 投掷出手；
- 蹲伏拆械；
- 受击淘汰终点。

禁止同时跑、跳、开枪、换弹、投掷和说长台词。

### 8.3 玄旗识别

玄黑、深绛、黛青与克制铜金；旗色、补服、腰牌、护腕和甲纹构成阵营识别，不使用现代印花队服。

## 9. 观察者 UI

### 9.1 版式

- 军令牌：选手、武器、护甲与存活；
- 竹筹：兵筹；
- 火漆：暂停、申诉和封存；
- 兵部文书：名单、地图权益与回执；
- 沙盘：小地图、轮转和道具轨迹；
- 铜钟：回合/火药匣计时。

### 9.2 信息硬锁

UI 面向观众，不是角色可见全息界面。精确比分、姓名、兵筹、击杀栏和字幕全部留后期安全区。

### 9.3 观察者视角

- 第一人称：看输入与准星；
- 自由镜头：看双方空间关系；
- 俯视沙盘：看轮转、道具和补枪；
- 慢放：看时间顺序和证据；
- 现实切回：看人物承担后果。

## 10. 太监解说视觉

### 岗位

- 高鸣玉／唱局监：深绛收袖工作袍、微前倾、铜边耳机和悬臂麦克风；
- 曹慎言／评策监：黛青收袖工作袍、稳定坐姿、玉白数据板与回放旋钮；
- 掌镜监、录局监：墨青/黑绿工作服，真实操作多屏切换与时间轴；
- 姜观澜：观议司制作与公共口径，不与实时解说岗位混同。

### 尊严硬锁

禁止尖嗓夸张脸、娘化、猥琐、身体羞辱、跪地、拂尘当麦克风、谄媚皇帝和古代无电子设备。

## 12. 失败诊断

- **地图看不懂**：回到甲乙阵、主信息线和回防；
- **地图纯贴皮**：重新从现实权益与工作空间设计；
- **武器结构错**：删除纹样，先锁机械；
- **化身不像本人**：加强身份母版，不堆职业词；
- **动作坍塌**：拆成单动作关键帧；
- **UI 像外挂**：移出游戏世界，明确 OBSERVER；
- **解说像宫廷小品**：删身体/嗓音梗，恢复专业岗位；
- **文字乱码**：清空并后期合成；
- **比赛无世界感**：补现实权益、阵营和赛后后果；
- **现代游戏复刻**：删除现实地图几何、皮肤、标志和 UI。

## 13. 交付总检

- 资产是否只有一个主类型和一个主层；
- 战术功能是否先于装饰；
- 地图是否原创、可打且绑定现实权益；
- 枪械是否现代、可操作且结构一致；
- 比赛化身是否与空手母版分流；
- 阵营是否用旗色、补服、腰牌和甲纹；
- 观察者 UI 是否只面向观众；
- 太监解说是否专业、有尊严和权限边界；
- 精确文字是否后期合成；
- 是否无历史人物、旧称号、现实队标、真人肖像和随机文字；
- 当前资产通过后才进入下一资产。
