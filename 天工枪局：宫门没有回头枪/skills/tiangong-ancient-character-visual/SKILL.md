# 《天工枪局》人物身份母版与视觉连续性

## 1. 核心目标

将新人物档案中的脸型、体态、发型、家族、职业和大曜身份转为统一画风但彼此可辨认的身份母版。身份母版用于锁定“这个人是谁”，不是战斗海报。

## 2. 权威输入

冲突时按以下顺序：

1. 作者当前明确要求；
2. `设定/IP圣经/00_专名词典与原创边界.md`；
3. 对应 `人物档案/`；
4. `设定/人物家族背景/`；
5. `视觉资产/人物外观母版/` 中对应图片；
6. `提示词/天工枪局视觉提示词总表.md`；
7. 本 Skill。

历史图只提供脸、发、体态和版式。图内旧文字、胸牌、称号、队标和身份全部作废。

## 3. 身份母版契约

标准输出固定为：

```text
4:3 横构图
纯白或极浅中性背景
左侧约 38% 超大面部特写
右侧正面全身 + 严格 90° 侧面全身 + 背面全身
同一身份 / 同一服装 / 同一发型
脚部完整
中性自然站姿
双臂自然下垂
双手完整可见且完全空置
```

人物必须是成年原创人物。画面强调现代清制工业社会，不做历史清宫人物、仙侠角色、影楼古装和统一网红脸。

## 4. 空手硬锁

身份母版中严格禁止：

- 枪、刀、剑、弓、矛和任何战斗武器；
- 枪匣、枪套、弹匣、弹药袋、手雷、枪带、瞄具和长管影子；
- 手持扇子、签册、卡片、笔、印章、鼠标、耳机线和工具；
- 瞄准、拔枪、战斗准备和夸张英雄姿势；
- 物件倒影或背景轮廓看似武器。

职业只能通过脸体、肩线、站姿、窄袖服制、固定式护腕、队长牌、袖扣、编号片和耳机适配结构表达。

比赛持械资产必须转交 `tiangong-match-visual`。

## 5. 外观母版迁移

### 使用流程

1. 打开新人物档案，先锁新身份；
2. 打开对应外观母版，只提取：
   - 脸型；
   - 发际线/分缝；
   - 头顶体积；
   - 鬓发；
   - 后脑束点；
   - 发尾长度；
   - 肩线、体态与年龄感；
3. 删除图片旧文字、旧胸牌、旧服章含义；
4. 根据新家族与职业重做服装；
5. 以新姓名、新主色和新固定识别物输出。

不得在提示词中写“把旧角色改成新角色”。

## 6. 大曜服制翻译

服制必须适合现代职业生活：

- 能坐进电竞工位；
- 能戴耳机且不压坏发髻；
- 袖口不扫鼠标和键盘；
- 下摆不妨碍走动、设备维修和签字；
- 家族纹样克制，不能像礼服广告；
- 皇帝常服与选手训练服区分；
- 朝廷、票盟、会馆和火器营通过材料、补服位置与腰牌体现，不靠夸张身份字幕。

### 材料

- 玄旗队：玄黑、深绛、黛青、克制铜金；
- 谢家：极小景泰蓝编号片；
- 裴家：门钉/测绘线暗纹；
- 闻家：灰蓝与票号折线纹；
- 霍家：红黑护腕与火器营受力结构；
- 陆家：墨青、运河水线与低对比袖扣；
- 皇室：深色高质量织物、少量金线和制度纹样，不满身龙凤。

## 7. 发型卡

每个角色固定填写：

```text
HAIRLINE:
PARTING:
TOP_VOLUME:
TEMPLE_LOCKS:
EAR_CLEARANCE:
BACK_ANCHOR:
TAIL_LENGTH:
ORNAMENT:
HEADSET_COMPATIBILITY:
```

短发人物保留短发，不为古风强行盘髻；所有发型须能戴耳机、伏案、跑动和签字。

## 8. 核心人物视觉锚点

### 谢照夜

- 平肩窄脸、黑发、歪银簪；
- 右袖结构略短；
- 深绛玄黑；
- 固定式小景泰蓝编号片；
- 克制、观察型，不持枪。

### 裴镇霜

- 方下颌、短发直肩、稳定重心；
- 玄黑深绛；
- 左肩固定式可翻队长牌；
- 不做皇权或将军礼服。

### 闻青砚

- 高瘦窄脸、耳下碎发；
- 灰蓝黛青；
- 固定式护臂；
- 不出现重狙、枪匣和瞄准姿势。

### 霍长缨

- 宽肩方脸、贴颈短发、低重心；
- 玄黑与红黑护腕；
- 动作感来自肩线，不做冲锋海报。

### 陆停云

- 高瘦长脸、深发高束；
- 墨青袖扣；
- 安静、轻量轮廓，不神秘仙侠化。

### 祁元熙

- 四十岁左右成年女性、长直肩线；
- 深色窄袖皇帝常服，制度感强；
- 不以皇冠、凤袍和性感权力造型替代人物；
- 双手空置，不持圣旨或印章。

## 9. 正向提示顺序

```text
构图契约
→ 新姓名、年龄与身份
→ 脸型和体态
→ 发型卡
→ 新家族/职业服制
→ 固定式非武器识别物
→ 清制现代工业材质
→ 空手终局硬锁
```

空手终局段必须放在完整正向提示最后。

## 10. 负面提示

```text
历史清朝真人，现实职业选手肖像，旧人物文字与称号，现代队标，赞助商，
幼态，性感后宫，影楼新娘，统一仙女脸，夸张皇冠，满身黄金，仙侠法术，
枪械，枪匣，弹匣，手雷，枪带，刀剑，弓，长条硬物，手持扇子，手持签册，
双手遮挡，手部缺失，三视图脸漂移，侧面不严格，背面发型错误，随机文字，水印。
```

## 11. 工作流

1. 确认资产类型：身份母版、发型板、表情板、服制板或现代穿越前档案；
2. 读取新身份卡；
3. 提取旧图外观字段，不读取旧身份；
4. 建立发型卡和服制卡；
5. 写正向提示并追加空手硬锁；
6. 写负面提示；
7. 一次只生成一个角色；
8. 先检查双手、武器轮廓和身份漂移；
9. 再检查脸型、发型、服制、年龄和新家族识别；
10. 通过后登记为新母版，不覆盖历史源。

## 12. 失败诊断

- **出现武器**：删除“枪手、狙击手持械”等措辞，强化空手终局；
- **出现手持物**：改为衣面固定标识，双手自然下垂；
- **像旧角色换名**：重写新家族服制、主色和职业动作；
- **像真人复刻**：降低相似，保留宽泛脸体发式；
- **发型同质化**：回到分缝、束点、鬓发和长度；
- **纯古装**：加入现代工位适配、耳机空间和窄袖结构；
- **皇帝像后宫海报**：降低装饰，增加成熟度和工作常服；
- **文字乱码**：移除生成文字，后期排版。

## 13. 交付门槛

- 使用新姓名与新人物档案；
- 三个全身视图双手均完整空置；
- 无任何武器、容器、附件或疑似轮廓；
- 正侧背脸、发型和服装一致；
- 发型可戴耳机；
- 服装适合现代职业动作；
- 新家族与岗位可辨认但不过度装饰；
- 无旧称号、旧胸牌、现实姓名与队标；
- 历史图只作为外观参考，没有反向覆盖正史。
