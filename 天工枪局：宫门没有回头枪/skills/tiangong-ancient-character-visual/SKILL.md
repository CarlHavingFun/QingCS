# 天工枪局人物身份母版

## 目标

把人物档案中的年龄、性别、脸型、发型、体态、职业和家族位置转换为稳定可复用的清制工业风身份母版。母版用于锁身份，不是比赛海报。

## 权威输入

1. 作者本轮要求；
2. `设定/时代背景/04_唯一男性适格者与职业赛制性别规则.md`；
3. `人物档案/<角色>.md`；
4. `设定/人物家族背景/`；
5. `提示词/天工枪局视觉提示词总表.md`；
6. `视觉资产/README.md`；
7. 历史图片只作外观轮廓参考。

## 性别与身份硬锁

- 周烬：成年男性，必须新建男性母版；
- 禁止使用任何女性历史图、谢照夜图或性别转换图代替周烬；
- 谢照夜：独立成年女性；
- 裴镇霜、闻青砚、霍长缨、陆停云、纪衡秋、唐照野均为成年女性；
- 祁元熙为约四十岁的成年女性皇帝；
- 其他职业选手均为成年女性；
- 不把成年角色做成未成年、偶像幼态或统一网红脸。

## 标准画面契约

```text
4:3 横构图
纯白或中性浅背景
左侧约 38% 大面部特写
右侧正面全身 + 严格 90° 侧面全身 + 背面全身
同一身份、同一服装、同一发型
脚部完整
双臂自然下垂
双手完整可见且完全空置
```

## 空手硬锁

标准身份母版禁止：

- 枪、刀、弓、弹匣、手雷；
- 枪匣、枪套、枪带、武器箱；
- 鼠标、奖牌、签册、扇子、印章、卡片等手持物；
- 武器影子、倒影和长条疑似轮廓；
- 瞄准、拔枪或战斗姿势。

职业通过肩线、站姿、服制、固定式胸牌、护腕和腰侧扁平标记表达。

## 周烬母版流程

首个新资产固定：

`视觉资产/人物外观母版/00_周烬_男性外观母版.png`

需锁定：

- 25 岁东亚成年男性；
- 178—183 cm，偏瘦但有职业肩背；
- 窄长脸、清晰下颌；
- 黑色短发，前额自然下落；
- 眼下轻疲劳；
- 克制、不摆英雄姿势；
- 初始现代深色无品牌队服；大曜服制另做第二套；
- 双手空置，不佩戴奖牌和耳机。

母版通过前，不生成周烬持枪正脸海报。

## 女性历史母版流程

已迁移图片只保留：

- 脸型；
- 发型结构；
- 体态；
- 大致主色。

必须重写：

- 姓名；
- 服制身份；
- 队伍纹样；
- 职业标记；
- 图片文字；
- 家族和关系。

历史图若带武器或旧文字，只可作为轮廓参考，正式母版必须重制为空手版。

## 服制翻译

- 玄旗正选：收袖工作袍、原创玄旗纹样、功能腰牌；
- 教练/工程：耐磨工作服、固定式设备标；
- 皇帝：克制礼服与工作常服分开；
- 家族工艺可以进入织纹、扣件和边线，不能堆满黄金；
- 身份母版不放战术弹药和武器附件。
