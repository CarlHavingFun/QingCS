# 天工枪局人物视觉 Skill

## 1. 资产分类

### 男性新制母版

周野及现代四名男队友必须新生成，不复用女性母版。

### 女性迁移母版

谢晚、陈默、林溪、赵雨、顾遥、纪秋、唐果可复用已批准女性图片的脸型、发型和体态。

## 2. 身份母版硬锁

- 空手；
- 无枪、弹匣、手雷、枪带和武器影子；
- 全身、正面/侧面/背面；
- 窄袖可操作服装；
- 不使用真实队标和赞助商；
- 姓名和身份来自新人物档案。

## 3. 周野

必须是二十四岁男性职业选手。现代版本保留现代队服；大曜版本使用男性窄袖训练服。禁止女性身体、长发、银簪、皇子、太监、武侠少侠和后宫男主造型。

## 4. 同名对照

现代男陈默、林溪、赵雨、顾遥与大曜同名女性可共享宽泛轮廓和一个动作习惯，但不得做照片级性转复制。至少改变：

- 性别骨相与身体比例；
- 发型和服装；
- 世界材质；
- 表情与关系距离；
- 家庭与职业物件。

## 5. 生产流程

1. 读取人物档案；
2. 锁定 `WORLD`、`GENDER`、`IDENTITY_VERSION`；
3. 生成单人空手母版；
4. 检查脸、发、体态、服装、手部和性别；
5. 通过后才制作比赛化身；
6. 不一次生成多人 Sprite Sheet。

## 6. 负面项

- 用谢晚图片代替周野；
- 女性围住周野的宣传海报；
- 同名角色只靠发色区分；
- 宽袖礼服、皇冠、后宫、性暗示；
- 枪械粘在身份母版上；
- 旧人物胸牌和称号回流。
