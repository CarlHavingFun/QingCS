# 天工枪局分镜与预演

## 交付物

每章通常产出：

1. `分镜/第NN章_导演书与镜头表.md`
2. `分镜/第NN章_十格分镜.md`

十格是十个约 15 秒的生成/剪辑单元，不等于十个单镜头。每格只完成一个主要叙事节拍，可拆 1—4 个短镜头。

## 前置条件

必须先有：

- 已批准正文；
- 当前人物档案；
- 周烬男性母版或明确的避脸策略；
- 场景平面；
- 高风险关键帧；
- 当前物证与身份状态。

没有人物母版时，不能靠每格重新写一次角色描述赌连续性。

## 每格模板

```text
## 第N格｜时长
- 节拍/观众更新：
- LAYER:
- 镜头拆分：
  - N.1 时长｜功能｜景别/焦段｜走位起点→动作→终点｜机位｜声音｜转场
- 表演变化：
- 身份与性别连续性：
- 场景/道具连续性：
- 比赛字段：
- 解说字段：
- UI_SAFE_AREA:
- H3/图生视频运动提示：
- QC：
```

## 第一章分镜节奏建议

1. 决胜回合；
2. 失败与银牌；
3. 团队事实复盘；
4. 周烬独自重放；
5. 女声、时间和手机记录错位；
6. 材质与空间变化；
7. 四名女性正常处理陌生男性；
8. 谢照夜门禁与物证；
9. 三次职业检测；
10. 无籍临时卡与承天门查档钩子。

穿越后不要立刻用旁白讲完大曜世界。

## 太监解说字段

```text
COMMENTATOR_ROLE: 唱局监 / 评策监 / 掌镜监 / 录局监
KNOWN_INFO:
LINE_FUNCTION:
AUDIO_PRIORITY:
OBSERVER_VIEW:
END_STATE:
```

唱局先报发生什么，评策再说为什么重要。现场判断、回放证据和赛务结论不能混成一句。

## 图生视频规则

起始关键帧已经有主体和场景时，只描述：

- 人物如何移动；
- 表情如何变化；
- 相机如何移动；
- 烟、火、布料和光如何变化；
- 动作在哪里结束。

不重复整段静态设定。复杂动作拆镜，开火、换弹、拉栓和投掷不能同时发生。

## 文字规则

比分、姓名、赛籍、地图名、击杀栏、临时卡和长字幕以后期合成为主。生成图只保留版式和安全区。

## 身份连续性

- 周烬：成年男性、同一脸、同一身体；
- 谢照夜：独立成年女性，不与周烬换脸；
- 其他职业选手：成年女性；
- 非选手男性可以自然出现；
- 不用性别差制造夸张身高差、围观膜拜或暧昧站位；
- 角色位置由职责决定。

## 失败诊断

- 故事失败：观众不知道为什么重要 → 重做节拍；
- 空间失败：不知道谁在哪 → 补主镜头和地理；
- 身份失败：周烬女性化/换脸 → 停止生成，重建男性母版；
- 群像失败：所有女性只看男主 → 重做职业走位；
- 比赛失败：只有枪火 → 补人数、时间、目标和后果；
- 解说失败：像宫廷小品 → 删除口彩，重写事实；
- 文字失败：乱码 → 清空并后期合成；
- 动作失败：动作过载 → 一镜一主动作；
- 连续性失败：锁定参考图、道具和光向。

完成当前章后停止，不提前制作下一章。
