# 天工枪局小说生产

## 核心任务

把设定、人物和比赛事实写成读者能顺着动作理解的第一人称网文。正文不是设定汇编，也不是比赛攻略；每个场景必须让人物在有限信息下作出会留下后果的选择。

## 权威输入

冲突时按顺序裁决：

1. 作者本轮明确要求；
2. `docs/superpowers/specs/2026-08-11-tianggong-reboot-design.md`；
3. `设定/时代背景/`；
4. `设定/游戏背景/`；
5. `设定/人物家族背景/` 与 `设定/IP圣经/`；
6. `人物档案/`；
7. 已批准正文；
8. Skills、提示词与历史参考。

旧项目不再是正文正史，只能提供第一章文风、节拍和生产方法。

## 永久硬锁

- 周烬是成年男性，以自己的身体穿越；
- 谢照夜是独立成年女性失踪选手；
- 周烬不继承谢照夜的身体、记忆、合同、家族或正选席位；
- 周烬是唯一通过完整职业适格检测的男性；
- 除周烬外，全部注册职业选手、替补和正式试训选手均为成年女性；
- 适格只证明设备兼容，不自动产生赛籍、队籍、首发、外挂、皇权或恋爱特权；
- 性别规则不得推导现实男女能力优劣；
- 天工枢网没有人格，不发任务、不评判忠诚；
- 皇帝不能改比分、直接封正选或替人物签约；
- 女性人物有独立利益、职业能力和拒绝权，不能成为男主奖励；
- 正式比赛必须留下局内账、队务账或现实账后果；
- 当前章完成后停止，不提前写下一章。

## 正文视角

默认采用周烬第一人称“我”。

只能写：

- 我看到、听到、触到的内容；
- 我从文件、屏幕、语音或他人口中获得的事实；
- 我当下的判断和可能误判；
- 事后通过回放核实的内容。

不能写：

- 其他人物未表达的内心；
- 作者知道但周烬不知道的真相；
- “她其实已经爱上我”等全知关系结论；
- 电脑或旁白宣布穿越答案。

切换他人视角必须由作者明确批准，并在章节结构上清楚标记。

## 生产前事实单

每章开始前填写：

```text

```

事实单答不清，就不以气氛和设定填充。

## 场景因果

每段核心动作遵循：

`可见事实 → 人物判断 → 最小可执行动作 → 结果 → 新限制`

例：

- 事实：门禁只有谢照夜刷入记录；
- 判断：周烬不可能从正常入口进入；
- 动作：陆停云复制只读门禁盘；
- 结果：保住异常证据；
- 新限制：所有人必须在赛籍司查档前保持口径。

禁止：

- 先写作者结论，再让人物配合；
- 角色一出场就自报完整家族史；
- 用系统通知代替人物选择；
- 笑点结束后没有职业后果。

## 口语与解释

### 普通对话

- 短句；
- 贴着眼前任务；
- 用停顿、改口、物件和反应表达压力；
- 不让每个人都说完整分析报告；
- 宫廷礼法只在门禁、会签、接待和公开场合出现。

### 比赛解释

第一次出现规则时采用：

`看见的动作 → 一句口语解释 → 立即产生的代价`

示例：

> 霍长缨先出门，我跟在她身后一身位。她负责让第一支枪开火，我负责在她倒下前把那个人换掉。

不熟悉枪战的读者能懂，熟悉玩家能判断距离和选择。

### 专名分流

现代层和周烬内心可用 `CS / AK / AWP / C4 / A点 / B点`。  
大曜公开层使用 `天工枪局 / 云雷铳 / 望山狙 / 震城匣 / 甲点 / 乙点`。

第一次类比后不反复双语翻译。

## 比赛章节

正式比赛开始前让读者知道：

- 谁攻谁守；
- 比分、人数、时间；
- 震城匣状态；
- 主角位置；
- 经济与关键道具；
- 该图押注的现实权益。

每个关键回合至少写清：

1. 谁拿第一信息；
2. 谁交道具；
3. 谁先接触；
4. 谁补枪或回防；
5. 为什么保枪、强起或转点；
6. 下一轮少了什么。

高光后必须切回现实赛台或赛后后果。不要连续数页只写击杀播报。

## 唯一男性钩子使用规则

每次强调周烬性别，必须落到具体冲突：

- 检测；
- 赛籍；
- 训练资源；
- 数据和肖像授权；
- 外邦承认；
- 安保和隐私；
- 商业合同；
- 队内公平竞争。

禁止只写：

- 全场女性围观；
- 所有人自动脸红；
- 男主靠性别成为队长；
- 女性职业选手集体不如他；
- 皇帝用婚姻解决身份。

## 家族与政治

家族信息只在资源或选择发生时进入：

- 裴家要求赢回城门时，写城门轮值和图契；
- 闻家索要回放时，写授权条款；
- 霍家要求强攻时，写兄长旧伤和火器营荣誉；
- 陆家路线受影响时，写运河合同；
- 谢家旧案出现时，写材料、质检和赔偿。

政治冲突必须落到门、牌照、预算、配额、合同、回放、印信或公开责任。

## 穿越悬疑

异常按层级推进：

`音画 → 时间 → 记录差异 → 材质/温度/气味 → 空间 → 跨界实物`

每次异常至少有一种可复核方法。主角可以怀疑，但不能因为“像小说”就立刻接受穿越。

## 章节完成检查

- 本章是否只有人物当下能知道的信息？
- 周烬是否始终是男性本体？
- 谢照夜是否保持独立主体？
- 其他职业选手是否均为成年女性？
- 适格是否被误写成上场资格或能力加成？
- 女性角色是否有自己的目标和合理反对？
- 比赛是否有前因、地理、经济和后果？
- 家族/政治是否落到具体资源？
- 是否出现旧人物称号、旧皇帝或现实职业身份？
- 章末是否产生一个明确新问题和一个新限制？
- 是否停止在当前章？
