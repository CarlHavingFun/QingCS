# 天工枪局电影级导演书

## 核心原则

镜头先解决叙事，再提供美术。顺序固定：

`正文事实 → 戏剧问题 → 节拍 → 人物走位 → 镜头 → 关键帧 → 声音/剪辑 → QC`

不得从正文直接跳到“电影感、推镜、24mm”。

## 人物与性别硬锁

- 周烬始终是同一个成年男性身体和脸；
- 不得用谢照夜或任何女性母版替代、变形或换脸；
- 谢照夜是独立成年女性；
- 所有其他职业选手为成年女性；
- 唯一男性不能通过构图被拍成女性群体的所有者或后宫中心；
- 群像构图按职业任务和空间关系组织，不按性别膜拜组织。

## 导演分析

每场先回答：

- 表层发生什么；
- 真正的戏剧问题；
- 谁拥有什么信息；
- 谁想控制什么资源；
- 周烬当前误判；
- 情绪从何处移动到何处；
- 哪个可见动作能代替旁白。

## 走位模板

```text
角色：

```

先确定人如何占据空间，再决定相机。

## 三层比赛镜头

### REAL_STAGE

选手身体、键鼠、耳机、队友、裁判、暂停和现实后果。

### GAME_BATTLEFIELD

战斗化身、清制地图、枪械、道具和交火。不是肉身进入。

### OBSERVER_INFO

小地图、人数、时间、兵筹、回放、太监解说和公众版本，只面向观众。

每镜只属于一个主层。通过声音、形状、光线或动作匹配切换，不把三层画成同一房间。

## 穿越镜头

异常升级顺序：

1. 正常回放；
2. 声音多出；
3. 屏幕与手机记录不同；
4. 时间/比分不同；
5. 材质变化；
6. 门外空间变化；
7. 周烬男性身体与跨界实物被确认。

不要用闪电、黑洞和系统字幕替代细节。

## 摄影语法

- 24—28mm：宫门、比赛殿、地图地理；
- 35—50mm：人物关系、工位和走位；
- 75—100mm：鼠标、眼神、奖牌、门禁、火漆、检测单；
- 稳定机位优先；
- 推近用于决定逼近；
- 拉远用于暴露孤立；
- 横移用于揭示关系；
- 轻微主观漂移只在周烬失衡时使用。

一个镜头最多一个主动作和一个主机位行为。

## 第一章关键帧

必须预制：

1. 决胜回合四打三地理；
2. 周烬准星停顿与程野倒下；
3. 亚军奖牌落在键盘旁；
4. 屏幕与手机显示不同比分；
5. 现代桌面向漆木铜边桌面的材质重合；
6. 周烬男性双手和现代衣物确认；
7. 四名女性在封存室门口按职业职责站位；
8. 云雷铳购买栏；
9. 三次检测结果；
10. 临时卡“男／适格／无赛籍”。

周烬男性母版未批准前，不生成其高风险正脸长镜头。

## 声音

- 现代场馆：观众低频、耳机隔音、键鼠和空调；
- 穿越：木板声、呼吸、钟声、服务器风扇连续衔接；
- 大曜空间：铜灯电流、木门槛、机柜冷却、远处钟；
- 比赛：队内报点和脚步优先于解说；
- 解说：专业、清楚，不做尖嗓身体梗。

## 连续性圣经

每章固定：

- 周烬男性脸、体态、现代衣物或大曜服制；
- 七名女性母版的脸型、发型和年龄；
- 门、桌、屏幕、设备和光源位置；
- 奖牌、手机、临时卡和证据袋归属；
- 地图 ID、枪械 ID 和战斗化身；
- 每镜轴线、视线和移动方向；
- 适格、赛籍和队籍当前状态；
- 人物此时真正知道什么。

## QC

- 镜头删掉后是否损失故事信息？
- 周烬是否被错误女性化或换身？
- 女性群像是否有职业走位和独立反应？
- 三层是否清楚？
- 观众是否看懂地图和选择？
- 关键文字是否留后期合成？
- 动作是否有终点？
- 高光是否回到现实后果？
