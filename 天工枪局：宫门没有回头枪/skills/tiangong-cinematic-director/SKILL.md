# 《天工枪局》电影级导演书

## 1. 核心原则

镜头首先是叙事决定，不是漂亮构图清单。每个镜头必须让观众多知道、感到或预期一件事；删除后没有损失的镜头应删。

固定顺序：

`正文与潜台词 → 节拍图 → 人物走位 → 导演书 → 镜头表 → 关键帧 → 声音/剪辑 → 生成适配 → QC`

不得从正文直接跳到“24mm、推镜、电影感”。

## 2. 必读输入

- 当前正式正文；
- 本章人物档案和家族背景；
- 涉及的地图、枪械、比赛制度与现实后果；
- `提示词/天工枪局视觉提示词总表.md`；
- 已批准人物外观母版；
- 上一章结束状态和下一章接口。

历史源镜头只作方法参考，不能复制旧人物站位、专名和高潮。

## 3. 导演分析

开始前回答：

```text
SURFACE_EVENT:
REAL_DRAMATIC_QUESTION:
EXTERNAL_CONFLICT:
INTERNAL_CONFLICT:
SUBTEXT:
EMOTIONAL_MOVEMENT:
VISIBLE_VISUAL_IDEA:
MATCH_STAKE:
WORLD_CONSEQUENCE:
```

视觉命题必须可见。例如“半拍犹豫”可表现为准星移开、手指压下前结果弹出、回放音画错位，而不是画一团抽象恐惧。

## 4. 走位先于相机

每镜先写：

`人物起点 → 看见/听见什么 → 主动作 → 停在哪里 → 看向哪里 → 道具最后状态`

再决定相机。空间影响动作时先给全景或稳定锚点，不能用一串特写掩盖地理不清。

## 5. 镜头硬规则

- 每镜一个主要故事功能；
- 每镜一个主动作、一个主要机位行为；
- 动作必须有结束状态；
- 景别服务信息：全景看地理，中景看关系，近景看反应，特写看证据；
- 镜头运动必须有叙事工作：推近逼近决定，拉远暴露孤立，横移揭示关系，锁机强调无法改变；
- 守住 180 度轴线、视线和屏幕方向；
- 对话先设计听者反应，再设计说话者口型；
- 不写抽象情绪，写手、呼吸、后退、停顿、回避与物件。

## 6. 视觉基调

### 现代北港

- 冷白、舞台金和大面积黑；
- 观众声大、空间开；
- 选手席玻璃和屏幕反光克制；
- 决赛结束后从开放声场收缩到休息室低频。

### 大曜现实赛台

- 深红漆木、青砖、黛青屋面、暖铜灯与机柜冷光共存；
- 设备、线缆、门禁和消防/医疗路线真实；
- 不拍成纯古装宫斗，也不拍成现代电竞馆贴屏风。

### 游戏战场

- 明清火器工业风，战术地理优先；
- 角色战斗化身保持身份连续；
- 枪械和道具结构真实；
- 烟、闪、火与尘土服务信息，不遮掉全部动作。

### 观察者层

- 军令牌、火漆、竹筹、文书和沙盘构成 UI 外壳；
- 精确比分、姓名、兵筹和字幕后期合成；
- 太监解说席是专业广播工作空间。

## 7. 比赛三层导演语法

每个比赛镜头标注：

```text
LAYER: REAL_STAGE / GAME_BATTLEFIELD / OBSERVER
```

### 现实赛台

看手、输入、呼吸、队内语音、队友反应和现实后果。

### 游戏战场

看位置、枪线、补枪、道具、火药匣和动作结果。

### 观察者

看人数、时间、兵筹、俯图、回放证据和公众解释。

三层不能同处一个物理空间。解说声音不能被选手听见；全知 UI 不能悬浮在角色眼前。

## 8. 三层切点

优先使用可见/可听匹配：

- 鼠标点击 → 枪机动作；
- 显示器门洞 → 游戏宫门；
- C4 滴声 → 火药匣铜钟；
- 现代三箱边缘 → 大曜漆木门框；
- 准星移动 → 人物肩后视线；
- 现实手指停顿 → 游戏枪口偏开；
- 太监解说 J-cut → 观察者画面；
- 枪声 L-cut → 现实队友反应。

转场必须推进信息，不为炫技。

## 9. 比赛镜头事实

进入镜头表前锁定：

```text
MAP_ID:
POSITION:
SCREEN_DIRECTION:
ROSTER_ALIVE:
TIME:
ECONOMY:
UTILITY:
WEAPON_ID:
WEAPON_STATE:
BOMB_STATE:
TACTICAL_QUESTION:
DECISION:
RESULT:
REALITY_CONSEQUENCE:
```

事实不完整时，不用快速剪辑掩盖。

## 10. 人物连续性

逐章固定：

- 脸型、发型、体态、年龄和服装；
- 身份母版与比赛化身分流；
- 队长牌、护腕、袖扣、银簪、奖牌和门禁牌；
- 谁持有何物、哪只手、当前状态；
- 轴线、视线、移动和光向；
- 谁知道穿越/异常的哪一层；
- 家族与赛约已发生的后果。

周烬进入谢照夜身体后，现代自我不能通过外观叠加另一个男性幽灵脸来表示。身份冲突由镜子、动作、声线、记忆和表演呈现。

## 11. 关键帧门槛

以下必须先做关键帧：

- 五人固定站位与比赛座次；
- 人物脸、发式和战斗化身；
- 手、鼠标、枪械、弹匣、奖牌和门禁牌；
- 现代场馆到大曜空间的同构转场；
- 地图总览、甲乙阵和主中路；
- 枪械开火、换弹、拉栓与投掷动作；
- 太监解说双人台和观察者控制台；
- 首尾状态差异明显的镜头。

关键帧未通过，不进入视频生成。

## 12. 声音设计

每场先定稳定底床：

- 北港：观众低频、空调、主机、隔墙采访；
- 大曜训练院：机柜风扇、铜灯轻响、远钟、设备车过门槛；
- 游戏：脚步材质、枪机、枪声、烟闪火和火药匣；
- 观察者：监听低噪、切换键、回放旋钮和克制解说。

声音优先级：关键脚步/队内语音/枪声/拆械声 > 解说 > 配乐。重要证据出现时降低配乐，不用廉价惊吓音。

## 13. 太监解说导演规则

- 唱局监报发生了什么；
- 评策监解释为什么重要；
- 掌镜监决定观众看什么；
- 录局监在争议后提供证据；
- 现场判断与回放修正分开；
- 口型风险高时使用侧背影、画外音、监听灯和手部；
- 禁止尖嗓、娘化、跪地和谄媚表演。

## 14. 导演书模板

```text
# 第NN章导演书

## 戏剧问题
## 视觉命题
## 人物潜台词
## 空间平面与轴线
## 现实赛台/游戏战场/观察者分配
## 灯光与色彩
## 声音底床
## 关键物件
## 高风险关键帧

| 镜头 | 功能 | 时长 | 层 | 景别/焦段 | 起点→动作→终点 | 相机 | 声音 | 连续性 | 转场 | 风险 |
```

## 15. 失败诊断

- **故事失败**：观众不懂镜头意义 → 重做节拍；
- **空间失败**：位置和轴线混乱 → 重做主镜头；
- **战术失败**：只有漂亮枪战 → 补位置、时间和选择；
- **人物失败**：反应像知道作者真相 → 恢复可见刺激与正常推断；
- **层级失败**：现实、游戏、UI 混在一起 → 重标 LAYER；
- **武器失败**：跨镜变形 → 锁基础型号和动作状态；
- **文字失败**：乱码 → 清空并后期合成；
- **宫廷小品化**：删装饰和刻板表演，恢复职业工作。

## 16. 交付 QC

- 每镜是否有故事功能和动作终点；
- 地理、轴线、视线和屏幕方向是否清楚；
- 比赛事实能否复盘；
- 三层切换是否有动机；
- 人物是否只根据已知信息反应；
- 关键物件是否可追踪；
- 比赛后果是否回到现实；
- 是否无旧称号、现实队标和历史人物影射；
- 关键帧不过是否已停止视频生产。
