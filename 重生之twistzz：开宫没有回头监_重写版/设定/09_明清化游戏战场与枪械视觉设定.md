# 明清化游戏战场与枪械视觉设定

> 状态：正式设定  
> 方案：**战术骨架保留、视觉重新设计**  
> 适用范围：穿越后的正式比赛、训练赛、回放、直播、漫剧分镜、地图设定图、武器设定板与角色比赛化身。  
> 不适用范围：第一章现代现实比赛、标准空手人物定妆照、现实赛台硬件空间总览。

## 1. 核心定义

穿越后的比赛不是“古装人物坐在现代电脑前打原样 CS”，也不是“把现代地图贴上红墙金瓦”。游戏本体已经沿平行大清的工业、审美和国家赛制发展出自己的视觉语言：

- 规则层继续使用读者熟悉的 5V5、MR12、经济、购买、炸弹、A/B 点、道具、补枪、保枪和残局逻辑；
- 战术层保留清楚的中路、长短道、交叉火力、轮转、回防、烟闪投掷空间和视线管理；
- 视觉层把地图、枪械、角色化身、观察者 UI 与直播包装统一重构为明清火器工业风；
- 叙事层采用现实赛台、游戏战场、观察者信息三个画面层，使比赛像职业电竞漫剧，而不是屏幕录制或战术讲义。

本设定禁止两种偷懒：

1. **纯贴皮**：原地图截图不改结构，只贴古建筑材质；
2. **伪古代化**：把 AK、AWP 等现代枪械变成火绳枪、燧发枪、弓弩、法器或无法工作的礼器。

## 2. 三层比赛画面

### 2.1 现实赛台层

现实赛台层是选手身体真正所在的位置。它沿用宫廷电竞生产系统：朱墙、深色漆木梁柱、黛青瓦、铜灯、宫门、值房与漆木铜边机箱、显示器、键鼠、耳机、交换机、服务器、网线共同工作。

该层必须承担：

- 鼠标急停、拉枪、压枪和重新定位；
- 键盘移动、切枪、投掷和购买操作；
- 队内语音、呼吸、手部犹豫和耳机内的沉默；
- 暂停、教练建议、队友反应、现场礼法与赛务流程；
- 回合结果对首发、经济、责任、关系和舆论的真实后果。

现实赛台不是每次交火都要切回。只有当手部、队友反应、指挥权、设备状态或回合代价发生变化时才切回。

### 2.2 游戏战场层

游戏战场层把屏幕中的比赛电影化。角色以比赛化身进入地图，镜头可以使用：

- 战术全景与俯视地理；
- 第三人称肩后跟随；
- 第一人称持枪与开镜；
- 侧面交叉火力、低机位贴地投掷和高位回防；
- 子弹打击、烟雾扩散、闪光遮白、燃烧封路和炸弹倒计时；
- 死亡后立即退出该角色主观，不把中弹做成血腥猎奇。

比赛化身必须复用身份母版的脸型、发型、体态、主色和职业动作，但服装改为适合战斗的短袍战术体系：

- 袖口收紧，不能遮挡扳机、弹匣或手雷；
- 下摆不拖地，能跑动、蹲伏、跨门槛和上梯；
- 弹匣、投掷物、拆弹器和通讯件固定在腰带、护腕或背侧；
- 战队识别只使用原创纹样、主色和职责标，不使用现实队标或赞助商；
- 身份母版仍然空手，只有比赛化身和剧情动作资产允许持械。

### 2.3 观察者信息层

观察者信息层面向观众，不面向选手。它包含：

- 小地图、A/B 点、人数、比分、时间和经济；
- 击杀栏、道具数量、持枪与护甲信息；
- 第一人称、自由镜头、俯视图和回放切换；
- 太监解说的实时播报与战术解释；
- 赛后慢放、补枪链、烟闪轨迹、责任时间轴和公众版本。

该层不能成为外挂：

- 观察者看到的敌方位置不得传回队内；
- 未公开队内语音不得被解说实时引用；
- 精确 UI、比分、地图名、选手名和击杀栏以后期合成为主；
- 生成画面只保留短标签与安全区，禁止随机文字和伪汉字。

太监解说的完整制度、岗位和语言规则见 `10_太监解说与观察者信息层设定.md`。

## 3. 三层之间的镜头接口

### 3.1 第一次完整揭示

穿越后的第一场正式比赛必须完整建立以下语法：

1. 现实赛台全景确认五席、座次、设备和观众；
2. 回合开始音或鼠标点击作为声音切点；
3. 显示器里的门洞、墙线或准星扩大并占满画面；
4. 用形状、光线或运动匹配切入明清化游戏战场；
5. 先给地图地理，再给角色比赛化身和武器识别；
6. 交火时由太监解说提供人数、时间和普通读者入口；
7. 高光或失误后切回现实手部、队友眼神或指挥反应；
8. 回合结束后由观察者回放解释烟、闪、补枪和下一轮经济。

### 3.2 后续比赛简化

后续比赛不重复“进入游戏”的完整仪式，只保留：

`地图建立镜头 → 武器/角色识别镜头 → 核心战术镜头 → 观察者/解说更新 → 现实反应镜头`

只有地图第一次登场、武器第一次亮相、角色换枪或战术关系发生根本变化时，才增加设定型镜头。

### 3.3 第一章边界

第一章现代现实比赛保持现代 CS 视觉，不提前把整套明清战场展示完。穿越段只允许一次短预告式匹配切换，例如：

- 现代双门的缝隙短暂叠为朱漆瓮城双门；
- 现代黑色 AK 护木短暂闪为赤漆云雷式；
- 现代击杀提示音与宫钟尾音重叠。

这些只能作为时空错乱证据，不得让其他人物据此理解“穿越”。

## 4. 地图设计总规则

### 4.1 必须保留的战术骨架

每张地图至少显式标出：

- 攻守出生区；
- A 区、B 区与中路；
- 一条长视线和一条近距离争夺路线；
- 至少一条主回防线与一条高风险侧线；
- 烟雾切割、闪光进入、燃烧封路和手雷伤害的合理空间；
- 可被补枪的接触距离；
- 可形成交叉火力、包点与残局绕后的结构；
- 明确但不夸张的高低差。

### 4.2 明清空间语言

地图可以来自边关、府城、王城、皇陵、漕运、机造、园林水工和营造工地，不得全部做成皇宫。建筑必须像真实可工作的空间：

- 门洞、城墙、院落、巷道和台阶有合理尺度；
- 木构、砖石、铁件和铜件有承重与使用逻辑；
- 掩体来自军械箱、粮包、石栏、车架、工装平台、货栈与墙体，不是随意摆放的古董；
- 旗帜、匾额和纹样只承担方向与阵营识别，不填满画面；
- 视觉识别不能牺牲对手轮廓、枪口方向和投掷物轨迹。

## 5. 枪械与道具设计总规则

### 5.1 双名称系统

正文、语音、解说和 UI 优先使用玩家熟悉的短名：AK、AWP、M4、沙鹰、USP、格洛克、烟、闪、雷、火、包和钳子。

视觉设定、资产文件和首次展示可以同时使用原创式样名，例如：

> 箱姐从主狙匣里取出 AWP。灰白枪身上只有一道霜纹刻度——霜纹望山式。

首次建立后，枪战段落回到“AWP”，不反复念全称。

### 5.2 功能优先

所有枪械必须保留一眼可辨认的功能轮廓与操作：

- AK 的弧形弹匣、导气结构、机匣和护木；
- AWP 的长枪管、大型瞄准镜、栓动机匣和弹匣；
- M4 的直线枪身、弹匣、护木与枪托；
- 消音枪的消音器、低反光表面与拆装关系；
- 手枪的套筒、握把、弹匣和扳机护圈；
- 冲锋枪的紧凑结构、快速换弹与近战轮廓。

装饰只能出现在不影响握持、瞄准、散热、拆卸、换弹和抛壳的位置。

### 5.3 材料与纹样

统一材料语言：

- 黑化钢、乌铁、弹簧钢和磨砂金属承担结构；
- 赤漆木、乌木、灰白硬木和深黛复合材料承担护木与枪托；
- 黄铜只用于包角、刻度、接口、铆钉和保护件；
- 云雷纹、冰裂纹、回纹、城垛纹只做低对比暗纹；
- 枪带、贴腮垫和护套使用深色皮革与织带；
- 磨损必须来自握持、架枪、换弹、枪口热和运输，不做均匀“做旧滤镜”。

禁止满枪黄金、玉石堆砌、龙头枪口、宫廷礼器比例和无法工作的蒸汽朋克管线。

## 6. 角色与武器连续性

### 6.1 基础型号先于角色皮肤

同一把武器先建立稳定基础型号，再增加角色版本。角色版本只允许改变：

- 枪带颜色与系法；
- 握把、枪托和护木的局部磨损；
- 原创队纹、职责标和个人小记号；
- 角色惯用的贴腮垫、护套、刻度和保养状态；
- 不影响功能的小型挂件。

不得因为角色不同而改变同一武器的枪管长度、弹匣形状、机匣比例、瞄具位置或换弹方式。

### 6.2 比赛化身调用

比赛化身以 `人物档案/24_比赛化身与武器绑定总表.md` 为准。标准定妆照继续由 `qingcs-ancient-character-visual` 生产；持械比赛化身、武器设定板和游戏战场关键帧必须由 `qingcs-mingqing-match-visual` 生产。

## 7. 视觉统一与色板

- 绛色：制度、赛台、进攻识别与关键提示；
- 黛青：防守、阴影、机枢、低反光武器和外邦冷色；
- 玉白：UI 面板、地图线、烟雾识别与屏幕信息；
- 铜金：接口、刻度、铆钉、灯具和有限高光；
- 黑铁：枪械结构、机械、轨道和工业骨架；
- 木色：赤漆、乌木、灰白硬木，按地图和武器分配。

禁止紫蓝霓虹赛博朋克、满屏金色、荧光彩虹武器和塑料 cosplay 材质。

## 8. 比赛描写规则

### 8.1 先动作，后视觉名词

正文不得用大段设定说明打断交火。推荐顺序：

> 可见动作 → 队内/解说口语 → 结果 → 必要时补一笔视觉识别。

示例：

> 箱姐拉栓，铜制镜筒在灯下闪了一线。中门第二个人刚露肩，AWP 已经响了。

而不是先解释“霜纹望山式”的制造史。

### 8.2 枪械音色

不同武器仍保留玩家熟悉的声学识别：AK 厚重、M4 更紧、消音枪低闷、AWP 单发强烈、冲锋枪短促。宫钟、木鱼、锣鼓不能覆盖枪声，也不能把每次击杀都配成宫廷庆典。

### 8.3 死亡与重生

比赛化身的死亡是竞技淘汰表现，不延伸为现实身体伤害。可使用冲击、失衡、武器脱手、画面抽离和观察者切换，避免持续血腥特写。下一回合重新出现在出生区属于游戏规则，不解释为法术复活。

## 9. 生产与 QC

### 9.1 生产顺序

1. 锁地图战术骨架；
2. 锁场景平面和关键视线；
3. 锁基础武器型号；
4. 锁角色比赛化身；
5. 生成地图与武器设定板；
6. 生成无 UI 的比赛关键帧；
7. 预留 UI 安全区；
8. 后期合成精确比分、地图、经济和击杀栏；
9. 接入太监解说、枪声、队内语音和现实赛台反应。

### 9.2 失败判定

以下任一出现即失败：

- 看不出 A/B 点、中路或回防关系；
- 地图像纯古装街景，没有枪战尺度和掩体；
- 武器变成火绳枪、燧发枪、弓弩、法器或礼器；
- 弹匣、枪管、瞄具、消音器或握持结构错误；
- 角色宽袖拖地、手指穿枪、弹匣悬浮或武器比例漂移；
- 现实赛台、游戏战场和观察者 UI 混成同一物理空间；
