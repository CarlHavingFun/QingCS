# 文风

## 权威基准

- 成熟基准：正文/第01章_输掉决赛后，我成了大清女队首发.md。
- 连续性校准：正文/第02章_这个世界，男人上不了CS国赛.md 与 正文/第03章_用女人的手，我打回第一枪.md。
- 第一人称深度限知，主角的职业判断可以锐利，作者不能替配角解释内心。

## 叙述声口

- 现代职业选手的事实优先声口：先位置、人数、时间、设备和结果，再给半句带偏见的判断。
- 宫廷名词与现代电竞物件自然并置，不把错位写成段子堆砌。
- 情绪从手、肩、步幅、鼠标线、耳机、纸面和门禁后果落地，少写抽象感悟。

## 句段节奏

- 叙述默认用二至四个紧密动作或信息组成自然长句，避免通篇三五字电报句。
- 段落按镜头、动作、物件或信息变化断开；高压瞬间可用孤立短句，之后恢复连续叙述。
- 对话短、口语化、角色可辨：大表姐说下一步和责任；箱姐说完整视野与长线；雨姐说入口条件；老六姐说时间、位置和确认范围。

## 电竞写法

- 每个术语首次出现时先演后说，让普通读者从动作和后果理解。
- 高光必须写清判断链：已知事实 → 条件成立或不成立 → 最小动作 → 命中或代价。
- 一次成功只证明该次成功，训练记录、赛籍和席位的范围由人工程序明确。

## 去AI味硬线

- 不用章末总结、命运升华、作者预告、论文式因果解释。
- 正文和对白不使用破折号或省略号制造停顿。
- 避免“不是A而是B”、万能声音描写、连续比喻、三连排比、排队式群像发言。
- 不为反检测机械切短句，不故意删掉自然的“的、了、就、但是”。
