# 题材定位

## 基本信息

- 书名：《穿越大清打CS，我成了女队首发》
- 题材类型：电竞爽文、平行现代历史幻想、身份悬疑、制度权谋
- 目标平台：长篇网文移动端兼容，具体平台尚未锁定
- 核心梗：现代男性职业选手输掉Major决赛后，醒在平行大清成年女队首发身体里，从普通终端重新争取国力赛资格。
- 微创新点：宫门、赛籍、密折、设备、五席和国际赛制处在同一现代制度中；宫斗通过名册、预算、证据和训练后果落地。

## 读者契约

- 核心读者承诺：看主角凭职业判断和可复盘操作从受限观察走回赛台，同时破解7比5、男性国力赛禁限和原贼贼姐去向。
- 主角代理权承诺：关键进展必须来自主角的判断、选择、训练和承担；机构可以授权程序，队友可以完成职责动作，不能替主角赢回席位。
- 利益安全线：首发、赛籍、设备、身份和穿越真相不能由电脑、皇权、宠信、暧昧或一次高光自动授予。
- 期待债：卷一偿还“能否用新身体重新完成职业动作并争到临时席”；第32—34章集中偿还7比5与身份交换证据；第39—44章偿还世界冠军。
- 题材边界：五席群像服务主角的职业重建，不写成主角拥有四名队友；制度合作必须留下主角因果权和收益归属。

## 终局底牌与升级台阶

- 终局底牌：世界冠军在第六卷解锁；7比5与赤门旧案在第五卷解锁；原贼贼姐可能进入现代世界的证据在第五卷解锁；逐人稳态认证改革在第六卷结尾启动。
- 升级台阶：普通终端短测 → 未注册的宫内候验优先意见 → 四方有条件续期 → 国内资格赛临时第五席 → 国力赛小组 → 阵容重组与淘汰赛 → 世界决赛。
- 身份台阶：临时来历不明者 → 三日观察对象 → 宫内二号位候验优先对象 → 国内资格赛临时第五席 → 正式国力赛队员 → 主动选择代表大清出战。
- 透支红线：卷一不能证明穿越机制、不能恢复正式首发、不能让皇帝或慈宁宫直接选人；第04章只能赢得继续训练。

## 核心梗三分法

- 表层卖点：男职业选手穿成平行大清女队首发，在宫里打CS。
- 深层爽点：熟练职业判断遭遇新身体、陌生队友和旧制度后，仍能一枪一证据地把主动权赢回来。
- 长线钩子：异常7比5为何跨越两个世界，原来的贼贼姐去了哪里，男性禁限到底是安全规则还是被固化的权力。
