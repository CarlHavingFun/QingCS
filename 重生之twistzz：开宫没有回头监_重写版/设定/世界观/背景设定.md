# 世界观与时空错乱设定

## 1. 现代现实层

现代层是读者熟悉的职业电竞现实。故事从一场公开 CS 职业比赛开始，比赛有地图、经济、回合、队内语音、解说、观众和赛后回放。现实层只借用一名现代职业步枪手的公开职业功能、公开赛事语境和中国 CS 观众熟悉的“总监”戏称；真实原型字段只在内部映射表核稿，不进入公开层，也不替现实人物补写私下感情、未公开动机或虚构对白。

现代层的功能有三项：

1. 先让读者看懂贼贼姐的职业脑：她知道二号位如何跟第一接触、经济不足时何时保枪、烟和闪各自换什么空间。
2. 让“总监”先是观众对队内位置感的玩笑标签，随后在平行世界被误读成管理权标签。
3. 让时空错乱从现实服务器、公开回放、耳机声音和意识失重中逐步发生，而不是从宫殿讲义开场。

现实比分、现实战队和公开履历只能作为入口锚点。它们不能直接证明平行世界某位原创人物的性格，也不能把现实职业生涯的结果复制进平行赛季。

## 2. 平行世界层：大清与职业电竞

平行世界是一个沿独立工业路线发展出的现代化大清政体。宫门、内廷、外朝、礼名、宫籍、印信、值房和位号保留明清叙事语感；显示器、服务器、交换机、鼠标、耳机、直播、跨境联赛和合同体系则是这个世界已经成熟的生产设施。古典外壳不改变硬件性能，宫廷装饰也不能让电脑获得意志。

大清战队是大清政体的国家/宫廷电竞代表，受大清国朝电竞署统筹，日常由内廷竞技院管理，正式赛务由联赛协会审核。它不是现实中国俱乐部的换名，不是民间俱乐部的皮肤，也不是某位皇室成员的私人队伍。大清战队拥有国家赛籍、宫廷训练资源、选手合同和公开责任，代表的是大清政治实体的竞技制度。

“凤仪五席”是大清战队当前赛季的一组五人首发编制；“内廷训练院”是住宿、训练、复盘和设备管理机构；“宫籍位号”是组织身份、礼仪和媒体字段。三者都不能替代“大清战队”这一战队字段。

### 2.1 大表姐的队友时间线

故事开局处于大清战队共同期：大表姐是大清战队资深 IGL 和队内地位核心，贼贼姐是她的队友/二号位。两人共同赢下过比赛，也共同在暂停、失分和赛后责任栏里签过字。她们不是开局就分属两国。

中段大表姐因职业路线、队内决策、国家代表制度以及合同/尊严冲突离开大清，转入北凛联邦霜旌队。离队必须经过队务、合同、赛籍、签证、设备和席位交接等人工流程；大清舆论把这件事称作“叛逃”，但这个标签不替正文裁定她的道德真相。后段贼贼姐留在大清承受空出的席位、旧队友关系和公开压力，大表姐以霜旌队身份与她重逢、对阵或在合同许可范围内合作。

## 3. 中国原生职业战队为何不存在

这个时间线的中国原生职业战队已经不存在，消失是制度史结果，不是电脑按了删除键，也不是某个民族被抹除。

职业化早期，地方会馆、民间队和短期本土俱乐部曾经存在。后来天衡联赛实行统一赛籍：能够长期报名的主体必须拥有国朝、联邦、商盟、自治领或宫廷授予的法人/政治章程，且必须能承担跨境合同、设备验收、训练资源、选手保险和回放归档。原生民间队大多没有独立的长期注册承接主体。

改革之后发生了四件事：

- 选手被吸收到大清战队的国家代表编制、内廷训练院或外邦借席，个人能力和职业语言得以保存。
- 原生队的队徽、旧合同、训练录像和地方联赛记录被分散进国朝档案、宫廷档案和个人履历，原队名不再拥有现役赛籍。
- 当代赛季的国内竞技名额只由大清战队承接。大清内部可以有训练组、候补组和试训桌，但这些不是独立中国原生战队，不能以自己的队名报名国际联赛。
- 时空错乱只让贼贼姐更早看到两套档案的字段冲突：现代俱乐部字段找不到平行世界可承接的本土队，平行世界的国朝/宫籍字段也无法替代现代俱乐部史。它暴露断裂，不负责修复断裂。

因此，大清战队是唯一中国本土竞技来源，但它不是“中国原生俱乐部”的替代名。正文若写国内竞技，必须写成大清战队内部选拔、国家编制、内廷五席或大清赛务，不得凭空出现另一个中国本土职业队。

## 4. 时空错乱机制

### 4.1 只负责一次意识错位

现代比赛结束后，现实服务器与平行世界的公开档案在一次跨时空错乱中短暂重叠。贼贼姐的现代意识进入平行世界一名成年女性职业选手的身体；身体、宫籍、旧训练记录和队友关系属于平行世界本人，现代意识带来的只是记忆、方法和自我认知的错位。

错乱的根因可以在长线中继续调查，但它不再制造第二套能力。穿越完成后，冲突由贼贼姐、队友、协会、媒体、国家队管理层和外邦战队的选择推动。

### 4.2 读者逐步看到什么

- 首发状态锁：第 1—24 章的首发框架固定为贼贼姐、大表姐、箱姐、雨姐、老六姐。第 1 章落地时，人工名册已经写明“大清战队／凤仪五席／首发五席”和贼贼姐的二号位首发。固定五席已登记；待核只限本人到场、图内责任、暂停责任和人工留痕。
- 第一章：现代赛台上的公开比赛结束后，公开回放出现时间轴停滞、画面与音频错位和陌生女声；意识失重后，贼贼姐落到服务器、运行中的电脑和宫殿门廊共存的世界。固定五席已登记；待核只限本人到场、图内责任、暂停责任和人工留痕。
- 第二章：贼贼姐确认成年女性身体、宫籍、五席框架和已经存在的队友印象/旧名声；人工名册继续由人补录到场与责任，不因意识错位自动改写首发，也不把工作人员或训练候补挤进五席。
- 第三至第十一章：通过人工名册、旧训练录像和赛务签字看见身份不一致；电脑只显示字段冲突、缺页、时间戳和回放状态，不判定她是谁。
- 中后段：通过旧队档案、外邦申诉和协会听证解释中国原生战队的制度性消失；这些证据会改变合同、舆论和资格，不会召回一支不存在的队伍。

### 4.3 明确不能发生的事

- 电脑不能自动改写已经登记的首发五席，也不能替人工补录本人到场、图内责任或暂停责任；不能自动发放资格、替补位或改比分。
- 赛务平台不能读取感情、私密记忆或未来战术，不能替任何人决定留下、离开、恋爱或背叛。
- 不删除现代记忆，不用“重置人格”洗掉平行身体的旧责任。贼贼姐必须面对身体原主留下的训练纪录和关系债务。
- 不用神秘权限推动宫斗。门禁、名册、合同、签字、回放和资源都由人维护，也由人解释和承担错误。

## 5. 明清宫廷与电脑共存

大清的电竞设施是一套真实生产系统：漆木铜边的机箱、玻璃显示器、风扇、交换机、耳机线和服务器柜与朱墙、回廊、宫灯、门禁、值房和封条共同存在。视觉上可以出现龙纹散热罩、铜质权限灯和丝绸线套；功能上仍然是设备温度、网络延迟、显示刷新率和人工配置。

宫廷物件与电竞动作的对应关系如下：

| 宫廷物件 | 现实设备/流程 | 对比赛的实际影响 |
|---|---|---|
| 宫门、门牌、钥匙 | 训练房门禁、设备柜钥匙、赛台入场牌 | 谁能进房、谁能接设备、谁会错过赛前准备 |
| 名册、印信、封条 | 首发名单、合同页、赛务回执、回放硬盘封存 | 谁能报名、谁能申诉、哪份证据可以公开 |
| 值房、轮房表 | 训练时段、服务器排班、教练和复盘室预约 | 谁多练一小时，谁能复现一套烟闪和反清 |
| 观议屏、宫报 | 直播、赛后剪辑、论坛和采访 | 谁先得到公众解释权，谁被剪成高光或替罪羊 |
| 铜灯、钟声 | 设备状态灯、回合倒计时、赛务提示音 | 暴露断线、暂停时间和开局压力 |

## 6. 多国赛制、签证、合同与舆论

大清战队的对手来自同时代的北凛联邦、 西澜商盟、东陆诸邦和海西自治领。国别必须进入职业动作：

- 北凛选手需要联邦队长双签和外邦赛照，训练记录公开，优点是审计清楚，缺点是临场改签慢。
- 西澜选手的合同细到地图、数据和回放使用权，硬件与数据资源丰富，但退出和商业授权都要逐条谈。
- 东陆选手常受会盟轮换和跨邦调度影响，签证与队伍合约可能只覆盖一个赛季，快节奏战术是训练选择，不是民族天赋。
- 海西选手拥有远程机房和海运设备优势，但设备入境验收、网络路线和豪门频繁换阵会改变磨合时间。

所有外邦选手进入大清赛区都需要外邦赛照、设备申报、训练时段确认和翻译/沟通安排。大清战队出境则需要国朝赛籍文件、队员合同副本、医疗与保险证明。签证和合同冲突可以直接造成缺席训练、错过地图禁选或失去替补资格，但不能由电脑自动补齐。

观议司、解说、外邦媒体、论坛和观众共同形成舆论层。舆论可以把贼贼姐叫作“总监”，却不能因此给她官方权限；她若要改变标签，必须用完整回放、公开资源账和队友自己的发言让公众看到事实。媒体不是裁判，论坛也不是赛务。

### 6.1 宫门到训练线的固定物理动线

宫廷基地不是一张把古装贴到现代电竞馆上的平面图。每条路线都由门、院落、廊道、门禁、设备和人工岗位维持：

1. **公共中轴：** 午门 → 太和门 → 外朝前院 → 比赛殿。观众、媒体、国家名义和正式比赛沿中轴进入，午门与太和门之间必须有门洞、台基、朝房和赛务分流。
2. **外西工作线：** 西华门 → 熙和门 → 外朝西路 → 外队接待处 → 复盘处/直播处。外邦赛照、合同、译员、验机、采访和完整回放走侧线，不能与观众入口混成一条迎宾通道。
3. **外东数据线：** 协和门 → 外朝东路 → 器材库 → 服务器房。设备箱、维修件、带宽记录、双人封存硬盘和备用电源从后勤线进出，不能穿过正式观众流线。
4. **内廷队伍线：** 乾清门 → 大清战队内廷基地绛霜宫原创院落 → 清朝风格宫殿电竞殿/选手值房 → 夜间训练通道。公开场景名只有“夜间训练通道”；西二长街夜间训练段和大清战队内廷基地西夹道只是物理分段。
5. **比赛殿内部五线：** 队伍入口、赛务入口、观众入口、侧廊、后勤线必须彼此可辨；队伍与设备从队伍入口/后勤线进，裁判从赛务入口进，观众从正面入口进，侧廊连接直播和观察位。

这些路线会在前十章逐步被读者认出：第1章从现代比赛转入服务器房和宫门外，第2—4章走午门、太和门、乾清门及内廷训练，第5章让夜间训练通道承担门禁与资源冲突，第6章经过服务器房，第7章进入直播处，第8章处理外队接待处，第9章由比赛殿回到复盘处，第10章完成公共中轴、外西工作线、外东数据线和内廷队伍线的第一次闭环。

## 7. 词汇硬锁与禁止事项

- 命名按阶段证据执行：Ch1 现代男性比赛段第一人称“我”可被叫“贼贼”，队友使用“大表哥”“箱子”等男性外号；意识错位并由声音、手、鼠标/重心、头发服装成本、队友和名册确认平行女性后，才逐步使用“贼贼姐”等女性公开名。不得写真实英文名、中文音译名或“某某女性版”；真实原型字段只在内部映射表出现。
- 战队固定写“大清战队”；训练院、宫籍、五席、主将席和协会不得被写成另一个战队名。
- 当代不得出现中国原生职业战队、地方中国俱乐部或现实中国俱乐部换皮。
- 其他主要女性化职业原型必须在外邦国家/政治实体和外邦战队中登记，并让签证、合同、资源、训练、语言、外交或战术至少有一项进入场景。
- 皇权可以决定国家政策和预算总盘，但不能直接成为某名选手具体训练时段、设备、枪械、首发、合同或赛务资格的执行来源；恋爱、性关系仍绝不成为上述来源。
- 禁止同位匹配、自动资格、删除现代记忆、人格重置、神秘系统任务和电脑替人物拍板。
- 第 1—24 章固定五席已登记；待核只限本人到场、图内责任、暂停责任和人工留痕。
- “现代电竞馆贴古装”是源设定、总纲、场景卡、分镜和图像提示的审核阻断项：若画面没有门—院落—廊道—后勤动线、真实设备散热/走线、比赛殿五条入口或宫廷空间的工作功能，必须退回重写。

## 8. 公开层命名边界

公开层执行“中文化别名优先”闸门，但 Ch1 必须保留现代男性阶段到平行女性阶段的可观察过渡：现代比赛段第一人称“我”可被队友叫“贼贼”，队友使用“大表哥”“箱子”等男性外号；意识错位并由声音、手、鼠标/重心、头发与服装成本、队友和名册逐步确认平行女性身份后，才切换到“贼贼姐”“大表姐”“箱姐”“雨姐”“老六姐”。这是阶段性命名证据，不是称呼漂移。进入平行世界后的正文、分镜和图像提示再统一使用中文化女性公开名；人物档案里若需要说明本名，只能写“平行公开层不另设第二姓名”，不能给正文可调用的真实姓名、英文名或中文音译名。

内部原型字段只放在 `设定/03_中文化职业原型映射.md`，用于制作核稿、打法拆解和资产追溯；它不能复制进正文、分镜台词、角色可见档案、场景可见屏幕、图像文字或对外提示词。不得用“某某女性版”“现实某某换性别”等句式提示读者识别原型。角色识别必须靠打法、身形、服制、道具、说话节奏、复盘动作和国别职业条件完成。

## 9. 皇帝线、权限链与命名连续性锁

### 9.1 Ch1 命名与真人出场

- Ch1 无沈衡真人、无“皇帝/陛下”声音、无皇帝影子解释；第一人称始终是“我”，唯一危机是比赛、穿越和女性化职业成本。
- 现代男性阶段只用中文男性外号；平行女性阶段的称呼必须跟随可观察证据逐步切换，不能在开头把女性公开名倒灌进现代比赛，也不能用真名、ID、真实队名补资料感。
- Ch1 之后的女性公开名仍要先由队友反应、名册、赛务或现场动作确认；“贼贼姐”是制作标签，正式正文仍以“我”叙事。

### 9.2 沈衡的权限边界

沈衡是原创成年女性皇帝，正文称“皇帝”或“陛下”，不以“女帝”作为标签。她可以定国策、预算总盘、任免、外交赛约和公开责任。皇权可以决定国家政策和预算总盘，但不能直接成为某名选手具体训练时段、设备、枪械、首发、合同或赛务资格的执行来源；恋爱、性关系仍绝不成为上述来源。

具体训练、设备、枪械、首发、合同、赛籍、地图池、暂停和临时席，必须经过协会/司竞监、队长、教练、队务/分析、回录与当事人按职责会签、回执和执行。任何一项不能由皇帝单签完成；大表姐的离队必须由本人、合同、队籍、赛籍、设备/数据交接和跨国附约共同成立。

权限链固定为：**沈衡 → 国策/总预算/任免/公开责任；协会与赛务 → 资格/回执/申诉；队长 → 临场口令/暂停申请；教练 → 训练与建议；队务/分析 → 设备、合同、数据与回放；队员 → 当事人选择与回合责任；天工/AI → 记录与评估材料。** 天工不发任务、不选首发、不改比分、不授予资源。

### 9.3 真人节点与制度影子
