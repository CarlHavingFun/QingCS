# 大清战队宫廷电竞基地总览与宫殿索引

## 1. 文件定位与公开命名

本文件是新版唯一的宫廷电竞基地总览、宫殿/功能院落索引、固定场景圣经和三视图环境接口。原“场景圣经与三视图锚点”的场景职责、空间锚点和视觉差异规则并入本文件，不再另设同级旧版文件。

公开场景名统一如下：直播处、外队接待处、服务器房、清朝风格宫殿电竞殿、复盘处、比赛殿、夜间训练通道、御前听报室。`国策值房`是御前听报室的内部值房称呼；两者是同一间可工作的房间，不是两个场景，不得各自增加一条无动线空间。夜间训练通道若需要物理细分，只能写“西二长街夜间训练段”或“大清战队内廷基地西夹道”；这两个是物理分段说明，不是第二个公开场景名。

“绛霜宫”若出现，只表示大清战队所属的架空内廷院落/训练基地，是选手值房、训练空间和夜间训练通道的建筑来源；它不是另一支中国原生战队，不是战队名，也不是贼贼姐的身份名。大清战队是唯一中国本土现役竞技来源。

资产追图可以有内部文件编号，但资产文件名、场景卡、分镜、图像提示和可见画面统一使用本文件的公开名。真实职业选手姓名不进入公开场景层；角色只使用贼贼姐、大表姐等中文化名字。

## 2. 建筑史与架空改造边界

现实建筑锚点是北京紫禁城的明建清用连续体：明永乐营建的中轴、城门、城墙、护城河、外朝/内廷分区和东西六宫提供结构骨架；清代门名、清代使用、清代重修和清晚期局部贯通提供叙事阶段。真实建筑史负责回答“这里是什么结构”，平行世界制度负责回答“这个结构现在承担什么职业功能”。

本基地不是现代电竞馆贴上古装，也不是把现实宫殿历史上已有的功能改写成电竞史。平行世界的大清政体经过独立工业化，才拥有电力、网络、服务器、显示器、直播和跨境职业联赛；机衡院、内廷竞技院、观议司和大清联赛协会分别负责设备、训练、传播与赛务。

架空改造必须同时补出承重、门宽、散热、供电、排水、消防、维修、门禁、设备领用和人员值守。电脑可以保存时间戳、回放和状态，但资格、首发、合同、公开权和责任由人和组织流程确认。

## 3. 文字地图：中轴、侧线、内廷与后勤

```text
                                      北
                                      │
                         神武门（后门，非观众主入口）
                                      │
       西二长街夜间训练段 ── 大清战队内廷基地西夹道 ── 绛霜宫原创院落
                                      │                  ├─ 清朝风格宫殿电竞殿
                                  乾清门                  ├─ 选手值房/宿舍
                                      │                  └─ 御前听报室（内部值房称：国策值房）
                                      │
          外朝东路服务线             外朝中轴公开线              外朝西路工作线
   协和门 → 器材库 → 服务器房      太和门 → 比赛殿      熙和门 → 复盘处 → 外队接待处
                                      │                  └─ 直播处侧向工作房
                                      │
                          太和门外朝前广场与赛务分流
                                      │
                         午门（紫禁城南门，公众进入层）
                                      │
                                      南
```

四条动线必须保持差异：

1. **公共中轴线：** 午门 → 太和门 → 比赛殿。观众、媒体、国家名义和正式比赛沿中轴进入；要有广场、台基、门洞、朝房和赛务分流，不能一脚跨进赛台。
2. **外西工作线：** 西华门 → 熙和门 → 外朝西路 → 外队接待处/复盘处/直播处。外邦赛照、译员、合同、回放和采访走侧线，避开观众正门。
3. **外东数据线：** 协和门 → 外朝东路 → 器材库 → 服务器房。设备箱、维修件、带宽记录和封存硬盘走服务线，不穿过典礼中轴。
4. **内廷队伍线：** 乾清门 → 大清战队内廷基地绛霜宫原创院落 → 清朝风格宫殿电竞殿/选手值房 → 夜间训练通道。夜间移动受门牌、时段、灯火、值守和设备小车约束；它不是秘密地道。

5. **后勤闭环：** 器材库 → 侧门/后勤路线 → 比赛殿队伍入口或服务器房 → 验机/安装 → 赛后封存。队伍入口、赛务入口、观众入口和后勤线不能互相冒充。

## 4. 比赛殿的五条入口与内部结构

比赛殿是架空正式职业赛殿，借外朝三大殿的中轴尺度、台基、月台、廊庑和礼仪压迫，但不是太和殿、保和殿的历史电竞化。每次分镜建立比赛殿，至少交代以下五条线：

| 线路 | 进入者 | 物理结构 | 制度作用 | 必须可画的标志 |
|---|---|---|---|---|
| 队伍入口 | 大清战队五席、候补、教练、一录、外邦队员 | 赛殿侧后方门，连接更衣/设备检查小院 | 核验队牌、设备、赛照和首发状态 | 队牌、设备箱、双人验机台、门禁灯 |
| 赛务入口 | 裁判、顾折枝所属司竞监、协会、机衡院 | 侧面独立值房门，直达暂停席和赛务台 | 交接地图池、暂停回执、计分、申诉和封存单 | 红头名册、计时铜钟、只读终端、赛务印 |
| 观众入口 | 观众、媒体、公共解说席 | 正面台阶和外朝广场分流门 | 控制座次、安检、媒体席和公共视线 | 分层栏杆、观众牌、入口告示、隔离线 |
| 侧廊 | 解说、摄像、观察员、译员、临时工作人员 | 沿赛殿侧面连接直播处/观察台/暂停席的有顶廊庑 | 传递口令、切镜、只读观察和语言确认 | 摄像机、译员牌、侧屏、线缆保护槽 |
| 后勤线 | 设备、维修、饮水、冷却件、备用电源 | 赛殿后侧服务门，连接器材库和服务器房 | 运输、安装、断电、维护、回收和封存 | 慢道、推车、封条、温度记录、服务门 |

赛殿内部按“中央五席赛台—后侧暂停席—两侧解说/观察—外圈观众—后勤服务线”组织。五名正式选手、候补、教练/一录、裁判/暂停席必须能数清；屏幕只展示地图、回合、经济、道具和短赛务状态，不出现悬浮系统权限。

## 6. 八个固定场景的剧情接口

### 6.1 直播处

直播处把比赛事实转成公众版本，但没有改比分、改首发或替选手承担责任的权力。常驻洛遥音、解说、音频人员、译员和采访官。可发生剪辑删掉烟的时间戳、外邦合同拒绝肖像、队友要求自主发言、直播延迟与暂停口径不同等冲突。画面必须有漆木直播案、玉白屏、铜麦、音频旋钮、采访牌、回放小窗和线缆槽。

### 6.2 外队接待处

外队接待处是职业工作流程的第一道门，不是迎宾大厅。它处理外邦赛照、设备验收、住宿、译员、训练时段、合同授权和外交礼数。常驻顾折枝联络员、译员、外队领队和机衡院验机员。冲突必须落到签证、设备清关、合同数据权、共同口令或同规执行。画面用半开门、接引案、设备箱、验机屏、延迟计和外邦牌表现内外边界。

### 6.3 服务器房

服务器房放真实机柜、交换机、配线架、回放存储、时钟和带宽记录，由机衡院维护。它可以产生延迟、温度、冷凝水、时钟漂移、硬盘封存和设备编号冲突，不产生人格答案。常驻机衡院和双人维护员；晏听澜按手续调证。厚墙、窄窗、独立底座、分层线缆、状态灯、维护台和双人封存柜必须可画。

### 6.4 清朝风格宫殿电竞殿

清朝风格宫殿电竞殿是大清战队的正式训练和五席工作殿，借养心殿式多功能前后空间和两进院分区，但不是皇权私殿、恋爱场所或另一战队。常驻大清战队五席、燕归迟、教练、一录和内廷竞技院人员。冲突有队长拍板、二号位复核、主狙/突破/支援资源、候补入席和五席约。前殿五台可拆工位、后侧白板、配殿设备、耳房值守和可关闭门槛必须能在镜头中分层。

### 6.5 复盘处

复盘处是人工证据工作区，沿武英殿式廊房和穿廊组织。它复核画面、语音、经济、道具、延迟、合同和责任，不能自动判案。常驻晏听澜、一录、教练、队员和协会见证人。冲突包括高光与原始回放、代签、证据公开范围和谁知道/确认/执行。长桌、时间轴纸卡、玉白屏、硬盘、朱印封条和五席签字栏必须出现。

### 6.6 比赛殿

比赛殿承载正式 BO3/BO5，是公开规则的检验场。它必须同时保留队伍入口、赛务入口、观众入口、侧廊和后勤线，并能让比赛、暂停、解说、观众和设备维护互不穿线。常驻大清与外邦五席、候补、教练、一录、裁判、解说、观众、媒体和维修人员。冲突包括地图禁选、座次、低经济、暂停、翻译、首发和责任。镜头可从观众席看赛台、从队伍入口回望五席、从赛务侧廊看只读屏、从后勤线拍设备进场；禁止把它画成现代体育馆或古装舞台。

### 6.7 夜间训练通道

夜间训练通道是正式公开名。它连接大清战队内廷基地西夹道、绛霜宫原创院落、清朝风格宫殿电竞殿、选手值房与受控的设备/复盘授权点。西二长街夜间训练段负责南北方向，大清战队内廷基地西夹道负责院落边界，两者在门禁节点处相接，不是一条神秘后宫长廊。常驻夜巡、门禁值守、选手、候补和必要译员。可发生训练牌收回、候补被拦、设备转运、半句报点、证据递交和外邦赛照时段冲突。画面要有朱墙、格窗、低位宫灯、门槛、状态牌、保护槽、备用鼠标匣和训练房门内的冷光。

### 6.8 御前听报室（内部值房称国策值房）

御前听报室是公开称呼，国策值房是同一房间的内部工作称呼；两者不拆成两处建筑。它位于乾清门内侧行政门廊，和外朝复盘/赛务线有可核对的门牌、值守与回执关系，不能凭空接到比赛殿中央。

这里是沈衡唯一固定的工作型皇帝场景锚点：桌面有预算总盘与分项栏、采购清单、外交赛约、设备状态、回放墙/回放终端、会签栏、责任令、协会回执、门禁牌和异议纸签。她可在桌边听报、翻回放、圈预算、追签字、改条件、听异议、签责任令，递报官必须留下材料来源和下一步回执。

视觉镜位优先桌面平视、材料与手部动作的近景、侧后方肩线和门槛外望；允许看到沈衡的成年女性体态、深绛/黛青窄袖工作服和稳定坐姿，但不把服制拍成海报。禁止空宝座站台、封建戏台、光束降旨、神像式仰拍、皇帝站上赛台、搬设备、调枪、做教练、报点或操作赛务终端。屏幕只显示人物能引用的回放、预算、赛约和设备状态短字段，不出现 AI 任务、权限值或神谕。

## 7. 物理连续性规则

1. 从午门到比赛殿至少经过午门门洞、外朝前院、太和门或其赛务分流；不能从城门切到赛台无过渡。
2. 外邦队走西华门—熙和门—外队接待处；设备验收必须出现门槛、箱体、序列号、译员或赛照中的至少两项。
3. 复盘处与比赛殿之间必须有廊庑、侧门、院落或穿廊；它不是赛殿地下万能密室。
4. 服务器房走协和门—外朝东路服务线；设备箱须经过器材库、门禁、保护垫、验机和双人值守。
5. 夜间训练通道走乾清门—内廷基地—绛霜宫前后院—大清战队内廷基地西夹道/西二长街夜间训练段；不能从西二长街夜间训练段直接穿墙进入外朝库房。
6. 门是状态变化点：进入、被拦、交牌、交设备、夜禁和临时开放都要有门牌、值守、封条、灯或门槛作为视觉证据。
7. 设备不悬浮：每次出现电脑、服务器、摄像或交换机，至少交代桌面/机柜、供电、散热、线缆、维修或门禁之一。
8. 宫殿功能不混写：配殿不是耳房，耳房不是值房，夹道不是穿堂，廊庑不是角楼，库房不是服务器房的历史名称。
9. “现代电竞馆贴古装”是审核阻断项：只要画面像普通现代电竞馆换了宫灯/屋檐，或像古风空殿摆了几台电脑，场景不得进入正文、分镜或图像生成。
10. 绛霜宫只能作为大清战队基地内的原创架空院落；任何把“绛霜宫”写成战队、国家、主角身份或中国原生俱乐部的用法一律退回。
11. 御前听报室与国策值房是同一物理房间；路线必须回到乾清门内侧行政门廊，房内必须有文件、回放、预算、赛约、签批、异议和回执等工作动作，不能新增第二个“皇帝值房”或把皇帝移到赛台。

## 9. 三视图与场景资产接口

每名角色和每个场景资产都必须填写：公开名/公开场景名、国家/战队或院落归属、脸型与五官重心、身高肩线、发型动作、站姿、国家服制、设备磨损、枪械/地图习惯、说话节奏、复盘动作、道具锚点、原型识别点、女性化改造点和不可混淆点。

三视图规则：

- **正面：** 画脸型、肩线、国家服制、职责牌和标准设备；去掉发色仍能辨人。
- **侧面：** 画鼠标/枪械姿势、耳机、袍摆、门槛动作和设备线；看出她怎样工作、怎样过门。
- **背面：** 画肩线、队伍纹章、发型轮廓、背包/耳机线、候补/职责牌和移动姿态；去掉姓名仍能辨人。

女性化职业原型不能只换发色和模特。贼贼姐的炫酷发型、冷静残局和位置感，大表姐的偏丰满体态、年长稳重、高学历/分析型气质，以及其他角色各自的打法、身形、服制、装备和复盘动作，必须通过工作姿态和道具落地，不通过真实姓名或真人肖像落地。
