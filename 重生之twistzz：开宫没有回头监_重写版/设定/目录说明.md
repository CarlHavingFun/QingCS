# 设定目录说明

本目录承载新版源设定、人物档案、关系图、场景锚点、宫殿总览、图像提示词、44 章总纲和审核输入；不承载正式章节正文或正式十格分镜。正文和分镜分别位于同级的 `正文/` 与 `分镜/`，由生产登记统一追踪。

公开层统一使用贼贼姐、大表姐、箱姐、雨姐、老六姐、米教姐、稳火姐、幕后姐等已锁定中文化名字；真实教练映射只留在 `设定/03_中文化职业原型映射.md` 和内部审核/研究文件。大表姐的时间线必须先是大清战队资深 IGL 队友，完成人工离队程序后才成为北凛联邦霜旌队成员。米教姐是大清登记“一教”，戚照霜是执行教练/继任制度负责人，幕后姐是霜旌队教练兼队务领队；大清战队是本时间线唯一中国本土竞技来源，绛霜宫若出现只指大清战队内廷基地内的原创架空院落。

空间公开名统一使用直播处、外队接待处、服务器房、清朝风格宫殿电竞殿、复盘处、比赛殿、夜间训练通道；旧目录保持只读，不在本目录合并旧文件。

## 现实空间与游戏战场的边界

`场景与电竞设定图资产清单.md` 继续负责现实比赛殿、训练房、服务器房、复盘处、直播处和宫廷电竞硬件；`09—11` 负责显示器内部被漫剧电影化的游戏地图、枪械、比赛化身、观察者 UI 和太监解说。两套资产可以通过镜头切换连接，但不得混成同一物理空间。

第一章现代现实比赛维持现代 CS 视觉；明清化游戏战场只允许在穿越时出现短暂预告，完整体系留到平行世界第一场正式比赛。
