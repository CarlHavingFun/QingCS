## 0. 统一视觉基准与交付边界

### 0.1 画面总方向

- **空间基底**：明清宫廷木构的真实建筑逻辑——深色漆木梁柱、朱墙、黛青瓦、玉白屏面、铜灯、门槛、值房、回廊和内外门禁；宫廷是可工作的建筑，不是影视棚或舞台布景。
- **电竞融合**：显示器、键鼠、耳机、麦克风、交换机、服务器柜、网线、回放终端、经济/回合状态板与木构同处一个功能系统。硬件要能真的工作，古典外壳不改变鼠标、延迟、视线和线缆路径。
- **统一配色**：绛色为制度与赛台主色，黛青为机枢、阴影和外邦冷色，玉白为屏幕和状态板，铜金只作为灯具、接口、印章与边缘高光；避免满屏金色、荧光彩虹和霓虹灯。
- **漫剧概念设定质感**：高质量动画/漫剧前期设定图，材质清楚、空间可拍、结构可复用；保留适量线稿感和设计稿信息，但不做平面 UI 截图，不做照片级真人肖像。
- **信息可读性**：CS 信息必须能读懂，但场景图只保留少量短标签，例如 `5V5`、`A区`、`B区`、`MIRAGE`、`回合`、`经济`、`暂停`、`复盘`、`五席`、`一候`、`一教`、`一录`、`待核`。禁止大段说明文字；所有文字必须是设计需要的短标签，不用随机英文或伪文字填充。
- **人物边界**：不生成角色设定图。场景中若需要尺度参照，只允许极小比例的无脸背影、剪影、手部或空置座位；人物不能成为主体，不能出现可辨认真实人物脸。

### 0.2 命名与原型映射硬规则（本轮新增）

1. 平行世界不直接使用职业哥英文名；进入世界、场景、电竞设定图的角色全部采用**短、顺口、带原型梗且简单易记的中文化女性同位名**、原创宫廷姓名、原创队名或职责称谓。目标原型的唯一正文/图像资产称呼固定为 **“贼贼姐”**；其它职业原型也按同一规则命名，不在平行世界保留英文名。中文化名要让读者能从发型/体态、设备颜色、枪位/战术习惯和公开职业功能认出原型，但不能把英文名直接贴在画面上。
2. 场景/电竞资产的 `assetId`、文件名、类型、叙事用途、构图、关键元素、连续性锚点、img2 prompt 与 negative prompt，优先使用中文化名、中文制度词和 CS 通用术语；本轮以空间和职责为主，尽量不把任何真人原型姓名写进画面。若后续资产必须指向职业原型，只使用“贼贼姐”或对应的短中文女性同位名。
3. 真实职业身份和队伍只允许在 `设定/03_中文化职业原型映射.md` 与研究文件中出现；不得进入文件名、可见画面文字、牌匾、队牌、状态板、屏幕标签、prompt 的可见文字要求或 negative prompt 的画面内容。
4. 内部映射只是原型索引，不是平行世界称谓，不代表真人进入后宫恋爱关系；本轮场景与电竞设定资产不生成真人或角色肖像。

**空间名锁：** 资产中出现“绛霜宫”时，统一指大清战队所属的原创架空内廷院落/训练基地；它不是战队名、国家名、主角身份名或另一支中国原生战队。公开场景名仍以直播处、外队接待处、服务器房、清朝风格宫殿电竞殿、复盘处、比赛殿、夜间训练通道、御前听报室为准；“国策值房”只是御前听报室的内部值房称呼，同一物理房间。

### 0.3 全局禁止项

以下禁用词和验收条件适用于已登记的 16 张资产；每张资产的 negative prompt 会在此基础上补充局部禁用项：

- 现代品牌 LOGO、赞助商标、现实战队标记、现实职业选手英文名、随机文字乱码、伪汉字、长段无法阅读文字。
- 真实人物脸、可辨认角色肖像、角色海报、男性职业哥形象、后宫色情化、身体占有暗示、把位号画成恋爱等级。
- 纯游戏 UI 截图、悬浮系统面板、技能树、任务弹窗、万能电脑人格、科幻霓虹赛博朋克、紫蓝荧光灯带。
- 把宫廷做成舞台布景、现代电竞馆贴古装、纯古风空景、只摆古董不具备真实网络/设备功能、过度黄金宫殿、塑料 cosplay 质感。
- 让 CS 只剩“键盘发光”和“高手气场”；至少保留地图/点位、人数/经济、道具/时间、五席职责、回放或赛务中的两项可读信息。
