# 全职电竞方法迁移与原创边界

## 1. 迁移的不是素材，而是职业系统

本项目只提炼成熟职业竞技叙事的底层方法：比赛是公开规则下的高风险选择；选手、队友、解说、观众、赛后舆论和组织构成反馈回路；角色通过打法、习惯、语言、压力反应和利益选择形成差异；专业信息要翻译成读者能跟上的口语；胜负之后必须留下关系、资源、名分和下一场限制。

迁移后的本项目闭环为：

```text
赛籍/阵容/合同
      ↓
地图禁选与资源 → 回合选择 → 队友协作 → 比分/数据
      ↓                    ↓
赛务记录 ← 解说/观众 ← 赛后回放与论坛
      ↓                    ↓
责任复盘 → 首发/训练/合同/舆论变化 → 下一场比赛
```

## 2. 七条可迁移原则

### 2.1 职业比赛要像职业体育

每场正式赛包含赛前准备、回合动作、现场解说、赛后结果和余波。高光不能只有枪法；读者要知道谁拿信息、谁交道具、谁承担第一接触、谁补枪、谁选择保枪，以及这个选择让下一轮少了什么。

### 2.2 比赛必须有完整反馈回路

每场比赛至少留下：明确比分/地图结果、一个可复述的战术选择、一个公众版本、一个关系后果和一条下一场限制。比赛结束后，角色的位置必须已经改变。

### 2.3 角色差异来自重复选择

为每人固定打法、可见习惯、说话节奏、压力反应和不肯放弃的利益。相同经济局里，主狙、突破、支援、二号位、队长和候补可以做不同但合理的选择，并承担不同代价。

### 2.4 战术用中国玩家口语解释

采用“可见动作—队内/解说口语—结果与代价”。术语第一次出现只解释一层，不把章节写成攻略；不熟悉 CS 的读者能跟上，老玩家能判断选择是否真实。

### 2.5 热血、笑点和宫斗围绕同一事件变调

热血来自有人在有限时间里承担风险；笑点来自礼法、设备、合同和职业任务错位；宫斗来自首发、资源、指挥、舆论、责任和去留的重新分配。笑点之后必须留下更具体的职业问题。

### 2.6 成长来自协作与利益判断

贼贼姐从“我判断正确”走向“我让队伍共同判断”。她要学会把权力交给看见新信息的人，接受队友反对，公开自己的错误，允许队友通过试训获得资格，也允许队友离开。

### 2.7 宫廷视觉与硬件组成同一生产系统

宫门对应门禁，印信对应赛务回执，值房对应训练排班，回廊对应地图通道，铜灯对应设备状态，账册对应资源和责任记录。视觉元素只有在改变角色选择时才保留。

## 3. 本项目的原创边界

### 3.1 禁止复制参照作品

- 不复制任何人物姓名、人物组合、人物履历、一对一性格模板或关系收束。
- 不复制任何台词、口头禅、章节标题、宣传语、标志性镜头和胜利宣言。
- 不复制任何世界观、组织名称、职业制度、能力规则、地图/副本结构或道具设定。
- 不采用“换名但同样的情节链”，不让读者一眼看到对应人物和对应高潮。
- 不暗示本项目是官方续作、官方平行改编或角色对应表。

### 3.2 禁止本项目内部偷懒

- 不让贼贼姐一个人拥有全部信息、全部高光、全部权限和最终答案。
- 不把队友写成资源、恋爱奖品、五个分身或只负责证明主角正确的工具人。
- 不把宫斗写成吃醋、争宠和阴阳话；每一次权力冲突都要落到首发、座次、合同、资源、发言、责任或联盟。
- 不把电脑写成人格、神谕、任务发布者或胜负保证者。
- 不用性别、外貌、民族、国家天赋解释枪法和道德；战术来自训练、合同、地图、经济和职责。
- 不只写胜利；必须写赛后解释、责任追踪、资源调整和下一场代价。

## 4. 交付前三轮审核

### 竞技轮

核对地图、经济、道具、人数、时间、枪位、补枪、暂停和比分是否互相支持。高光能否被复盘；如果删掉术语，动作是否仍成立。

### 戏剧轮

不熟悉 CS 的读者能否明白人物为什么争、让、拒绝、站队或离开；比赛结果是否改变关系和组织状态；笑点是否来自处境而不是羞辱。

### 原创轮

逐段排除参照作品的专名、台词、人物对应、世界观影子和相同高潮摆位。检查大清战队是否保持国家/宫廷代表身份，其他女性化原型是否仍属于外邦，电脑是否仍是现实设备。

## 5. 生产上的可复用事实单

写每场比赛或训练前，先记录：事件类型、当前目标、限制、五席分工、关键选择、观众解释、赛后后果、视觉物件和责任栏。没有事实单，就不以“热血”代替比赛因果。

## 6. 原创的最终标准

读者记住的应是贼贼姐、大清战队、外邦队、五席约、回放责任、宫门与硬件的共同生产系统，以及每个人在关键时刻选择承担什么，而不是某部成熟作品的替代影子。故事可以有职业热血和团队关系，但职业热血必须被本项目自己的国家赛籍、女性化主体性、制度史断裂和五席责任重新组织。
