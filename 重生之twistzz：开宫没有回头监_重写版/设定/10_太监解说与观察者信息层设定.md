# 太监解说与观察者信息层设定

> 状态：正式设定  
> 定位：穿越后比赛的直播、OB、回放和公共叙事系统  
> 核心原则：**专业先于奇观，信息先于口彩，人物尊严先于笑点。**

## 1. 设定目的

QingCS 的比赛不能只靠主角内心和队内语音解释。普通读者需要一个能跟上交火的公共入口，老玩家需要足够真实的经济、道具和站位判断，漫剧还需要稳定的画外声音把现实赛台、游戏战场和回放连接起来。

因此，平行大清的观议司设有正式比赛播报班。直播中的核心声音由太监解说承担，幕后观察者同样由经过赛务认证的太监担任。太监身份来自宫廷职业制度，不是异能、神谕或喜剧惩罚。

本设定不把太监写成：

- 只会尖叫的高亢嗓音；
- 娘化、猥琐或身体羞辱笑话；
- 只会喊“圣上万岁”的宫廷摆设；
- 能偷听队内、预知战术或修改比分的万能权限节点；
- 用文言文掩盖不懂比赛的假专业解说。

## 2. 机构关系

### 2.1 观议司

观议司负责直播制作、采访、公共口径、赛后剪辑和舆论档案。洛遥音仍是该层的核心公共人物，负责：

- 决定正式直播的栏目、采访和赛后版本；
- 与赛务确认哪些队内语音、回放和责任材料可以公开；
- 管理解说排班、广告/赞助禁入规则和文字后期；
- 在争议回合后区分直播判断、赛务结论和队内复盘；
- 对剪辑失真、标题误导和公众版本承担职业责任。

洛遥音不是现场每一秒都在说话的主播，也不被太监解说替代。她更接近直播制作人、公共主持和赛后口径负责人。

### 2.2 播报班

播报班是观议司下属的专业岗位组，固定包含：

| 岗位 | 公开称呼 | 核心工作 | 不能做的事 |
|---|---|---|---|
| 实时解说 | 唱局太监／唱局监 | 报交火、人数、时间、掉包、残局和胜负瞬间 | 不替队伍报点，不用声量代替事实 |
| 战术解说 | 评策太监／评策监 | 解释经济、道具、站位、轮转、补枪链和下一轮代价 | 不把结果倒推成唯一正确答案 |
| 观察者 | 掌镜太监／掌镜监 | 切第一人称、自由镜头、俯视图、慢放和证据插入 | 不追求漂亮镜头而错过关键交火 |
| 数据与回放 | 录局太监／录局监 | 标时间戳、经济曲线、道具轨迹、击杀顺序和回放索引 | 不修改原始录像，不替赛务定责 |

默认直播使用一名唱局监、一名评策监和一组幕后掌镜/录局人员。除剧情明确写换班、病假或重大争议外，同一赛事阶段的固定搭档不得随机换脸、换声线或换职责。

## 3. 默认形象与声音连续性

### 3.1 唱局监

- 成年男性，约 30—45 岁；
- 身形偏瘦但不幼态，动作快，坐姿前倾；
- 深绛短圆领工作袍，袖口收紧，铜边耳机与悬臂麦克风；
- 说话速度随交火提升，但咬字清楚；
- 高潮时提高密度，不默认提高音高；
- 手边只有回合计时、击杀顺序和即时人数，不摆夸张拂尘。

### 3.2 评策监

- 成年男性，约 40—55 岁；
- 体态稳定，坐姿较直，表情克制；
- 黛青工作袍，玉白数据板、铜边回放旋钮和低反光耳机；
- 语速比唱局监慢，负责把复杂回合压缩成一到两句因果；
- 不以“老气横秋”代替专业，也不永远正确；
- 允许在回放后修正现场判断，并明确说出证据变化。

### 3.3 掌镜监与录局监

- 多数时候只出现背影、侧脸、手部和观察者台；
- 服装为墨青或黑绿短工作袍，便于操作多屏终端；
- 手部动作必须对应真实观察者工作：切人、标记、回放、缩放、时间轴定位；
- 不拿拂尘指屏幕，不把印章当鼠标，不用宫廷动作替代专业操作。

## 4. 解说语言规范

### 4.1 语言比例

一段完整正式赛解说建议保持：

- 约 70% 现代中国 CS 口语；
- 约 20% 地图、经济、道具、赛务和数据解释；
- 不超过 10% 宫廷报幕、礼法节奏和固定口彩。

宫廷词是调味，不是每句都要古风。可用词包括“鸣钟开局”“入席”“报局”“封口”“回录”“候审”“请看俯图”，但进入交火后优先说“中路两个”“A 大掉人”“包落了”“只剩十五秒”。

### 4.2 现代术语保留

以下短词直接保留：

`AK / AWP / M4 / 沙鹰 / USP / 烟 / 闪 / 雷 / 火 / 包 / 钳子 / 经济局 / 强起 / 全起 / 保枪 / 补枪 / 架枪 / 拉枪 / 回防 / 假打 / 默认 / 前压 / 残局 / 一打三`

不得为了古风把“补枪”改成冗长官话，把“烟”说成每次都念全称“云烟罐”。首次视觉亮相可以说式样名，之后回到通用短名。

### 4.3 一次解说只完成一项主要工作

- 唱局监先报**发生了什么**；
- 评策监再说**为什么重要**；
- 回放阶段再说**证据支持什么**；
- 赛后节目才说**公众会如何理解**。

禁止在一秒交火里同时塞地图史、武器史、人物履历、经济规则和宫廷笑话。

### 4.4 可调用语例

**回合开始：**

> 唱局监：“鸣钟开局。大清这轮全甲全道具，箱姐的 AWP 先看中门。”
>
> 评策监：“北凛少一颗中路烟，第一轮碰撞会来得很早。”

**快速交火：**

> 唱局监：“A 大先掉一个！雨姐没退，她把第二个人留给补枪——贼贼姐跟上了！”
>
> 评策监：“这不是两个人各打一个，是同一条补枪链。大清现在可以把烟留给包点。”

**残局：**

> 唱局监：“只剩十五秒，包还在中路。贼贼姐一打三，先拿包，不能贪人。”
>
> 评策监：“她听见的是 B 门脚步，但看不见第三个人。先下包才把时间变成自己的。”

**现场判断被回放修正：**

> 唱局监：“方才我以为是箱姐先空枪。”
>
> 评策监：“回录给到俯图——不是空枪，是前一颗火逼她多退了半步。现场判断撤回，责任要看投掷顺序。”

**宫廷错位笑点：**

> 唱局监：“烦请诸位先别给她封神，包还没拆完。”
>
> 评策监：“是，圣旨也得等钳子走满五秒。”

笑点之后必须回到计时、拆包或责任事实，不能停在段子上。

## 5. 信息权限

### 5.1 可用信息

太监解说和观察者可以使用：

- 公开直播观察者画面；
- 已公开的小地图、人数、时间、经济和道具；
- 联赛允许展示的选手第一人称；
- 赛后或延时开放的队内语音片段；
- 赛务确认可公开的回放、时间戳和责任材料；
- 现场可见的暂停、设备问题和裁判手势。

### 5.2 禁止信息

不得使用：

- 选手内心、未说出口的判断和私人记忆；
- 未公开合同、伤病、转会和纪律材料；
- 仍在保密期的战术、训练录像和队内争执；
- 未来回合结果、系统预测或所谓天意；
- 通过观察者视角向选手传递的敌方位置；
- 未经允许的实时队内语音。

### 5.3 直播延时与隔离

正式国际赛默认存在观战延时。解说席、观察者台和选手赛台物理隔离：

- 解说声音不进入选手耳机；
- 观察者屏幕不在选手视线内；
- 现场大屏在赛事规则需要时使用延迟；
- 掌镜监与录局监不得接触队内语音频道；
- 任何串音、误播或提前泄露都必须成为赛务事件，而不是便利剧情。

## 6. 观察者镜头规则

### 6.1 掌镜优先级

1. 即将发生的第一接触；
2. 能解释交叉火力与补枪关系的镜头；
3. 包、时间和残局关键位置；
4. 道具落点与烟墙变化；
5. 回防路线和绕后信息；
6. 高光后的现实赛台反应；
7. 赛后慢放与责任证据。

不能因为某位角色更受欢迎就长期锁她第一人称，错过真正改变回合的人。

### 6.2 观察者失误

掌镜监可以犯职业错误，例如：

- 切晚一步，错过第一枪；
- 追逐热门选手，漏掉包的转移；
- 俯视图停太久，观众看不清个人操作；
- 第一人称切太快，空间关系丢失。

失误必须能被复盘和改进，不能写成恶意操控的默认阴谋。

### 6.3 UI 视觉

观察者 UI 使用：

- 玉白或浅灰信息底；
- 黛青与绛色区分两方；
- 铜金只用于选中框、计时危险和回放刻度；
- 小地图边框可借卷轴、玉屏或铜镜结构，但内部线条保持现代清晰；
- 击杀栏和经济数字不使用书法字体；
- 精确文字以后期合成，生成画面只留干净安全区。

## 7. 声音设计

### 7.1 音轨层级

比赛成片至少区分：

1. 枪声、脚步、投掷物和炸弹；
2. 队内语音；
3. 太监解说；
4. 现场观众与比赛殿底噪；
5. UI 提示与回放音；
6. 配乐。

枪声和队内关键信息优先。解说不能持续压住脚步、拆包音和关键报点。

### 7.2 J-cut 与 L-cut

- 可用太监解说的 J-cut 提前把观众带入游戏战场；
- 可用枪声或倒计时的 L-cut 把游戏结果带回现实赛台；
- 回放时解说音色稍收窄，明确与实时交火区分；
- 争议回合中可让现场解说先停一拍，再由回录证据进入，避免强行煽情。

### 7.3 禁止声音梗

不得使用尖细变声、滑稽宫廷配乐、每次爆头敲锣、每次残局喊万岁或用身体特征制造笑声。

## 8. 戏剧功能

### 8.1 普通读者入口

唱局监用人数、时间和动作告诉读者“发生了什么”；评策监用一句因果告诉读者“为什么重要”。解释后立刻回到人物选择，不把章节变成教学视频。

### 8.2 公众版本与事实偏差

现场解说可能因为视角有限形成初步判断，观议司剪辑可能强化某一版本，赛后回放再补充证据。三者必须分栏：

- 直播判断不是赛务结论；
- 公众热词不是队内事实；
- 回放证据能修正解说，但不能读取动机；
- 洛遥音对剪辑和标题负责，太监解说对现场表述负责。

### 8.3 角色与解说的关系

选手可能听见赛后回放中的解说，但比赛当下听不见。解说对“总监”“老六”“保枪”等公共标签的使用会影响舆论，却不能授予正式席位、权力或道德结论。

### 8.4 太监解说自身成长

太监解说也应有职业弧线：

- 从追高光到尊重补枪、道具和信息位；
- 从结果论到愿意在回放后撤回判断；
- 从宫廷口径优先到区分赛务事实与宣传需要；
- 从只叫热门角色到能说清低可见度工作的价值。

这类成长通过具体直播失误、回放修正和公开道歉发生，不需要把他们加入主角团。

## 9. 漫剧分镜调用

每个出现太监解说的分镜单元至少写清：

- `EUNUCH_CAST_ROLE`：唱局／评策／掌镜／录局；
- `KNOWN_INFO`：该岗位此刻合法知道什么；
- `LINE_FUNCTION`：报事实／解释因果／修正判断／转场／制造公众版本；
- `AUDIO_PRIORITY`：解说是否让位于枪声、脚步、队内语音或拆包音；
- `OBSERVER_VIEW`：第一人称／自由镜头／俯视图／回放；
- `UI_SAFE_AREA`：比分、击杀栏、地图和字幕的后期区域；
- `END_STATE`：观众在该句后多懂了什么。

图生视频不要求模型生成准确口型长对白。高风险对白使用画外音、侧背影、短口型或后期配音。

## 11. QC 清单

- 解说是否先报可见事实，再做判断？
- 唱局、评策、掌镜和录局是否各守职责？
- 是否使用了该岗位无权知道的信息？
- 是否把直播判断误写成赛务结论？
- 是否以尖嗓、娘化或身体梗代替人物？
- 宫廷词是否少量、清楚且不妨碍 CS 口语？
- 解说是否在关键脚步、拆包、队内报点和枪声处让位？
- 观察者镜头是否交代了真正改变回合的人和动作？
- 精确 UI、比分和字幕是否留给后期？
- 高光之后是否回到现实人物承担的后果？
