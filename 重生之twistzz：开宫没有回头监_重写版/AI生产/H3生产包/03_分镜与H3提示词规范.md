# 分镜与 MiniMax-H3 提示词规范

## 1. 输入事实优先级

```text
已发布/当前正文事实
> 章节总纲与逐章硬锁
> 人物档案、制度和场景权威文件
> 导演书
> 十格分镜
> H3 JSON
> 单次生成结果
```

下游文件不能反向改写上游事实。H3 生成出了更“好看”的动作，也不能据此改变人数、队籍、合同、时间线或角色权限。

## 2. 单格字段

第 2—44 章每格必须有：

1. 景别/地点；
2. 画面动作，且含 0—3、3—10、10—15 秒；
3. 台词或音效；
4. CS 信息；
5. 关系/笑点；
6. 空间锚点。

第 1 章优先读取原有导演级字段：`SCENE`、`ACTION`、`CAMERA`、`BLOCKING`、`PERFORMANCE`、`AUDIO`、`TRANSITION`、`CONTINUITY`、`NEGATIVE`。

## 3. 双层时间线

### 总段 00:00—00:15

只描述本格的因果链：主体处于什么状态，收到什么信息，做出什么动作，最终停在哪里。不得描述跨镜剪辑后的下一格结果。

### 分拍时间线

- 00:00—00:03：建立空间、人物位置、目标、人数或证据来源。
- 00:03—00:10：完成一个核心动作；镜头运动只能服务揭示、跟随或强调。
- 00:10—00:15：保持结果、关键台词或证据，让观众读懂后再切出。

## 4. 比赛镜头

- 必须先建立谁是进攻/防守、是否下包、当前人数、关键点位和目标。
- 脚步、报点、鼠标/键盘输入、准星转移、枪声和倒地结果有明确先后。
- 补枪镜头要看见第一枪、补枪距离和第二人的决策，不只靠击杀栏解释。
- 解说与观察者信息不回传选手席；画外队友语音不得让画面人物凭空对口型。
- HUD 只留后期安全区；不让 H3 生成精确比分与姓名。

## 5. 宫廷制度镜头

制度必须通过可见动作落地：分栏、签字、盖章、拒签、回执、封存、物件换手、门禁、空栏、训练表变化。禁止用漂浮面板、权限值、神谕播报或一段解释性旁白替代。

## 6. 参考图模式

编译器自动选择：

- 没有已验收人物图：`t2va`；
- 命中一张或多张人物三视图：`ref2va`。

当前批次不自动生成或猜测首帧/尾帧，因此不会自动切换 `i2va`、`fl2va` 或 `l2va`。手动使用帧模式时必须移除全部多模态 reference；两类输入不能混合。

## 7. 声音

H3 提示把声音分为：

- 可见动作同步声：脚步、鼠标、纸张、印章、门禁、枪声；
- 画内对白：逐字保留、说话人稳定、口型只绑定可见说话者；
- 画外队伍语音：保持无线电/耳机空间，不在镜头里发明嘴部动作；
- 环境床：场馆低频、机柜风道、宫门风声、观众与远处设备车；
- 非叙事音乐：克制，永远不盖报点、脚步、枪声和短对白。

## 8. 文字与 UI

以下内容统一进入后期：比分、人数 HUD、地图名、队名、角色名、击杀栏、门禁时间、合同字段、名册、印章、直播标题、弹幕和赛务状态。提示词只描述版面位置、空白安全区和对应物理载体。

## 9. 失败诊断

| 失败 | 修正 |
|---|---|
| 人物像三视图拼贴 | 减少参考人物，强化“只锁身份，不复制白底排版”，改用单人动作首帧 |
| 宫殿过度豪华 | 加入工作磨损、线缆、散热、门禁、推车和窄空间；删除金色英雄构图 |
| 比赛看不懂 | 补人数、目标、位置建立镜头；缩短交火链，减少无动机摇镜 |
| 随机汉字 | 删除提示里的精确文字要求，只保留安全区和后期字段 |
| 多出人物/同脸 | 减少同时参考图数量，写清站位与入画顺序，拆镜 |
| 角色越权 | 回到人物档案和制度栏，给真正的签字人/拍板人一个可见动作 |
| 15 秒塞太满 | 把第二个决定或第二个地点移到相邻格；不要加速对白 |

## 10. 生产验收

免费阶段先运行测试与 JSON 编译；付费阶段从单格开始。只有角色、空间、战术、对白、声音、后期文字安全区和终态全部通过，才执行相邻格。整章批量生成是最后一步，不是第一步。
