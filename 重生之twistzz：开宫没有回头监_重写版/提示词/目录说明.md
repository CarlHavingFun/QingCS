# 提示词目录说明

本目录存放可直接调用的文本提示、生产清单和模型接入说明。

## 当前人物视觉权威入口

1. `古风人物定妆照提示词总表.md`：22 位核心人物的标准定妆照提示词。
2. `../skills/qingcs-ancient-character-visual/SKILL.md`：提示词生产、发型调用、无武器硬锁和 QC 流程。
3. `../人物档案/23_全员外貌性格与古风发式深化.md`：人物脸型、体态、性格与基础发式。
4. `../人物档案/23A_发型参考源与无武器定妆规范.md`：外部发型参考源和标准定妆禁物。
5. `../人物档案/24_主角与必要角色穿越前档案_内部制作层.md`：主角及旧世界必要人物的内部研究档案。

人物标准定妆照固定为空手无武器。旧审核文件若包含枪械、主狙匣、步枪匣、武器箱、弹匣袋或持械姿态，只能作为历史审计记录，不能覆盖当前人物视觉权威入口。

本目录中的人物提示只使用公开中文名；现实职业 ID 只允许出现在明确标注内部制作层的研究文件中。
