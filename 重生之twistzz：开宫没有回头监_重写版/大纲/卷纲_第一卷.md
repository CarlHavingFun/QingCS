# 宫门换世 卷纲

## 核心信息

- 章节范围：第01—08章
- 字数目标：约4.8万—5.2万字
- 本卷定位：开篇、身体适应、身份查证、入场资格争夺
- 已生效范围：第01—04章
- 下一工作章：第05章（待作者确认后进入）

## 卷契约与终局储备

- 卷契约：主角不靠穿越特权，从普通终端和职责短测重新证明自己能成为二号位。
- 本卷主推线：身份与席位线，从三日观察对象推进到国内资格赛临时第五席。
- 本卷战果：当前身体可用操作稳定；与四席建立最初职业信任；慈宁宫资源链首次露出具体后果；7比5保留查证入口。
- 本卷解锁的终局里程碑：取得国内资格赛的临时登记入口。
- 本卷禁碰的终局底牌：穿越机制、原贼贼姐去向、赤门旧案全貌、正式世界冠军级能力兑现。
- 契约风险：契约安全。每次程序授权都必须由主角先用判断与行动赢得，且收益只到下一层。

## 剧情单元卡

### 剧情单元 L1-01

- 单元ID：L1-01
- 章节范围：第01—04章
- 对标剧情参照：无
- 单元节拍：失冠与异常 → 身份、门禁和男性禁限复核 → 新身体第一枪 → 四席职责短测与继续训练
- 单元承诺：证明“职业判断还在”不等于自动恢复旧身份；主角要把能力重新落到当前身体和当前队伍里。
- 单元情绪引擎：主角失去熟悉身体与赛台 → 普通终端提供窄入口 → 两次失败暴露旧错误与新距离 → 主角压住越权冲动完成补枪 → 队友只给有条件的职业承认。
- 卷级贡献：完成从陌生闯入者到可继续训练的观察对象。
- 主角局部目标与核心利益：保留查档和训练入口，建立当前样本，争到下一轮宫内选拔资格。
- 因果入口：北港决赛7比5异常和穿越。
- 核心阻碍：身体距离变化、旧操作档案、正式权限关闭、四席各自的职责怀疑。
- 关键选择与决定性行动：主动接受窄测试、单独留存当前样本、只报条件并等待最终拍板。
- 兑现方式与归属：一次干净补枪归主角操作，继续训练由四席意见和人工签字落地。
- 本单元主推线/战果：主推入场资格；战果为身体校准、证据分袋和有限证据同盟。
- 终局底牌边界：不能证明穿越，不能恢复首发，不能进入正式五人合练。
- 禁止提前释放：7比5真相、正式赛用设备、国力赛资格。
- 下一单元因果钩子：慈宁宫家族候选携资源进入宫内选拔。
- 风险等级：契约安全。

### 剧情单元 L1-02

- 单元ID：L1-02
- 章节范围：第05—08章
- 对标剧情参照：无
- 单元节拍：同机请求待裁定与候选资源压场 → 主角赢得未注册候验优先意见 → 三日到期、旧制派要求停训 → 四方有条件续期 → 身份询问中追查7比5 → 国内资格赛临时第五席登记
- 单元承诺：训练结果必须压过保荐与资源；第05章只赢候验排序，第06章只续观察，第08章才获得阶段性登记，不把制度冲突一次解决。
- 单元情绪引擎：公平请求尚未获准 → 候选的真本事与资源优势同时施压 → 主角用残局守住排序 → 到期权限再次归零 → 队友用带条件的意见共同担责 → 临时第五席形成。
- 卷级贡献：偿还卷一入场资格期待债，并把旧案与国内资格赛推入第二卷。
- 主角局部目标与核心利益：拿到依法可复盘、权限边界清楚的临时第五席，并保住查证资格。
- 因果入口：第04章末候选申请与设备清单。
- 核心阻碍：内务府资源差、身份流言、慈宁宫停训要求。
- 关键选择与决定性行动：先要求裁定同项同机，再以残局判断而非数据榜争候验排序；到期后接受四方条件而不冒领正式首发。
- 兑现方式与归属：第05章候验优先意见由主角赢取，第06章续期由四方分别担责，第08章临时第五席才由司竞监登记。
- 本单元主推线/战果：主推身份席位线；战果为队友初步站队与7比5调阅入口。
- 终局底牌边界：不能证明男魂、不能解决男性禁限、不能获得永久首发。
- 禁止提前释放：赤门旧事故密折全貌。
- 下一单元因果钩子：国内资格赛前设备被调包。
- 风险等级：契约安全。

## 核心矛盾

主角必须在旧身份不可信、正式权限关闭和宫廷资源干预下，用当前身体与当前队友重新赢得临时入场资格。

## 对标结构坐标

无外部对标，按八节点占比自排：第02章规则加压，第04章完成第一轮窄兑现，第06章旧制反扑，第08章临时五席结算。
