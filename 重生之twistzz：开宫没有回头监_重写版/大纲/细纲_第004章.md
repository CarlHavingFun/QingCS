# 细纲（第004章）

## 第004章：五席都想试我？那就一起上

- 核心事件：主角依次接受箱姐、雨姐、老六姐和大表姐的普通终端短测，只凭一波按令完成的补枪赢得继续训练。
- 字数目标：4500字
- 阶段位置：开篇期；第一卷第4章；完成第一轮职业关系窄兑现。
- 单元ID/位置：L1-01末拍，决定性行动与单元兑现。
- 目标情绪：四席把她当成旧身体里的危险变量 → 各自看见她能守住一条职责边界 → 形成有条件的专业认可。
- 主角目标/关键选择：拿到继续训练入口；关键选择是压住抢全队结论的冲动，只报事实、条件和自己的最小动作。
- 章节定位：推进、关系试探、修炼试错。
- 本章结构公式：四卡落时段 + 三项职责拆测 + IGL综合压测 + 一波补枪窄兑现 + 家族候选资源钩子。
- 章首钩子：限时任务钩子。四张卡被压到同一早晨，黄牌有效期继续倒数。
- 爽点：四种岗位问题在最后一次普通终端压测中汇合，主角等大表姐拍板后完成唯一一波干净补枪。
- 本章禁止提前释放：正式赛籍、正式五人合练、原赛用设备、首发归位、穿越真相、队友无条件信任。
- 契约风险：契约安全。继续训练由主角的选择和操作赢得，四席保留自身职责与人工拍板。

### 内容概括（五段式）

- 起因：第03章末四张短测卡排到次日，主角携黄牌和公用设备编号到乾清门接受逐项见证。
- 发展：箱姐检查主狙撤退与再架通道；雨姐检查入口条件不全时能否停；老六姐检查晚段半条信息会不会被擅自扩写。
- 转折：前三项记录有失败、有勉强、有完整，大表姐把三项素材合成最后一次短压测，并明确最终口令仍归她。
- 高潮：主角只报已确认事实和自己的跟枪动作，等到“按这个做”后，用雨姐的固定入口轨迹完成一波补枪，随后按“收”停住。
- 结尾：四席签下继续训练意见，慈宁宫随即送来带家族保荐和专配设备清单的红边候选卡。

### 情节安排（多线）

- 主线推进：三日观察对象获得下一段受限训练和宫内选拔入口。
- 辅线推进：慈宁宫与内务府资源链开始介入第五席竞争。
- 事件线 / 任务线：四张短测卡逐项消费，最后由人工签字结算。
- 任务卡点：主角想把四项压成一项尽快证明自己，但卡面要求分别见证；逐项受限逼她尊重四席不同职责，删掉会损失关系变化与权限边界。
- 感情线 / 关系线：无显性感情线；队友由“只读摘要后的怀疑”推进为“愿意继续测试的专业承认”。
- 逻辑线：短测卡生效 → 各职责暴露不同越权风险 → 主角修正表达与动作 → IGL授权综合压测 → 补枪完成 → 继续训练意见 → 外部候选入场。

### 人物关系和出场顺序

- 出场顺序：贼贼姐、乾清门值守、箱姐、雨姐、老六姐、大表姐、慈宁宫送件人与红边候选卡。
- 人物关系变化：四席各自防备 → 承认一项可复盘事实 → 愿意让主角进入下一轮受限训练。
- 视角/信息差：主角知道自己来自北港；四席只知道当前样本与旧档不同；任何人都不能从操作差异推导穿越。
