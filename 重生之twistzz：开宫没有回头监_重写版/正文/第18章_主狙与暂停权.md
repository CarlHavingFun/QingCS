# 第十八章 主狙与暂停权

《旧桥》重新开服，联合训练第九回合的计数接回四比四。

我们守方，回合钟一分五十五秒，双方五打五。箱姐拿 AWP、全甲、长线烟和闪；雨姐带 M4、全甲、入口烟和闪；我、老六姐和大表姐各拿步枪、全甲、烟和闪。大表姐把拆包器也买进腰包，购买栏最下面多出一个小小的工具图标。

“这回先把谁有东西说清。”她把购买栏推到我们面前，“暂停要我申请，赛务确认。枪和道具掉了，就按下一回合的购买栏算。”

箱姐在外廊石柱架好 AWP，内廊的门柱是雨姐的退点，连接口窄得只够我和老六姐听见回防声。箱姐抬了抬镜口：“第一枪后退石柱，第二个只露影子，我不追。”

呼延霁把霜旌队的晚段换位留在后半段。前段外廊只落了一声脚步，第二层道具迟迟没压出来，大表姐让我们守住已知枪线，没催箱姐离开长线。

一分十秒，外廊烟边先露枪管，再露肩线。箱姐的 AWP 响了一声，立刻退回石柱。

人数从 5v5 变成 5v4。

我在内廊听见脚步贴门：“第二个没进，内廊有人。”

雨姐把 M4 压在门柱后。迟后的闪光终于落下，第二名冲进内廊，她从入口烟边打掉对方，收枪退回门柱。

人数从 5v4 变成 5v3。

“第二个还在烟后。”雨姐报。她的入口烟留在手里，没为了追第三个人提前交掉。

老六姐把回防烟压到连接出口，沿烟边补掉第三个人。烟刚展开，霜旌队的远端枪线便穿过来，她倒在自己的烟旁。

人数从 5v3 变成 5v2，再变成 4v2。

大表姐从中路压向入口，枪口刚贴到门柱，侧墙另一把枪追着她的脚步扫过来。她倒地时，腰侧的拆包器滚到入口边。

人数从 4v2 变成 3v2。

我在耳机里听见雨姐吸了一口气：“工具掉了。”

“先收枪线。”大表姐的声音已经断了。

箱姐把镜口拉回外廊烟缝，等肩线完整出现，第二声 AWP 打掉一人。

人数从 3v2 变成 3v1。

最后一名霜旌队员沿内廊撤向入口。我贴着箱姐确认过的长线，先听脚步过门，再等半身露出，两发步枪收掉最后一人。

人数从 3v1 变成 3v0。

包没有安放，训练计数从四比四变成五比四。雨姐、箱姐和我活着带出 M4、AWP 和步枪；老六姐、大表姐的步枪和拆包器留在这一回合的入口。

回合结算后，赛务把掉落栏随比分一起清空。下一次冻结时间的地图画面里，入口已经只剩门柱和烟痕。

大表姐的队长牌重新回到赛务桌。她申请三十秒暂停，顾折枝从独立赛务入口确认，暂停回执压在购买栏旁。顾折枝提醒：“只冻结下一次购买，五比四和掉落物按刚才的结算走。”

箱姐先开口：“主狙还在我手里。下一回合我保外廊长线，别拿 AWP 的钱去填别人的空缺。”

米教姐把建议递到暂停桌：“守方先补拆包器。主狙、入口和跟枪的烟别全砍，先保证能打出回防。”

大表姐看着那行建议，又看向三把带出来的枪。她按住队长牌：“建议我收到了。三十秒里我决定购买，谁报自己的道具，谁承担缺口。”

雨姐把 M4 的设备牌推到她面前：“我有入口烟，闪要重新买。要是把钱给拆包器，我的闪就没了。”

“我不换 AWP。”箱姐说，“长线断了，M4也只是守门。”

我把自己的步枪牌放回格子里：“我的跟枪烟还在，能让你们保第二枪。”

大表姐的目光在 kit 那一栏停住。三十秒只够做一次取舍，她最后把购买栏转向所有人。

“拆包器没被带出。下一回合按购买栏算，先按无人有 kit。”她说，“我们保三把枪和入口烟，包落点由听见的人先报；谁要改这个决定，现在说。”

米教姐的手指收了回去。她没有替大表姐改口。

暂停结束，箱姐把 AWP 挂回主狙设备架，雨姐把 M4 压在入口牌旁。她看着购买栏里空着的 kit 格，把入口烟往自己这边挪了挪：“那我下一回合先报入口，包点听见了再叫。”

大表姐把队长牌翻回正面：“听到包，第一时间叫我。”
