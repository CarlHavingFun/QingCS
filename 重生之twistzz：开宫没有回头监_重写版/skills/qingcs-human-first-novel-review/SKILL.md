# QingCS 人话优先与防踩坑审校

## 使用顺序

写任何正文前先读本Skill；正文完成后再逐条复核。它高于“写得有道理”，第一标准是：**一个处在现场的人会不会这样说、这样想、这样做。**

## 一、对白不能替作者做总结

角色只说她此刻想让别人做什么，不说章节主题、审核结论或完整因果链。

### 已确认的反例

- “明天从第一句报点开始拆，今晚谁都别拿最后一枪给自己判刑。”
- “别只盯最后一帧。”
- “人名、地方和刚才做过的事都对不上。先别签任何东西，叫医务值守。”
- “你说的北港、这块奖牌，还有你为什么不认识我们，一样一样核。”

这些句子的问题：像会议纪要、心理咨询金句或作者替角色概括剧情。

### 推荐改法

- “这回合不怪你一个人。明早把这波重新走一遍。今晚先睡。”
- “最多再看十分钟。看完就回来。”
- “先别签。她状态不对，连我都认不出来。叫一下医务。”
- “今晚先歇着。明早我陪你查门禁和旧档。”

## 二、对白四问

每句重要对白必须能回答：

1. 说话人此刻知道什么？
2. 她此刻想让对方做什么？
3. 她和对方是什么关系，为什么用这个语气？
4. 这句话能否一口气自然说完？

任何一句同时解释三项以上设定，优先拆成动作、追问、物证和多轮短对话。

## 三、角色不能知道作者知道的事

不知道穿越的人只能根据眼前证据判断：输图应激、撞伤、低血糖、失忆、开玩笑或逃避复盘。

正确反应顺序：

`先吐槽/追问 → 发现对方不接玩笑 → 看见手抖、失衡或认人错误 → 担心 → 叫医务/查记录`

禁止所有人突然温柔、突然相信平行世界，或准确说出“身份错位”“另一个世界”。

## 四、证据出现不等于人物接受

重大变化至少经过：

`否认 → 主动验证 → 多份证据堵住旧解释 → 暂时配合 → 保留拒绝和回去目标 → 后续主动选择`

拿卡、跟队、穿队服、参加训练、签“到场”都只是具体行为，不能自动等于接受身体、国籍、队伍或使命。

## 五、比赛场景先让普通读者站稳

进入完整回合后尽早说清：

- 我方是进攻方还是防守方；
- C4有没有埋下；
- 谁守包、谁拆包；
- 当前人数；
- 输掉这一分会失去什么。

写“瞄着A1出口”，不写“准星压A1”；写“等我们先打前面的人”，不写“等我们转枪”。

## 六、场馆流程不能为剧情让路

- 对手夺冠时，大屏优先播放冠军和奖杯，不替败方循环播放失误。
- 完整复盘回到休息室或复盘室进行。
- 疑似伤病或定向异常时，赛务先停签、叫医务，不能趁异常取得身份或参赛同意。

## 七、第一次出现人物给三种锚点

只给读者当场需要的三项：

- 她是谁/与主角什么关系；
- 她在本场负责什么；
- 一个动作、外貌或说话习惯。

不要让四个人排队进门、自报姓名和人物小传。

## 八、段落与短句

- 常规段落2—4句；
- 不连续堆三个以上单句短段；
- 单句段只留给赛果、枪响、身份翻转和章尾；
- 连续对白之间必须有动作、视线、物件或停顿；
- 删除“到这一步，他终于明白了……”式重复总结，能让证据自己说话就不再解释一遍。

## 九、穿越必须逐级失控

按以下顺序升级：

`可解释设备异常 → 可测量时间错误 → 现实不同步 → 温度/气味/触觉越界 → 局部物件替换 → 空间完全重合`

不能从黑屏直接跳到完整宫殿，也不能只用白光解决。

## 十、历史常识误解要由人物自己提出

现代主角看到“午门”，应先想到斩首传说并产生警惕；本世界的人再用日常行动和具体地点用途解释。不要让主角毫无反应地收卡，也不要插入百科全书式旁白。

## 十一、书名和章名必须兑现

书名可直接卖“穿越大清＋CS＋女队首发”，但正文必须真的包含这些内容。章名可以爽，不能承诺本章没有的打脸、冠军、系统奖励或恋爱。

## 十二、电影级分镜不是形容词堆砌

固定流程：

`正文/潜台词 → 节拍 → 走位 → 轴线 → 镜头表 → 关键帧 → 模型提示 → animatic → QC`

每镜只有一个主要功能和动作终点。相机移动必须揭示信息、改变关系或表现失衡，不能只为“电影感”。

## 十三、逐章硬锁

当前章正文通过后，才同步当前章导演书和分镜；完成自检即停止。作者未确认前，不改下一章正文，不顺手修后续章，不跳号。

## 最终朗读检查

把所有对白单独读一遍：

- 像人临场说话，还是像作者写审查报告？
- 角色会不会知道得太多？
- 有没有一句话同时完成诊断、决定、安慰和主题总结？
- 去掉漂亮金句后，人物意图是否更清楚？

只要听起来“不像人会这么说”，就继续改，不以语法正确为通过标准。
