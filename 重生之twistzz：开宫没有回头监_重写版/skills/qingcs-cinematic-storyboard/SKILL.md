# QingCS 电影级分镜与预演

## 方法来源

本技能按 QingCS 项目需要，吸收并重组以下开源方法，不照搬其具体示例：

- `calesthio/generative-media-skills` 的 `storyboard-previsualization`：先验证故事节拍、空间、构图、动作、剪辑、时长、声音和连续性，再做生成提示。
- `game-cinematic-cutscene-design`：每个镜头必须有叙事工作，检查可读性、轴线、视线、屏幕方向、节奏、声音和场景交接。
- `higgsfield-ai/skills`：生成提示使用具体可见的镜头语言，图生视频重点描述运动，不反复重述静态画面。

## 核心原则

分镜不是“漂亮画面清单”，而是可执行的电影预演。先回答观众在这一刻要看懂什么，再决定景别、机位、表演、声音和剪辑。

每个15秒格只能有一个主要叙事任务，但可以拆成1—4个镜头。复杂动作不能靠加速对白硬塞；信息过载时优先删镜头、改视觉表达或明确标记需要扩时。

## 每格固定字段

1. **叙事任务**：本格结束后，观众比开始时多知道什么。
2. **观众问题**：本格必须回答的一个问题。
3. **镜头表**：稳定镜头编号、时长、景别/焦段、动作、镜头动机、人物调度。
4. **表演**：角色先看到什么、如何反应、情绪在哪一拍改变；不能只写台词。
5. **声音与剪辑**：对白、环境声、音乐、静默、J-cut/L-cut、硬切或匹配切换。
6. **连续性**：轴线、视线、屏幕方向、人物位置、服装、道具、光线、比分和物件状态。
7. **通过标准**：不看文字说明，观众是否能回答“谁在做什么、发生了什么变化、应该看哪里”。
8. **生成提示**：`SCENE / ACTION / CAMERA / BLOCKING / PERFORMANCE / AUDIO / TRANSITION / NEGATIVE`。

## 电影语言硬规则

- **先建空间。** 空间影响动作时，先给全景、中景或稳定锚点；不能连续特写后才解释人物在哪里。
- **守住180度轴线。** 为桌面谈话、门口进入、赛场走位标明轴线；有意越轴时必须用移动镜头或中性机位完成过渡。
- **屏幕方向有意义。** 人物连续移动保持同一方向；反向移动应表示退回、对抗或心理变化。
- **镜头运动必须有工作。** 推镜用于逼近决定，拉镜用于暴露孤立，横移用于揭示关系，手持用于不稳定；禁止“为了电影感而移动”。
- **景别服务信息。** 全景看地理，中景看关系和动作，近景看反应，特写/插入看证据。
- **表演先于说明。** 角色不懂穿越时，只能表现为疑惑、玩笑、担心、怀疑受伤或失忆；不能说出只有作者知道的真相。
- **声音可以先行或滞后。** 用J-cut预告下一空间，用L-cut保留上一情绪；异常场景允许声音、倒影和动作故意错半拍，但现实场景不能无意不同步。
- **剪辑必须有动机。** 枪声、动作方向、视线、形状、光线或声音可以成为切点；避免随机切换景别。
- **给镜头呼吸。** 决定、认人、拒绝和章尾至少留一个可读反应拍，不让人物说完关键台词立刻切走。

## 角色反应规则

当主角表现异常时，其他角色只能依据眼前证据判断：

- 先把异常解释为输图后的应激、撞伤、低血糖、记忆混乱、开玩笑或逃避复盘；
- 先吐槽或追问，发现主角没有配合玩笑后再转为担心；
- 每个人按自己的职业习惯反应：队长控制场面，主狙核对证据，入口位先照顾人，断后位观察细节，赛务员暂停流程并记录异常；
- 不能集体瞬间理解“她是穿越者”，也不能替主角解释身份认同问题。

## 生成连续性圣经

每章生成前固定：

- 角色脸型、发型、体态、服装、饰物和职业动作；
- 场景平面关系、门、桌、设备、光源和人物初始位置；
- 主色调、光线方向、景深和焦段范围；
- 关键道具由哪只手持有、当前朝向和状态；
- 每个镜头的轴线、视线和屏幕移动方向；
- 禁止变化：真实选手肖像、真实队标、随机文字、换装、角色漂移、道具凭空出现。

## 审核顺序

1. **故事审核**：本格是否只做一件主要事情，观众是否理解。
2. **空间/调度审核**：人物位置、轴线、视线和移动方向是否连续。
3. **表演审核**：反应是否来自角色已知信息，关键情绪是否有停顿。
4. **节奏审核**：15秒能否自然完成，是否存在加速对白和信息堆叠。
5. **声音审核**：对白、环境声、静默和切点是否帮助叙事。
6. **生成可行性审核**：复杂动作、文字、手部或连续身份是否需要拆镜、参考图或后期合成。
7. **交接审核**：本格结束状态能否无缝进入下一格。

完成一章分镜后，必须与正文逐项核对事实、人物认知、动作顺序、章尾状态和下一章接口，然后停止，不提前制作下一章。
