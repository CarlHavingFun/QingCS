# QingCS 小说正文与分镜生产

## 核心原则

先让读者进入现场，再让比赛发生。任何专业术语都必须依附于可见动作；任何设定都必须通过人物、物件或后果出现。

使用 `gpt-5.6-sol` 时，先读取 `提示词/GPT-5.6-SOL_章节续写提示词清单.md`，按“一章一契约、一章一审校、一章一提交”执行；继承《差半拍》的叙事机制，不机械复制其比喻和句式。

制作或审查分镜时，必须同时读取 `skills/qingcs-cinematic-storyboard/SKILL.md`，使用故事任务、观众问题、稳定镜头编号、轴线、屏幕方向、人物调度、表演、声音、剪辑、连续性和通过标准，而不是只在提示词里堆“电影感、24mm、推镜”。

## 正文流程

1. **先定读者此刻知道什么。** 每个场景先回答：在哪里、谁在场、正在争什么、失败会失去什么。
2. **比赛状态尽早说清。** 进入一个完整回合后的前300个汉字内，明确：
   - 我方是进攻方还是防守方；
   - C4尚未下、已经下包，还是正在拆除；
   - 当前人数；
   - 双方此刻各自要完成什么。
3. **第一次出现人物时给三个锚点。**
   - 与主角的关系或队内身份；
   - 本回合职责；
   - 一个能被看见的动作、外形或说话习惯。
   不用人物档案式罗列，也不能只报名字。
4. **以场景写关键时刻，以概述跨过无关过程。** 枪战、决定、认人、签字与关系变化用实时场景；移动、等待和手续可压缩。
5. **段落必须有节奏。**
   - 常规段落以2—4句为主；
   - 不连续使用超过3个单句短段；
   - 单句段只留给真正的结果、枪响、认知翻转或章尾；
   - 对话段必须搭配动作、空间或人物反应，避免连续报台词。
6. **人话优先。** 写“瞄着A1出口”，不写“准星压A1”；写“等我们先打前面的人”，不写“等我们转枪”。普通读者读完一句，应能复述谁看见什么、做了什么、为什么。
7. **赛后流程要符合现场逻辑。** 冠军庆祝时，大屏优先显示冠军包装和奖杯镜头；完整回放由队伍回到休息室、复盘室或赛务终端后主动打开。
8. **章节运动：** 承接上一状态 → 压力增加 → 人物选择 → 具体后果 → 下一章接口。
9. **异常必须逐级越界。** 时空异常按“可解释的小异常→可测量错误→现实同步失效→感官/局部物件越界→实体完全重合”推进，至少跨越三种感官；不要从黑屏直接跳成完整新世界。
10. **证据不等于心理接受。** 穿越、身体、国籍、关系或身份发生重大变化时，必须依次写出否认或逃离冲动、主动验证、现实约束、暂时选择；签字、跟随、训练或上场准备只能表示具体行为，不得自动等于内心认同。
11. **旁人只能依据眼前证据反应。** 不知道穿越的人，先把主角异常解释为输图应激、撞伤、低血糖、失忆、开玩笑或逃避复盘；先吐槽或追问，发现主角没有配合后再担心。不同人物按各自职业习惯处理，不能集体瞬间理解作者真相。
12. **主角要逐步确认现实。** 通过空间可触摸性、旁人不一致却自然的反应、过去行动细节、照片/设备/记录和可重复验证，逐步确认“这里是真实的、别人不知道穿越、这个世界认识这具身体”；不要只靠一张名册完成认知。
13. **逐章顺序硬锁。** 只修改当前编号章节；完成正文、分镜、事实、语言和相邻接口自检后立即停止。当前章未通过作者确认前，不得提前改下一章，更不得跳号。

## 分镜转译

每个10—15秒视频块只承担一个主要叙事任务，并固定填写：

- **叙事任务与观众问题：** 本格结束后观众多知道什么；
- **镜头表：** 稳定镜头编号、时长、景别/焦段、动作、镜头动机和调度；
- **表演：** 角色看见什么、先做什么、情绪在哪一拍改变；
- **声音与剪辑：** 台词、环境声、静默、J-cut/L-cut、硬切或匹配切换；
- **连续性与通过标准：** 轴线、视线、屏幕方向、人物位置、服装、设备、比分和物件状态；
- **生成提示：** `SCENE / ACTION / CAMERA / BLOCKING / PERFORMANCE / AUDIO / TRANSITION / NEGATIVE`。

同一章节的角色外形、色调、空间结构和关键道具必须反复使用。图生视频时，提示重点写运动，不重新描述起始图。若15秒无法自然容纳对白和反应，必须在预演中标记拆镜风险，不能通过加速台词假装完成。

## 交付前检查

- 前500字是否已经看见环境、主角、比赛目标和代价？
- 进攻/防守、守包/拆包是否毫无歧义？
- 每名首次登场角色是否有关系、职责和动作锚点？
- 是否存在只有作者懂的术语？
- 是否出现不合现场逻辑的大屏、赛务、设备或动线？
- 是否连续堆叠短句、台词或说明？
- 时空异常是否逐级升级，并在完全穿越前出现现实同步失效和局部物件越界？
- 不知道穿越的角色是否只根据主角的异常表现作出自然判断，而不是替作者理解真相？
- 主角是否通过多个独立证据逐步确认现实，而不是看一张纸就认命？
- 重大身份变化是否区分“客观证据、暂时配合、真正接受”？
- 分镜是否明确轴线、屏幕方向、镜头动机、表演变化和通过标准？
- 是否只处理了当前章节，并在自检后停止，没有提前修改下一章？
- 正文与分镜的比分、人数、地点、结果和下一章接口是否一致？
