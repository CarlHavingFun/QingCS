# QingCS 小说正文与分镜生产

## 核心原则

先让读者进入现场，再让比赛发生。任何专业术语都必须依附于可见动作；任何设定都必须通过人物、物件或后果出现。

## 正文流程

1. **先定读者此刻知道什么。** 每个场景先回答：在哪里、谁在场、正在争什么、失败会失去什么。
2. **比赛状态尽早说清。** 进入一个完整回合后的前300个汉字内，明确：
   - 我方是进攻方还是防守方；
   - C4尚未下、已经下包，还是正在拆除；
   - 当前人数；
   - 双方此刻各自要完成什么。
3. **第一次出现人物时给三个锚点。**
   - 与主角的关系或队内身份；
   - 本回合职责；
   - 一个能被看见的动作、外形或说话习惯。
   不用人物档案式罗列，也不能只报名字。
4. **以场景写关键时刻，以概述跨过无关过程。** 枪战、决定、认人、签字与关系变化用实时场景；移动、等待和手续可压缩。
5. **段落必须有节奏。**
   - 常规段落以2—4句为主；
   - 不连续使用超过3个单句短段；
   - 单句段只留给真正的结果、枪响、认知翻转或章尾；
   - 对话段必须搭配动作、空间或人物反应，避免连续报台词。
6. **人话优先。** 写“瞄着A1出口”，不写“准星压A1”；写“等我们先打前面的人”，不写“等我们转枪”。普通读者读完一句，应能复述谁看见什么、做了什么、为什么。
7. **赛后流程要符合现场逻辑。** 冠军庆祝时，大屏优先显示冠军包装和奖杯镜头；完整回放由队伍回到休息室、复盘室或赛务终端后主动打开。
8. **章节运动：** 承接上一状态 → 压力增加 → 人物选择 → 具体后果 → 下一章接口。

## 分镜转译

每个10—15秒视频块只承担一个主要叙事任务，并固定填写：

- **场景：** 地点、人物、起始状态；
- **动作：** 一个清楚的主要变化；
- **镜头：** 景别、角度、运动；
- **声音：** 台词、环境声、必要音乐；
- **连续性：** 人数、比分、位置、服装、设备和角色身份；
- **生成提示：** 固定角色与视觉锚点，描述本格的动作和镜头，不重复整张静态画面。

同一章节的角色外形、色调、空间结构和关键道具必须反复使用。生成提示尽量控制在约200英文词以内；需要图生视频时，提示重点写运动，不重新描述起始图。

## 交付前检查

- 前500字是否已经看见环境、主角、比赛目标和代价？
- 进攻/防守、守包/拆包是否毫无歧义？
- 每名首次登场角色是否有关系、职责和动作锚点？
- 是否存在只有作者懂的术语？
- 是否出现不合现场逻辑的大屏、赛务、设备或动线？
- 是否连续堆叠短句、台词或说明？
- 正文与分镜的比分、人数、地点、结果和下一章接口是否一致？
