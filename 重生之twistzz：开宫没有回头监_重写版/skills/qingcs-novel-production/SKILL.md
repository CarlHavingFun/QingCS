# QingCS 小说正文与分镜生产

## 核心原则

先让读者进入现场，再让比赛发生。专业术语必须依附于可见动作；设定必须通过人物、物件、程序或后果出现。

使用 `gpt-5.6-sol` 时，先读取 `提示词/GPT-5.6-SOL_章节续写提示词清单.md`，按“一章一契约、一章一审校、一章一提交”执行；继承《差半拍》的叙事机制，不机械复制其比喻和句式。

制作或审查分镜时，再读取 `skills/qingcs-cinematic-storyboard/SKILL.md`。先完成导演分析、节拍图、导演书、人物走位、镜头表和关键帧门槛，再写 MiniMax H3 的15秒生产适配；禁止只堆“电影感、24mm、推镜”。

## 正文流程

1. **先定读者此刻知道什么。** 每个场景先回答：在哪里、谁在场、正在争什么、失败会失去什么。
2. **比赛状态尽早说清。** 进入完整回合后的前300个汉字内，明确阵营、C4状态、当前人数和双方目标。
3. **第一次出现人物给三个锚点。** 与主角的关系/身份、当前职责、一个可见动作或说话习惯；不能只报名字，也不能搬人物档案。
4. **关键时刻用场景，无关过程用概述。** 枪战、选择、认人、核验、签字和关系变化实时展开；移动、等待和手续可压缩。
5. **段落有呼吸。** 常规段落以2—4句为主；不连续堆叠三个以上单句短段；单句段只留给赛果、枪响、认知翻转、真正决定或章尾；对白必须配动作、空间或反应。
6. **人话优先。** 写“瞄着A1出口”，不写“准星压A1”；写“等我们先打前面的人”，不写“等我们转枪”。普通读者读完一句，应能复述谁看见什么、做了什么、为什么。
7. **现场流程符合常识。** 冠军庆祝时大屏服务冠军包装；完整回放由战队回休息室、复盘室或赛务终端后主动打开。
8. **章节运动：** 承接上一章余波 → 压力增加 → 人物选择 → 具体后果 → 下一章接口。
9. **异常逐级越界。** 按“可解释小异常→可测量错误→现实同步失效→感官/局部物件越界→实体完全重合”推进，至少跨越三种感官。
10. **证据不等于心理接受。** 穿越、身体、国籍、队伍归属或关系发生重大变化时，依次写否认/逃离冲动、主动验证、现实约束、暂时选择；签字、拿卡、跟队或训练只能表示具体行为，不能自动等于身份认同。
11. **旁人只能依据眼前证据反应。** 不知道穿越的人，先解释为输图应激、撞伤、低血糖、失忆、开玩笑或逃避复盘；先吐槽或追问，发现主角没有配合后再担心。队长控制现场，入口位先照顾人，主狙核对物证，断后位查时间和记录，赛务员暂停流程，医务值守做伤情与定向检查。
12. **主角通过多份独立证据逐步确认现实。** 空间可触摸性、旁人自然却互相独立的记忆、门禁/时间/赛程、证件照、设备记录和不属于本世界的物件共同更新认知；不能靠一张名册直接得出全部结论。
13. **异常状态下不做强制签认。** 人物定向异常或疑似伤病时，正式责任签字、身份确认和参赛承诺必须暂停；程序可以发临时核验卡或由见证人确认到场，但不能利用异常状态取得同意。
14. **逐章顺序硬锁。** 只修改当前编号章节；完成正文、分镜、事实、语言和相邻接口自检后立即停止。当前章未获作者确认前，不改下一章，更不得跳号。

## 分镜转译

每章固定输出：

1. `分镜/第NN章_导演书与镜头表.md`；
2. `分镜/第NN章_十格分镜.md`。

每个10—15秒生产单元只承担一个主要节拍，但可以包含1—4个短镜头。固定填写：

- **叙事任务与观众问题：** 本格结束后观众多知道什么；
- **镜头表：** 稳定镜号、时长、故事功能、景别/焦段、动作终点和调度；
- **表演：** 角色先看见什么、先做什么、反应在哪一拍改变；
- **声音与剪辑：** 环境底床、对白、静默、J-cut/L-cut、匹配切换；
- **连续性与通过标准：** 轴线、视线、屏幕方向、位置、服装、设备、比分、道具和人物已知信息；
- **关键帧门槛：** 多人站位、身份、手部、道具和空间叠化先通过静帧；
- **H3提示：** `SCENE / ACTION / CAMERA / BLOCKING / PERFORMANCE / AUDIO / TRANSITION / CONTINUITY / NEGATIVE`。

图生视频时只写相对起始关键帧的运动和变化。若15秒无法自然容纳对白和反应，删说明、用证据插入或拆镜，不能加速台词。

## 交付前检查

- 前500字是否看见环境、主角、即时目标和失败代价？
- 进攻/防守、守包/拆包是否毫无歧义？
- 首次人物是否有身份、职责和动作锚点？
- 是否存在普通读者读不懂的术语或生产文档语言？
- 段落是否连续堆叠短句、纯对白或解释？
- 时空异常是否逐级升级？
- 旁人是否只根据可见异常作正常判断，没有替作者知道穿越？
- 主角是否通过多个独立证据逐步确认现实？
- 客观事实、暂时配合、心理接受是否清楚分开？
- 疑似伤病时是否暂停正式签认？
- 分镜是否先做导演书、走位和关键帧，再决定机位与H3提示？
- 每镜是否有故事功能、动作终点和连续性约束？
- 是否只处理当前章节并在自检后停止？
- 正文、导演书、十格分镜、事实哈希和下一章接口是否一致？
