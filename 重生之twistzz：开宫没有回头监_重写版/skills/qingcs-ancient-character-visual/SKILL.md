# QingCS 古风人物定妆与身份连续性

## 核心目标

把人物档案中的职业功能、脸型、体态、发型和制度身份，转换为统一画风但彼此可辨认的古风定妆设定。标准定妆照是**身份母版**，不是战斗海报。

## 必读资料与优先级

发生冲突时按以下顺序裁决：

1. 用户本轮明确要求；
2. `人物档案/<角色>.md` 的身份、年龄、权力和时间线；
3. `人物档案/23_全员外貌性格与古风发式深化.md`；
4. `人物档案/23A_发型参考源与无武器定妆规范.md`；
5. `提示词/古风人物定妆照提示词总表.md`；
6. 历史图片与旧审核提示。

旧文件中的枪械、枪匣、武器箱或持械动作不能覆盖本技能的标准定妆规则。

## 标准画面契约

标准输出固定为：

`4:3 横构图 / 纯白背景 / 左侧约 38% 超大面部特写 / 右侧正面全身 + 严格 90° 侧面全身 + 背面全身 / 同一身份同一服装同一发型 / 脚部完整 / 中性自然站姿 / 双手优先空置`

渲染方向：高端 3D 中国古风幻想概念艺术、UE5 级写实材质、棚拍柔光、精细发丝与布料、克制仙侠感。人物必须是成年原创女性，不做幼态偶像、性感海报、影楼新娘或统一仙女脸。

## 发型参考流程

1. 先锁人物脸型、耳机空间、职业动作和短发／长发事实。
2. 外部参考图必须已在上下文中可见，才可抽取：
   `发际线 / 分缝 / 头顶体积 / 鬓发 / 后脑束点 / 辫髻结构 / 发尾长度 / 饰物尺度`。
3. 外部链接无法打开时，明确标记“待视觉核验”，沿用项目既有发式；禁止猜测链接内容。
4. 只复制发型结构，不复制参考人物的脸、妆、服装、身份、背景、水印或摄影构图。
5. 短发人物保留短发，不为“古风”强行盘髻；所有发型须能戴耳机、伏案、跑动或签字。

## 无武器硬锁

标准定妆照中必须同时满足：

- 双手自然空置；
- 无枪、刀、剑、弓、矛或任何战斗武器；
- 无枪匣、主狙匣、步枪匣、武器箱、刀鞘、箭袋、枪套；
- 无弹匣、弹药袋、手雷、枪带、瞄镜或武器附件；
- 无类似枪管、枪托、刀身的长条硬物、圆柱容器、影子或轮廓；
- 无瞄准、拔刀、背负武器或战斗准备姿势。

职业只能由体态、服制、护腕、签册、卡片、计时器、耳机配件、设备封条和记录物表达。剧情动作图需要武器时，必须另立动作资产任务，不能污染身份母版。

## 工作流

1. **确认资产类型。** 标准定妆、三视图、表情板或穿越前现代档案；不要混成一张图。
2. **读取身份卡。** 提取公开名、年龄段、角色层级、脸型、肩线、身材、主色、职业小物和不可越权项。
3. **建立发型卡。** 用八个发型字段描述结构；检查正、侧、背都能读清。
4. **翻译服制。** 让古风工艺服务职业：能坐进工位、戴耳机、翻页、跑动；不堆黄金和礼服装饰。
5. **写正向提示。** 依次写构图、身份、脸体、发型、服制、允许的小型非武器物件、渲染。
6. **写负面提示。** 首先粘贴完整无武器串，再补角色串位、真人肖像、品牌和画面错误。
7. **QC。** 遮住姓名仍可辨认；三视图不换脸；无武器或武器形物件；短发未被强行古装化。

## 失败修正

- **出现武器：** 删除职业武器词和“战士／狙击手持械”措辞，改为“空手自然站姿”，加入具体禁物与“无武器形影子”。
- **职业不明显：** 增加非武器记录物、肩线、服制结构和姿态，不把武器加回来。
- **发型同质化：** 回到人物专属分缝、束点、鬓发和长度，不靠换发色区分。
- **参考链接不可见：** 停止推断，保留项目母版并标记待核。
- **像真人复刻：** 降低肖像相似要求，只保留宽泛脸型、体态、发型结构和职业气质。

## 完成门槛

交付前逐项确认：

- 22 位角色均有独立提示词；
- 标准照为空手且没有任何武器容器；
- 公开提示不含现实姓名、英文 ID、现实队标或品牌；
- 发型来源可追溯，未查看的链接没有被臆测；
- 本轮若只要求文本更新，不调用任何生图工具。
