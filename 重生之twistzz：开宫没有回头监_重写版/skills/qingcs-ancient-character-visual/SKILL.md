# QingCS 古风人物定妆与身份连续性

## 核心目标

把人物档案中的职业功能、脸型、体态、发型和制度身份，转换为统一画风但彼此可辨认的古风定妆设定。标准定妆照是**身份母版**，不是战斗海报。

## 必读资料与优先级

发生冲突时按以下顺序裁决：

1. 用户本轮明确要求；
2. `提示词/00_人物定妆空手终局硬锁.md`；
3. `人物档案/<角色>.md` 的身份、年龄、权力和时间线；
4. `人物档案/23_全员外貌性格与古风发式深化.md`；
5. `人物档案/23A_发型参考源与无武器定妆规范.md`；
6. `提示词/古风人物定妆照提示词总表.md`；
7. 历史图片与旧审核提示。

旧文件中的枪械、枪匣、武器箱、刀鞘、长管、持械动作，以及任何“手持签册／卡片／扇子”的旧表述，不能覆盖本技能的标准定妆规则。

## 标准画面契约

标准输出固定为：

`4:3 横构图 / 纯白背景 / 左侧约 38% 超大面部特写 / 右侧正面全身 + 严格 90° 侧面全身 + 背面全身 / 同一身份同一服装同一发型 / 脚部完整 / 中性自然站姿 / 双手必须完整可见且完全空置`

渲染方向：高端 3D 中国古风幻想概念艺术、UE5 级写实材质、棚拍柔光、精细发丝与布料、克制仙侠感。人物必须是成年原创女性，不做幼态偶像、性感海报、影楼新娘或统一仙女脸。

## 发型参考流程

1. 先锁人物脸型、耳机空间、职业动作和短发／长发事实。
2. 外部参考图必须已在上下文中可见，才可抽取：
   `发际线 / 分缝 / 头顶体积 / 鬓发 / 后脑束点 / 辫髻结构 / 发尾长度 / 饰物尺度`。
3. 外部链接无法打开时，明确标记“待视觉核验”，沿用项目既有发式；禁止猜测链接内容。
4. 只复制发型结构，不复制参考人物的脸、妆、服装、身份、背景、水印或摄影构图。
5. 短发人物保留短发，不为“古风”强行盘髻；所有发型须能戴耳机、伏案、跑动或签字。

## 空手与无武器硬锁

标准定妆照中必须同时满足：

- 正面、侧面、背面三视图的双臂自然下垂；
- 双手完整可见、五指放松并完全空置；
- 不得手持任何物件，包括签册、卡片、笔、扇子、夹板、计时牌、印章、鼠标和线材；
- 允许的小型工作物件只能固定在衣面、胸牌位或扁平腰侧卡槽，不能遮挡手部；
- 无枪、刀、剑、弓、矛或任何战斗武器；
- 无枪匣、主狙匣、步枪匣、武器箱、刀鞘、箭袋、枪套；
- 无弹匣、弹药袋、手雷、枪带、瞄镜或武器附件；
- 无类似枪管、枪托、刀身的长条硬物、圆柱容器、影子、倒影或轮廓；
- 无瞄准、拔刀、背负武器或战斗准备姿势。

职业只能由体态、服制、护腕、固定式签册标签、固定式卡片、计时器、耳机配件、设备封条和记录标识表达。剧情动作图需要武器时，必须另立动作资产任务，不能污染身份母版。

## 工作流

1. **确认资产类型。** 标准定妆、三视图、表情板或穿越前现代档案；不要混成一张图。
2. **读取身份卡。** 提取公开名、年龄段、角色层级、脸型、肩线、身材、主色、职业小物和不可越权项。
3. **建立发型卡。** 用八个发型字段描述结构；检查正、侧、背都能读清。
4. **翻译服制。** 让古风工艺服务职业：能坐进工位、戴耳机、翻页、跑动；不堆黄金和礼服装饰。
5. **写正向提示。** 依次写构图、身份、脸体、发型、服制、固定式非武器识别物和渲染。
6. **追加终局硬锁。** 把 `提示词/00_人物定妆空手终局硬锁.md` 的正向段放在完整正向提示最后，删除角色段中任何“轻持／手持／一只手拿”语句。
7. **写负面提示。** 先粘贴总表负面提示，再把终局负向硬锁放在最后。
8. **调用生图。** 一次只生成一个角色，不将多个角色放入同一张定妆板。
9. **QC。** 先检查双手和全部轮廓，再检查身份、发式和服装；发现武器或手持物时直接判失败。

## 失败修正

- **出现武器：** 删除职业武器词和“战士／狙击手持械”措辞，强化空手终局段；不要仅靠重复随机生成。
- **出现手持卡片或扇子：** 将物件改为衣面标签或扁平腰侧卡槽，双手恢复自然下垂。
- **职业不明显：** 增加肩线、体态、服制结构、固定式记录标识和表情，不把武器加回来。
- **发型同质化：** 回到人物专属分缝、束点、鬓发和长度，不靠换发色区分。
- **参考链接不可见：** 停止推断，保留项目母版并标记待核。
- **像真人复刻：** 降低肖像相似要求，只保留宽泛脸型、体态、发型结构和职业气质。

## 完成门槛

交付前逐项确认：

- 22 位角色均有独立提示词；
- 三个全身视图的双手均完整可见且完全空置；
- 标准照没有任何武器、武器容器、武器附件或疑似轮廓；
- 公开提示不含现实姓名、英文 ID、现实队标或品牌；
- 发型来源可追溯，未查看的链接没有被臆测；
- 含武器的历史样图只保留版式与材质参考，不作为正式身份母版。

## 比赛持械资产路由

出现以下任一需求时，本技能只负责提供已批准的身份母版字段，随后必须转交 `qingcs-mingqing-match-visual`：

- 游戏内比赛化身；
- 持 AK、AWP、M4、手枪或投掷物；
- 跑动、静步、蹲伏、架枪、开火、换弹、拉栓或投掷动作；
- 明清化游戏地图、武器设定板或观察者 UI；
- 太监解说席、掌镜台或比赛三层关键帧；
- 现实赛台与游戏战场的匹配切换。

路由时只传递：

```text
公开名 / 已批准脸型 / 已批准发型 / 体态与肩线 / 年龄段 / 主色 /
固定式身份锚点 / 不能变化的识别特征 / 身份母版参考图
```

不得把标准定妆的宽松礼服直接复制到比赛化身，也不得把比赛化身的弹匣、枪带、护具或武器写回身份母版。

当用户在同一请求里同时要求“空手三视图”和“持枪比赛动作”时，拆成两个独立资产：先完成空手身份母版并通过 QC，再由 `qingcs-mingqing-match-visual` 创建比赛化身。两个资产不能合并成一张板。
