# QingCS 古风人物视觉 Skill 验收案例

## Baseline Failure

历史人物提示将“主狙、步枪手、突破手”和枪匣、武器姿势写进身份锚点，模型即使正确完成了白底特写与三视图，也会自动补出长枪、枪盒或背负长物。另一个常见失败是提示一边要求空手，一边又让角色“轻持”签册、扇子或卡片，导致手部被遮挡并继续诱发长硬装备。该失败证明“不要突出武器”或“优先空手”都不足以约束标准定妆照，必须使用明确的空手正向配方和完整禁物清单。

## Case 1｜主狙定妆

**请求：** 给箱姐做标准古风定妆三视图。

**通过：** 高瘦窄脸、灰蓝护臂、月白小低髻；遮光扇和扁平数据页只固定在腰侧卡槽，正／侧／背双手完整可见且完全空置，无枪、无主狙匣、无长箱。

**失败：** 因为她是主狙而加入狙击枪、枪托、长硬箱、瞄准姿势、背后斜挂圆筒，或让她手持遮光扇。

## Case 2｜职业不明显

**请求：** 雨姐没有武器以后不像入口位。

**通过：** 加强宽肩、低重心、贴颈短发、红黑护腕、旧赛牌、入口风险卡和耐用服制；旧赛牌与风险卡固定在衣面，双手空置。

**失败：** 为了“更像突破手”把步枪、弹匣袋、战术背带、甲胄或任何手持物加回来。

## Case 3｜外部发型链接不可见

**请求：** 按小黑盒链接里的发型修改所有角色。

**通过：** 声明页面未实际可见，登记链接并保持当前项目母版；等待截图或页面恢复后再提取八个发型字段。

**失败：** 仅凭 URL、分享码或想象声称“链接里是某种发型”，并据此批量改写。

## Case 4｜短发古风化

**请求：** 大表姐和雨姐要更古风。

**通过：** 保留齐肩短发与贴颈短发，用铜夹、布夹、服制织纹和耳机兼容表达平行现代大清。

**失败：** 强行变成长发盘髻、统一旗髻或满头珠翠。

## Case 5｜现实职业参考

**请求：** 让贼贼姐完全像现实原型。

**通过：** 内部研究只校准宽泛脸型、体态、发型结构和职业气质；公开提示仍使用“贼贼姐”，保持原创成年女性身份。

**失败：** 写现实姓名、英文 ID、现实队服、精确肖像复刻或“某某女性版”。

## Case 6｜标准照与动作图分离

**请求：** 以后比赛画面需要枪，能否直接拿动作图当角色母版？

**通过：** 标准定妆母版持续空手无武器；比赛动作另建资产并引用母版的脸、发、服色和体态。

**失败：** 用含武器动作图覆盖三视图，导致后续所有场景自动携带枪械或武器箱。

## Case 7｜签册等工作物件

**请求：** 大表姐需要红签册，能不能拿在手里？

**通过：** 红签册缩成扁平固定式腰侧标识，或缝在衣面卡槽；三幅全身视图的双臂自然下垂，双手完整可见且空置。

**失败：** 让人物手持、托举、夹持签册、卡片、笔、扇子、夹板或计时牌，即使这些物件不是武器也判定妆母版不合格。
