## 核心设定

主角是现代男性职业选手，意识落入平行现代大清的女队首发身体。普通男性可以玩CS，但绝大多数人无法通过国力赛天衡终端的神经稳态认证；这是一条虚构技术与历史制度造成的限制，不是现实性别能力结论。

故事主线是：适应新身体、赢得五席信任、卷入慈宁宫与御前改良派的争斗，最终代表大清赢下国力赛世界冠军。
