## 核心设定

主角是现代男性职业选手，意识进入平行现代大清的一名成年女队首发身体。普通男性可以玩普通 CS，但绝大多数人无法通过国力赛天衡终端的神经稳态认证；这是架空技术和制度限制，不是现实性别能力结论。

故事主线是：验证平行现实与陌生身体，重新赢得五席信任，处理席位、合同、直播舆论和宫廷制度冲突，最终代表大清参加国力赛。电脑、AI 和天衡终端只能留下记录或评估材料，不能自动授予资格、改比分、选首发或替人承担责任。
