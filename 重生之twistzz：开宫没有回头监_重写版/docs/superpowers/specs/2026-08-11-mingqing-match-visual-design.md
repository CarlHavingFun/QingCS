# 明清化比赛战场、武器与太监解说设计

## 1. 目标

把穿越后的 QingCS 正式比赛建立为独立、可持续生产的视觉系统：保留 CS 读者熟悉的地图战术骨架、枪械功能、经济与回合逻辑，同时把游戏内地图、战斗化身、常用枪械、投掷物、观战界面和直播解说统一重构为平行大清的明清火器工业风。

本设计采用“战术骨架保留、视觉重新设计”。它不是给现成地图换一层古风贴图，也不是把现代枪械替换成火绳枪、法器或弓弩。

## 2. 三层比赛画面

### 2.1 现实赛台层

现实赛台继续使用宫廷电竞生产系统：明清木构、朱墙、铜灯、漆木铜边硬件、显示器、键鼠、耳机、服务器与线缆并存。该层负责手部操作、队内语音、暂停、队友反应、现场秩序和赛后后果。

### 2.2 游戏战场层

镜头可从显示器进入游戏战场，以角色战斗化身直接表现跑动、架枪、投掷、交叉火力、补枪、残局与回防。战斗化身复用人物身份母版的脸型、发型、体态和主色，但必须换成能跑动、蹲伏、戴耳机、装载弹匣和投掷道具的短袍战术服制。

标准人物定妆仍然严格空手。任何枪械、弹匣、手雷、枪带和战斗动作只能进入单独的比赛化身或剧情动作资产，不能污染身份母版。

### 2.3 观察者信息层

观察者信息层同时承担小地图、比分、经济、击杀栏、回放、战术解释、直播切镜和现场解说。它不是选手能看到的外挂界面，也不能把隐藏信息传回队内。

该层正式加入太监解说体系：

- 唱局太监负责实时播报交火、人数、时间、残局和情绪节奏；
- 评策太监负责解释经济、道具、站位、轮转、补枪链和下一轮代价；
- 掌镜太监属于幕后观察员，控制第一人称、自由镜头、俯视图和回放切换；
- 洛遥音继续承担观议司的直播制作、公共口径、采访与赛后剪辑，不被太监解说取代。

太监身份是平行大清的职业制度身份，不是尖嗓、娘化、身体笑话或低俗丑角。解说以现代中国 CS 口语为主，宫廷词只负责节奏和世界观识别。

## 3. 地图重构原则

每张地图必须保留可辨认的 5V5 战术关系：A/B 点、中路、长短道、出生区、回防路线、烟闪投掷空间、交叉火力、高低差和可控视线。不得一比一复制现实游戏截图或像素级几何。

首批图池：

- 朔漠关：边关、瓮城、双门、烽燧与军械台；
- 丹阙城：王城外廓、商市、内院、马厩与高台；
- 烟雨府：江南府城、窄巷、牌坊、粮道、钟楼与祠堂院落；
- 天工局：机造总局、火器工坊、上下层厂房与地下机库；
- 玄陵：皇陵外城、祭台、石兽道与地下甬道；
- 漕铁驿：皇家漕运总站、铁轨、货栈、龙门吊与军需仓；
- 御河桥：御河、水闸、桥关、园林外墙与地下水道；
- 凌霄台：高层营造工地、木石脚手架、吊装平台与未完工宫阙。

## 4. 枪械重构原则

比赛语音、正文战术和 UI 继续使用 AK、AWP、M4、Deagle、USP 等通用名称，保证节奏和玩家识别。视觉资产另设原创式样名。

功能结构必须保持：枪管、机匣、弹匣、瞄具、枪托、消音器、栓动结构、换弹路径和握持点不得被装饰破坏。明清化只改变材料、纹样、包角、枪带、刻度、磨损和制造语言。

首批式样：

- AK-47／赤漆云雷式；
- AWP／霜纹望山式；
- M4A1-S／玄甲静锋式；
- M4A4／镇门连发式；
- Desert Eagle／金翎重铳式；
- USP-S／夜巡静铳式；
- Glock-18／轻骑连铳式；
- P250／巡检短铳式；
- Galil AR／边军连珠式；
- FAMAS／羽林折锋式；
- MP9／宫门疾铳式；
- MAC-10／飞檐短铳式；
- SSG 08／游隼轻狙式；
- C4／震城火药匣。

烟雾弹、闪光弹、高爆手雷、燃烧瓶与拆弹器分别采用云烟罐、照夜闪雷、破阵震雷、赤焰瓶和拆械匣的视觉式样，但正文仍优先说烟、闪、雷、火与钳子。

## 5. 太监解说语言与权限

### 5.1 语言比例

- 约 70% 为中国 CS 玩家能直接理解的现代口语；
- 约 20% 为比赛制度词、地图词和数据解释；
- 不超过 10% 为宫廷节奏词、报幕词和固定口彩。

不得把每句话都写成文言文，也不得用“奉旨爆头”等单一梗反复消费设定。

### 5.2 信息边界

解说只能使用公开直播流、观察者画面、已公开赛务数据和赛后回放。队内语音只有赛事规则允许公开时才能在延时回放中出现。太监解说不能读取人物内心、未公开合同、隐藏战术或未来结果。

### 5.3 戏剧功能

太监解说不只负责热闹，还应完成：

1. 为普通读者解释回合；
2. 为老玩家保留专业判断；
3. 制造观众版本与队内事实的偏差；
4. 通过切镜和复述影响舆论，但不能改写原始证据；
5. 在高光后把镜头送回现实赛台，显示真正承担后果的人。

## 6. 漫剧镜头语法

穿越后的第一场正式比赛完整建立三层语法：现实赛台全景 → 回合开始音 → 屏幕/门洞匹配切换 → 明清化游戏战场 → 武器与战斗化身识别 → 战术全景 → 交火 → 太监解说与观察者信息 → 现实手部或队友反应 → 回放解释。

后续比赛只需保留地图建立镜头、武器/角色识别镜头、核心战术镜头和现实反应镜头，不重复展示完整进入过程。

第一章现代现实比赛维持现代 CS 视觉。穿越只允许使用一次短暂预告式匹配切换，例如现代双门叠为朱漆瓮城双门、现代 AK 的黑色护木叠为赤漆云雷式；完整体系留到平行世界第一场比赛揭示。

## 8. 验收标准

- 看到静帧时能同时认出 CS 战术用途和 QingCS 明清工业身份；
- 地图不是纯古风空景，枪械不是古代火铳或仙侠法器；
- 现实赛台、游戏战场和观察者信息层能在镜头中清楚区分；
- 太监解说有专业分工、信息权限和人物尊严，不靠嗓音与身体梗；
- 角色身份母版仍然空手，比赛化身才允许持械；
- 精确比分、击杀栏、地图标签和赛务文字留后期合成安全区；
- 不出现现实战队 LOGO、赞助商、真人肖像复刻、随机文字或伪汉字；
- 所有引用路径存在，Skill 之间的路由无循环或冲突。
