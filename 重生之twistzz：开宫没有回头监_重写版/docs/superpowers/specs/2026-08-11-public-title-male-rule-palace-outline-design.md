# QingCS公开书名、男性禁限与宫斗国战总纲设计

## 目标

让作品的公开定位一眼可懂，同时补上男性无法进入最高CS国力赛的可信虚构原因，并把未来44章统一成电竞成长、国家对抗、宫廷权谋和身份悬疑四线合一的结构。

## 决策

- 书名采用《穿越大清打CS，我成了女队首发》；不使用“穿越回大清”，避免误导为历史穿越。
- 男性可以玩普通CS，但多数无法通过女性样本校准的天衡终端认证；禁限由技术、事故和既得利益共同形成。
- 主角的男性意识借认证女性身体通过硬件检查，不获得额外枪法。
- 宫斗围绕可见资源展开：赛籍、设备、预算、密折、舆论、合同和回放。
- 第一篇章以赢得世界冠军和启动逐人认证改革收束，原贼贼姐去向进入后续篇章。

## 边界

- 虚构设定不得冒充现实性别科学。
- 皇帝不得变成外挂或替赛务决定首发。
- 旧制派必须有安全事故和职业历史依据，不写成纯脸谱反派。
- 新总纲不等于批量改写后续正文。
