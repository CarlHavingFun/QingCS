# QingCS 全员古风空手定妆与穿越前档案设计

- **日期：** 2026-08-11
- **分支：** `agent/ch01-half-beat-rewrite`
- **状态：** 用户已批准
- **目标：** 把已通过的古风 3D 角色设定板风格扩展到 22 位核心人物，并建立主角及开场所需人物的穿越前现代职业档案。

## 1. 交付范围

1. 新增可复用 Skill：`qingcs-ancient-character-visual`。
2. 新增 22 位角色的完整古风定妆提示词。
3. 新增发型语言与外部参考使用规则。
4. 新增固定构图、身份连续性和空手硬锁。
5. 新增穿越前现代职业档案：主角、开场四名队友，以及需要时调用的教练。
6. 更新旧三视图入口，避免旧提示词继续诱发职业器械。

## 2. 视觉设计

固定输出为 4:3 白底角色设定板：

- 左侧约 38% 为超大面部近景；
- 右侧依次为全身正视、严格 90° 侧视和后视；
- 同一脸、年龄、身材、发式、服装和饰物位置；
- 三视图同尺度，完整到脚；
- UE5 级超写实古风 3D 棚拍质感；
- 平行现代大清职业服制，不做纯仙侠、后宫或 cosplay。

职业差异主要来自脸型、肩线、体态、发型、配色、服装剪裁、表情和非攻击性工作物件。

## 3. 空手硬锁

人物标准定妆照必须双手完整可见且空置。禁止持握、背负、腰挂、倚靠或悬挂任何攻击性器物，也禁止长管、长硬盒、鞘状物和疑似攻击性轮廓。

允许使用复盘卡、签册、计时牌、印匣、耳机部件、鼠标线、软质文件包等小型工作物件，但不得放入手中遮挡手部。

旧图只保留布局、材质和综合色调参考；只要不符合空手规则，就不能升级为正式身份锚点。

## 4. 发型设计

发型以 `人物档案/23_全员外貌性格与古风发式深化.md` 为项目权威。用户提供的小黑盒页面作为可选情绪板：

- 可访问时只提取分缝、刘海、长度、层次、束发高度、发尾和蓬松度；
- 不复制真人脸、队服和画面环境；
- 页面无法访问时不得猜测内容；
- 外部参考不能覆盖耳机兼容、伏案、跑动、年龄感和国别服制。

每个发型提示固定写成：分缝 → 贴鬓/露耳 → 后脑结构 → 固定件 → 碎发 → 耳机/运动约束。

## 5. Prompt 架构

Prompt 由四层拼装：

1. 共用构图与渲染契约；
2. 角色身份层；
3. 全局负向提示；
4. 角色附加负向提示。

完整角色库只有一份权威来源：`角色三视图/全员古风空手定妆提示词.md`。Skill 只负责读取、拼装、生成和 QC，不复制 22 份提示，避免漂移。

## 6. 穿越前档案

档案是内部核稿文件，不进入公开提示词。时间锁定为现实五人完整同队窗口 2022-01-03 至 2023-12-01，用于校准：

- 主角的二号位、补枪、晚段判断和事实先行；
- 指挥位的默认、经济、最终口令和责任；
- 远点主位的长线、关键首发信息和残局；
- 首接触老将的开局空间、锚点和大赛冲击；
- 游走位的反默认、晚段信息和残局收束；
- 教练的后台连续性、训练和复盘支持。

北港 Major、比分、穿越事故和现代队内对白仍是平行原创，不得伪装成现实比赛记录。

## 7. 校验

自动校验脚本检查：

- 22 个角色章节齐全；
- 公开提示不泄露现实 ID、现实队名；
- 每个正向提示包含空手硬锁；
- 正向提示不包含容易诱发器械的关键词；
- 全局负向提示存在。

人工 QC 再检查身份一致、发式一致、同尺度、手脚完整、无攻击性器物和无现实标识。

## 8. 不在本次范围

- 不批量生成 22 张正式图片；
- 不删除既有图片；
- 不修改正式章节剧情；
- 不把现实人物私生活、未经证实心理或真人肖像写入公开层；
- 不改变角色首发、赛籍、合同或关系弧线。
