# QingCS 古风人物定妆提示词与穿越前档案实施计划

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development or superpowers:executing-plans to implement this plan task-by-task.

**Goal:** 为 22 位核心人物建立统一、可复用、无武器的古风定妆照提示词，并补充主角及必要旧世界人物的穿越前内部档案。

**Architecture:** 新建一个专门负责人物视觉转换的 Skill，以“人物档案 → 发型参考 → 古风服制 → 定妆照构图 → 负面约束 → QC”为唯一流程。角色专属提示词集中存放在权威总表中；旧世界档案独立放在内部制作层，严格区分“现实研究样本”“平行角色”和“真正穿越者”。

**Tech Stack:** Markdown、Agent Skill `SKILL.md`、GitHub 文档资产；本次不调用 `image_gen`、img2 或任何生图工具。

## Global Constraints

- 本次只更新提示词、Skill、人物档案和目录说明；不得生成、上传或修改图片。
- 标准定妆照固定为 4:3 横构图、纯白背景、左侧超大面部特写，右侧依次为正面全身、严格 90° 侧面全身、背面全身。
- 定妆照和三视图中禁止出现任何武器、武器箱、枪套、弹药、刀鞘、箭袋、武器背带或武器形状影子。
- 只允许非武器职业道具，例如复盘卡、签册、计时器、印章、文件夹、耳机配件、鼠标线、设备封条。
- 公开图像提示只使用中文公开名；现实职业 ID 只允许出现在明确标注“内部制作层”的映射或旧世界档案中。
- 发型首先服从脸型、职业动作、耳机兼容和人物差异；短发人物不得为了“古风”被强行盘髻。
- 用户提供的小黑盒链接作为发型视觉参考源；无法实际查看参考图时，只登记链接和核验闸门，不得臆测其内容。
