# 人物档案目录说明

本目录存放新版 **22 位核心人物档案**、总表、外貌发式补充、外部发型参考规范和旧世界内部档案。

## 人物分层

- 第 1—24 章大清战队首发五席固定为贼贼姐、大表姐、箱姐、雨姐、老六姐。
- 米教姐、戚照霜、郗雪篁、陶令仪、霍昭宁、燕归迟分别按登记一教、执行教练、队务、分析师、注册替补和非报名训练候选调用。
- 稳火姐是前史前教练，幕后姐是霜旌队教练兼队务领队。
- 公开层只调用中文化名字；现实职业 ID 只允许在 `24_主角与必要角色穿越前档案_内部制作层.md`、`../设定/03_中文化职业原型映射.md` 等明确内部研究文件中出现。

人物差异化必须同时落到脸型、发型、肩线、站姿、服制、打法、说话节奏、复盘动作和非武器职业道具。教练档案还必须写明可做事项、不可越过的五席／IGL／赛务边界和安全梗来源。

## 视觉调用入口

- `23_全员外貌性格与古风发式深化.md`：22 人的基础脸体、发式、性格和表演锚点。
- `23A_发型参考源与无武器定妆规范.md`：小黑盒外部发型参考源、可见性门槛、发型拆解字段和标准定妆禁物。
- `24_主角与必要角色穿越前档案_内部制作层.md`：主角、旧世界四名队友和按需教练锚点。
- `../提示词/古风人物定妆照提示词总表.md`：22 位标准定妆照的权威可调用提示。
- `../skills/qingcs-ancient-character-visual/SKILL.md`：人物视觉生产与 QC 流程。

标准人物定妆照与身份三视图一律空手无武器；不得出现武器箱、枪匣、枪套、弹药袋、枪带或武器形影子。旧图和旧审计文件中的武器只能视为历史资产，不构成新母版规则。

## 视角与称呼

档案与分镜可使用“贼贼姐”作为制作标签，正式章节正文必须由她以第一人称“我”叙事。称呼按关系和场景使用：亲近／照顾／老队友才用“小贼贼”，有共同回合的赛场互呛或复盘玩笑才用“狗贼”，外队／后辈／直播才用“贼姐姐”，“总监”只属于观众／直播公共层且不是职位。
