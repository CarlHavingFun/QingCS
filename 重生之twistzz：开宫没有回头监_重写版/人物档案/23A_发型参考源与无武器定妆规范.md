## 2. 发型拆解字段

每位人物的发型提示至少写清以下八项：

| 字段 | 要回答的问题 |
|---|---|
| 发际线 | 额头露出多少，是否有美人尖或自然碎发 |
| 分缝 | 中分、偏分、斜分或无明显分缝 |
| 头顶体积 | 贴头、自然蓬松或明确高束 |
| 鬓发 | 贴鬓、耳下碎发、单侧碎发或完全收净 |
| 后脑束点 | 高束、后颈、低髻、偏心髻或短发无束点 |
| 主体结构 | 直发、层次短发、长辫、盘髻、双环髻、旗髻 |
| 发尾长度 | 贴颈、齐肩、肩下、腰长或收进衣领 |
| 饰物尺度 | 无饰物、短簪、窄扁方、布带、小扣或克制钿子 |

禁止用“古风长发美女”“仙气发型”“精致盘发”代替结构描述。

## 3. 古风转换边界

- 发型必须先适配耳机、耳返、伏案、签字、跑动和设备维护。
- 短发人物保留短发；现代化平行大清允许贴颈短发和齐肩短发。
- 日常训练优先低髻、短簪、束辫和短发；公开赛务可少量增加扁方、珠花；正式国礼才使用克制钿子或礼髻。
- 禁止全员大拉翅、巨大戏曲头面、满头珠翠、所有长发都飘动、发饰穿过耳机。
- 参考图中若有染发、烫卷或现代层次，只翻译其轮廓、分缝和体积，不机械复制色号或造型产品效果。
- 不复制参考人物的脸、妆、耳饰、衣服、身份、背景、摄影棚和水印。

## 4. 标准定妆照无武器硬规则

“定妆照”“标准设定板”“身份三视图”“角色母版”四类资产统一执行：

- 默认双手自然空置；
- 不出现枪、步枪、手枪、狙击枪、刀、剑、匕首、矛、弓箭；
- 不出现主狙匣、步枪匣、武器箱、长枪盒、刀鞘、剑鞘、箭袋、枪套；
- 不出现弹匣、弹药袋、手雷、枪带、瞄镜、枪托、枪管或武器附件；
- 不出现武器形长箱、硬壳圆筒、背后斜挂长条物、武器影子或持械手势；
- 不以“女将”“刺客”“狙击手”等词诱导模型自动补武器。

允许出现的职业物件应短小、扁平、明确非武器：

- 签册、复盘卡、合同夹、赛籍册、文件板；
- 计时器、标记笔、印章、封条、薄数据夹；
- 鼠标、短段柔性线、耳机配件、耳返、护腕；
- 小型资源袋，但外形不得像弹药袋或武器包。

## 5. 正负提示模板

### 正向尾句

`标准人物定妆照，中性自然站姿，双手自然空置，空手，无武器，无武器容器，无武器附件；职业身份只通过脸型、肩线、发型、服制、配色和小型非武器记录物表达。`

### 负面硬串

`枪，步枪，手枪，狙击枪，刀，剑，匕首，长矛，弓箭，主狙匣，步枪匣，武器箱，枪盒，刀鞘，剑鞘，箭袋，枪套，弹匣，弹药袋，手雷，枪带，瞄镜，枪托，枪管，武器附件，长条硬质装备，硬壳圆筒，背负长物，武器轮廓，武器影子，持械姿势，瞄准姿势，战斗动作。`

## 6. 定妆母版与动作资产分离

- 定妆母版永远无武器。
- 比赛、冲点、架枪、保枪等剧情动作属于独立动作资产。
- 动作资产不得覆盖定妆母版，不得被回填到角色标准三视图。
- 后续代理收到“参考旧三视图”时，只继承脸、发、体态、服色和材质，不继承旧图中的武器或武器容器。

- 哪些人物发生变化；
- 是否复核正面、侧面、背面；
- 是否仍满足耳机与工作动作。
