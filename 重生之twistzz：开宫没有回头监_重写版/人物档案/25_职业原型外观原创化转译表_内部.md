# 职业原型外观原创化转译表（内部）

> **用途：** 本文件只供项目内部研究、人物设计、分镜连续性与图像提示审校。现实职业 ID 只允许留在本文件与`../设定/03_中文化职业原型映射.md`等明确标注的内部文件中；公开人物档案、正文、分镜、画面文字和图像提示只使用中文公开角色名。
>
> **验收句：** 熟悉职业比赛的人可以感觉到角色继承了对应位置、体态和赛场气质，但不能仅凭脸确认她是哪位现实选手。

## 一、总转译规则

### 1. 允许继承的职业层

只能从公开比赛和公开职业资料中提取概括性信息：

- 大致年龄感、职业阶段感和老将／成长中选手的状态；
- 高矮、肩宽、体型大类、坐姿、站姿和赛场重心；
- 脸型大类别，不提取精确五官比例；
- 发色、头发长短和整齐／蓬松等大方向，不复制具体发际线与标志性造型；
- 比赛时的专注程度、表情强度、动作节奏和压力下的职业习惯；
- 与职业位置相符的鼠标、键盘、耳机、显示器距离和身体语言。

这些内容只能回答“她像什么位置的职业选手”，不能回答“她长得像谁”。

### 2. 一律禁止复制的身份层

- 可被准确识别的现实选手面孔；
- 精确眼距、眉眼组合、鼻唇比例、下颌轮廓等面部识别特征；
- 标志性文身、伤疤、痣、首饰、牙齿特征或其他私人身体标记；
- 现实队服、队标、赞助商、品牌、签名姿势、庆祝动作和照片构图；
- 现实姓名、真实 ID、真人私生活、未经证实的性格或心理推断；
- 换脸、照片描摹、真人 LoRA 式复刻、指定相似度或“长得一模一样”的提示。

### 3. 五项身份锚点改写硬锁

每名有现实职业原型的角色，进入公开档案或视觉提示前，至少主动改变以下五项；本表实际为每名角色改变八项以上：

`眼型 / 眉骨与眉形 / 鼻梁与鼻尖 / 嘴唇形状 / 下颌与下巴 / 发际线与具体发式 / 肤色冷暖 / 身体比例 / 面部标记 / 配饰 / 服装结构 / 站姿重心`

职业动作可以连续，肖像身份必须断开。相同位置也不得共享同一张“电竞脸”。

### 4. 公开提示统一尾句

所有人物图像提示都必须包含以下原句：

> 原创虚构成年女性职业选手，不是任何现实人物的肖像，不复刻真人五官，不使用现实队服、队标或赞助标识。

标准定妆照还必须继续执行空手、无武器、三视图同一身份与耳机兼容发式等既有硬锁。

## 二、大清开局五席

### 01｜贼贼姐

- **内部现实原型：** `Twistzz`。
- **只继承的职业信号：** 顶级步枪手的成熟年龄感；中等体量、平肩、重心略向前；二号位跟枪、补枪与残局时视线稳定；操作前会先把鼠标线和握距理顺。
- **公开原创轮廓：** 中等身高，窄椭圆脸，颧骨低而清楚；眼神不是锐利型，专注感来自长时间盯住同一条证据；偏分贴鬓、小型偏心低髻、歪银簪和卷起的右袖形成大清职业锚点。
- **主动改变的身份锚点：** ①杏核偏长眼改为外眼角轻平的窄圆眼；②眉骨压低并改成平缓短眉；③鼻梁改为中低直梁、鼻尖略圆；④上唇薄、下唇更饱满且唇峰不明显；⑤下颌收窄、下巴短而圆；⑥发际线改成偏低圆弧并加入右鬓工作碎发；⑦肤色设为中性偏暖；⑧肩宽与手掌比例按成年女性重新设计；⑨右颊加入极淡、非现实来源的浅色小雀斑带；⑩改用歪银簪、黑色转接头、暗红窄袖职业袍，不使用任何现实服装与首饰。
- **不可漂移：** 不用真人照片定脸；不追求某一现实笑容、发型或侧脸；不得用英文 ID 作提示。

### 02｜大表姐

- **内部现实原型：** `karrigan`。
- **只继承的职业信号：** 年长资深 IGL 的职业阶段；偏丰而稳定的体态、厚实肩颈、坐下后自然成为沟通中心；说话时先扫全桌再落到下一步；耳机按键和队长牌使用频繁。
- **公开原创轮廓：** 中高个、方下颌、短发直肩；脸部不以强势五官制造权威，而以稳定坐姿、红签册和可翻队长牌建立空间中心。
- **主动改变的身份锚点：** ①眼型改为内双、眼尾轻下收；②眉骨降低，眉形改成短而宽的缓弧；③鼻梁较宽、鼻尖上翘幅度很小；④嘴唇改成上下一致的中等厚度，嘴角自然平；⑤方下颌保留大类但下巴改为圆钝；⑥发际线改成高低不对称的自然短发线，一侧铜夹固定；⑦肤色设为暖橄榄调；⑧身材改为中高个、偏丰、肩颈厚实的成年女性比例；⑨左眉尾设置一处原创的浅断眉，不对应现实标记；⑩深绛结构化指挥袍、黑红耳机与铜扣替代现实队服、队标和配饰。
- **不可漂移：** 不复制现实选手的笑脸、庆祝动作、手势或队服轮廓；不把“老将”画成男性面孔换发型。

### 03｜箱姐

- **内部现实原型：** `broky`。
- **只继承的职业信号：** 年轻至成熟主狙的职业阶段；高瘦、长手臂、坐姿收肩；进入长线瞄准后肩背拉直；表情强度低、确认画面后才动作。
- **公开原创轮廓：** 高瘦窄脸、眼窝略深、耳下碎发收进极小低髻；灰蓝护臂、月白短簪与遮光结构表现主狙职责。
- **主动改变的身份锚点：** ①眼型改为细长内收、外眼角不下垂；②眉骨变平，眉尾明显缩短；③鼻梁改为窄直、中段略低，鼻尖圆小；④嘴唇改为薄上唇与圆润下唇；⑤下颌线拉长、下巴改成窄圆；⑥发际线设为自然 M 形但用耳下碎发打散，低髻位置固定在后颈；⑦肤色设为冷中性；⑧肩更窄、手臂更长、躯干比例更短；⑨左眼下加入一枚极淡原创小痣但禁止成为标志性特写；⑩月白短簪、灰蓝护臂和无品牌设备封条替代现实配饰与队服。
- **不可漂移：** 不能依靠现实脸、现实发色或现实赛场照片认人；主狙身份不靠持枪定妆。

### 04｜雨姐

- **内部现实原型：** `rain`。
- **只继承的职业信号：** 长期老将、首接触与锚点的阶段感；宽肩、低重心、前臂结实；比赛时动作直接，压力下反而安静；入口前会确认撤退空间。
- **公开原创轮廓：** 宽肩方脸、贴颈短发、红黑布夹和护腕；笑时整张脸放松，真正担心时笑意迅速消失。
- **主动改变的身份锚点：** ①眼型改为宽内双与圆钝外眼角；②眉骨减弱，眉形改成较厚的平直眉；③鼻梁改为短直、鼻翼稍宽；④唇峰降低、嘴唇整体更厚；⑤方下颌保留大类但下巴改为短方圆；⑥发际线改为圆弧低发际并采用贴颈短发；⑦肤色设为暖棕调；⑧成年女性宽肩、短躯干、低重心比例重做；⑨右侧额发用红黑布夹而非现实首饰；⑩朱红黑耐磨短袍、旧赛牌和护腕替代现实队服与私人标记。
- **不可漂移：** 不复制现实文身、胡须轮廓、发际特征或庆祝动作；不把宽肩直接等同于男性化肖像。

### 05｜老六姐

- **内部现实原型：** `ropz`。
- **只继承的职业信号：** 游走、晚段信息和残局判断的成熟阶段；高瘦、肩线后收、站位常留观察角度；发言比第一波冲突晚半拍；鼠标动作小而克制。
- **公开原创轮廓：** 高瘦长脸、略高颧骨、高束深发折回后颈；墨青袖扣、静音计时器和青色回放签承载低可见度职责。
- **主动改变的身份锚点：** ①眼型改为内窄外宽的长圆眼；②眉骨提高但眉峰后移；③鼻梁改为中等宽度、鼻尖微垂；④嘴唇改为薄唇、下唇中央略满；⑤长脸保留大类但下颌角更柔、下巴更长圆；⑥发际线改为高圆弧并设计高束长辫折回盘扣；⑦肤色设为冷黄中性；⑧肩线后收、腿长比例提高但避免真人体型复刻；⑨左颊设置一条极浅原创晒斑，不作标志性伤疤；⑩墨青哑光长层服、青色回放签和无品牌低可见度鼠标替代现实视觉元素。
- **不可漂移：** 不用现实侧脸、发型、队服或鼠标姿态复刻；“老六”只来自职责，不来自对真人性格的推断。
