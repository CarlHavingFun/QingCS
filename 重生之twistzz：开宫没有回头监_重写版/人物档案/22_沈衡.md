# 沈衡｜皇帝档案

> 本档案是公开层生产约束。沈衡是原创成年女性皇帝；正文称“皇帝”或“陛下”，不以“女帝”作标签。她的权力必须通过文件、预算、任免、会签和公开责任落地，不能变成比赛外挂或神秘光环。

## 1. 身份与阶段

| 字段 | 固定内容 |
|---|---|
| 姓名 | 沈衡 |
| 身份 | 大清帝国国家皇帝，电竞国力工程的最高政策与公开责任人 |
| 年龄 | 成年女性，建议 38 岁；年龄不是权力来源之外的暧昧暗示 |
| 正文称呼 | “皇帝”或“陛下”；档案、章纲可写“沈衡” |
| 核心目标 | 让电竞国力工程能承受胜利与失败，并让国家为后果留下责任链 |
| 核心恐惧 | 明星个人合法性压过制度；天工信仰失控后无人为国家后果负责 |
| 第一印象 | 她坐在正在工作的桌前，面对预算案、赛约、回放和待签责任令 |

## 2. 外在、服制与镜头锚点

- 形体：成年女性，肩线平稳、重心稳定、动作节制；用落座、翻页、圈预算、递回执和停笔表现力量，不用夸张身材或仰望构图。
- 服制：深绛或黛青的窄袖议事常服，袖口能在桌面签批和翻回放时保持利落；少量玉白内衬与铜制印章/笔具作识别点。工作场景不以冠冕、宝座或华丽礼服抢主体。
- 道具：预算总盘、分项预算栏、外交赛约、设备状态单、回放终端/回放墙、责任令、会签栏、协会回执、门禁牌、朱印和异议纸签。
- 工作空间：公开名为“御前听报室”，内部值房称“国策值房”；两者是同一物理房间，不得拆成两个无动线场景。房内必须有工作桌、文件、屏幕、回放、预算栏、赛约、签批和异议处理位置。
- 镜位：优先桌面平视、侧后方肩线、手与材料的近景和门槛外望；人物与材料同框，避免空宝座、封建戏台、光束降旨和海报式神像。

## 3. 说话方式与可核实判断

- 句子短、问题具体，先问“预算从哪里来、谁签字、谁复核、失败由谁解释”，再决定是否批条件或追责任。
- 她不靠宏大台词压过别人；每次发言都应指向一页预算、一项赛约、一份回放或一张回执。
- 她能听报、看回放、圈预算、追签字、改条件、听异议、签责任令，也会在公开场合承认朝廷失误。
- 致命盲点：过信档案和可审计流程，低估队内临场信任在半秒内改变决策；合规的设备和流程仍可能因一句犹豫输掉残局。

## 4. 权限链：皇权定总盘，具体资源走程序

### 4.1 沈衡可以做什么

- 定国策、定预算总盘和公开条件；任免失职官员；签外交赛约；发布责任令；承担国家层面的公开解释与舆论后果。
- 要求机构提交预算分栏、赛务回执、设备清单、合同条款、回放和异议意见，并允许复核、分期、延后或公开审计。
- 批准的是政策额度与制度条件，不是某一把枪、某一个首发、某一次暂停或某一回合的答案。

### 4.2 她不能单签的事项

具体资源、训练时段、设备、枪械、首发、临时席、合同生效、赛籍、地图池、暂停、离队、跨国附约和赛务资格，必须经过对应机构会签、回执、执行和当事人选择。任何一项都不能由沈衡单签完成。

| 责任层 | 保留的边界 |
|---|---|
| 沈衡 | 国策、预算总盘、任免、外交赛约、公开责任；不改比分、不报点、不选枪、不选首发 |
| 国朝电竞署/协会/司竞监 | 把政策额度转成赛籍、赛务、预算拨付和审计回执；保留否决与复核 |
| 教练 | 训练判断、复盘、暂停建议、轮换提案和资源排班；不代替五席按键或 IGL 发令 |
| 队务/分析/回录 | 设备、合同字段、道具样本、数据、回放和责任记录；不占五席、不拍板赛果 |
| 队长与五席 | 地图、经济、暂停口令、枪位、临场选择与回合责任；由当事人承担代价 |
| 选手本人 | 合同确认、离队、跨国附约、训练风险和临时席选择；不能被皇权强留或强换 |
| 天工/AI | 只提供记录、异常时间轴、档案与评估材料；不发任务、不选人、不授予资源或权限 |

## 5. 利益、压力与关系边界

- 与贼贼姐：制度对手、责任见证、有限合作者。沈衡需要她赢，但不能给她能力、枪械、报点、首发或资源；她只能凭比赛、复盘、合同与队友选择获得位置。
- 与大表姐：必须允许依法离开大清。她不把忠诚测试伪装成命令，只让合同、程序、设备/数据交接和本人选择进入公开记录。
- 与大清国朝电竞署、协会、司竞监：她可设定总盘和任免条件，但机构保留会签、否决、拨付、赛籍与赛务执行边界；沈衡不能把执行失败全部推给下属。
- 与教练、队务、队员：她可以追问责任，但不越过训练、设备、首发、合同和临场的岗位边界。
- 与观议司：可利用公众解释，也会被自己的签字反噬；宣传不是赛务权限。
- 与天工：天工提供正统压力和评估材料，不是会说话的神；她不知道穿越全貌，也不能把旧音或档案缺页当成答案。

## 7. 不能写成什么

- 不能写成恋爱对象、性关系的资源来源、主角外挂、神谕宿主或终极反派。
- 不能写成空宝座上的静态神像，不能到赛台搬设备、调枪、做教练、报点、申请暂停、操作赛务终端、改比分或按键。
- 不能用“皇权可以但制度不行”的空泛解释替代动作；每场必须让她翻材料、追回执、改条件、签责任并承受后果。
- 不能把“皇帝/陛下”写成“女帝”标签，也不能把任何昵称写成职位、席位或权限。
