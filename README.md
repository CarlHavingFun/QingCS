## 当前主线

### `天工枪局：白桥第一枪/`

正式书名为 **《天工枪局：白桥第一枪》**。

现代 CS 职业选手周野输掉 Major 后，以自己的男性身体独自穿入架空大曜。他没有身份、赛籍、账号、住处和国家队保送，只能从曜京南城白桥枪馆的民间比赛重新开始，与苏禾、江宁、唐夏、许安组成白桥队，逐级进入城区联赛、职业赛、宫城选拔、国家集训和万国枪赛。

当前权威入口：

- 世界与生产导航：`天工枪局：白桥第一枪/README.md`
- 正式第一章：`天工枪局：白桥第一枪/正文/第01章_输掉Major后，我从民间赛重新开始.md`
- 时代、游戏与人物家族：`天工枪局：白桥第一枪/设定/`
- 新版 Skills：`天工枪局：白桥第一枪/skills/`

当前核心硬锁：

- 周野是唯一穿越者，保持自己的男性身体；
- 没有人因穿越失踪或被替换；
- 穿越后队友与现代队友完全无关；
- 第一部从白桥枪馆普通终端民间赛开始；
- 天衡检测、职业赛籍和国家队必须通过后续长期晋升获得。
