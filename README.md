## 新项目核心规则

现代男性职业选手周烬以自己的身体穿入清制风格的架空大曜朝。他是三百余年记录中唯一通过《天工枪局》完整职业适格检测的男性；除此之外，全部注册职业选手均为成年女性。

“通过检测”只证明赛台设备能够识别和承受他的操作，不代表他已经取得赛籍、合同、首发席位、政治特权或超能力。竞技结果仍由训练、情报、经济、道具、协作和临场选择决定。
